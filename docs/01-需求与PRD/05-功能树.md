# 05 功能树

说明：本树只保留当前唯一基线。叶子节点均为原子功能，格式为 `ID 标题 [MSABC][状态]`。本树同时体现用户主路径、对象从属关系和关键跨页衔接关系。

约束：
1. 本树不是只给当前协作看的功能目录，而是要让另一套 AI 也能看出产品结构。
2. `M/S/A` 级叶子节点必须足以表达：
   - 从哪个入口进入
   - 属于哪个对象
   - 依赖什么上游能力
   - 会阻塞哪些下游能力
3. 如果某个核心能力虽然写进树里，但另一套 AI 仍然可能把它放到完全不同的页面层级或对象层级，那这个节点仍然不够清楚。
4. 功能树不负责写代码，但必须尽量锁死设计结构。
5. 本树中的状态只作结构旁注，状态真相以 [06 功能清单](./06-功能清单.md) 为准。
