# 01 需求与 PRD

本目录是产品真相源，负责回答 Cyber Editor 是什么、为谁解决什么问题、必须先做哪些路径，以及这些路径被压实到什么粒度。

## 文件

1. `01-产品定位与目标用户.md`
2. `02-用户旅程与信息架构.md`
3. `03-功能范围与优先级.md`
4. `04-详细需求基线.md`
5. `05-功能树.md`
6. `06-功能清单.md`

## 使用规则

1. `01` 到 `03` 负责产品定位、用户旅程、范围边界和优先级。
2. `04` 到 `06` 负责把需求、对象关系、页面归属、状态和原子能力压实为当前基线。
3. 任何代码或 UI 修改都必须能回溯到本目录。
4. 如果实现方案与本目录冲突，先改需求文档，再改实现。
5. 新能力必须先进入本目录，再进入架构、详细设计和测试文档。
