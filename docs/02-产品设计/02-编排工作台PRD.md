# 02 编排工作台 PRD

## 首屏层级

编排页的主对象是 Flow 画布。首屏优先级固定为：

1. 中央画布最大。
2. 节点、边、分支、循环、并行、子流程可直接编辑。
3. 点击节点后，右侧直接出现节点配置。
4. 运行状态、审批、错误和恢复出现在画布或节点附近。
5. 顶部说明、大按钮、营销式引导全部降级。

## 推荐布局

```text
左活动栏 | 资产/节点库 |              Flow 画布              | 节点配置/AI/审批 | 运行轨
        |            |  状态条 / 待决 / 错误 / 恢复入口     |                |
```

## 节点配置

节点配置面板必须支持：

1. 基本信息：名称、类型、描述、启用状态。
2. 执行配置：角色、模型、工具、输入、输出。
3. 控制语义：条件、循环、并行、汇合、子流程。
4. 运行策略：超时、重试、断点、局部重跑。
5. 治理：权限、审批、风险、证据、审计。
6. 高级区：JSON、调试信息、版本迁移。

不得要求用户先点“打开深度配置”才能编辑核心配置。

## 复杂任务闭环

| 能力 | UI 要求 | 运行时要求 |
|---|---|---|
| 并行 | 分叉和汇合节点可见，分支状态独立显示 | 分支隔离、结果汇合、冲突处理 |
| 循环 | 循环条件、最大次数、退出条件可配置 | 防无限循环、checkpoint、局部恢复 |
| 子流程 | 子流程卡可进入内部编辑，可返回父流程 | 父子输入输出契约和证据继承 |
| 断点恢复 | 当前 checkpoint、可恢复节点和影响范围可见 | 持久化运行状态，支持重启恢复 |
| 工件失效传播 | stale 标记可点击，展示上游原因和下游影响 | 依赖图传播、重跑建议 |
| AI 写回冲突 | 差异、来源、风险和合并按钮可见 | 合并策略、审计记录、回滚 |
| 证据追溯 | 每个输出可查看来源消息、模型、节点、时间 | run event、artifact、citation 关联 |

## 运行控制

活跃运行必须常驻显示：

1. 当前 run。
2. 总进度。
3. 当前节点。
4. 可用动作：暂停、恢复、停止、重试、从此继续。
5. 阻断原因。
6. checkpoint。
7. 预计影响工件。

运行详情和历史可以折叠，但当前运行控制不能隐藏。
