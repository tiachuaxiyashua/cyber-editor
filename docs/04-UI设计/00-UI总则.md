# 00 UI总则

## 产品 UI 总原则
1. 以编排层为核心：编排页和由编排驱动的文档生产体验，是 Cyber Editor 的中心。
2. 小白降噪，高手深藏：首屏只显示当前任务必须的信息；低频和高级功能进入命令面板、更多菜单、右键菜单、Inspector 高级区或中心页。
3. 高频动作贴近对象：文件、节点、会话、模板、技能都应在对象本身提供常用按钮；低频动作进入右键或更多菜单。
4. 页面层级固定：欢迎页 -> 新建工程与模板中心 -> 主工作台 -> 编排页 / 深层中心页，不允许同一动作在多个页面用完全不同的入口语义。
5. 任何页面都必须考虑三种宽度：宽屏、常规宽度、紧凑宽度；布局缩放不能导致遮挡、挤爆和无法点击。
6. 无工程状态下也要成立：欢迎页不仅用于打开工程，也用于进入编排草稿和模板浏览。
7. 主工作台必须允许同时查看多个文件，优先支持分屏，并为桌面端预留独立文档窗口。

## 页面层级标记
- `P0 根页面`：进入后占据主内容区的主页面，例如欢迎页、主工作台、无工程编排模式。
- `P1 主内容替换页`：保留应用壳层，但替换主内容区，例如编排页、技能与连接中心、设置与模型配置、新建工程与模板中心。
- `P2 工作台子视图`：存在于主工作台内部的固定区域，例如文件树与文档区、AI 会话栏、流程面板。
- `P3 面板/抽屉`：不替换主页面，只展开局部层，例如更多菜单、右侧 Inspector 高级区、底部运行抽屉。
- `P4 对话框/原生选择器`：模态层或系统对话框，例如目录选择、导出文件、删除确认。

## 示意图表达规则
- 每个页面文档都必须给出一个低保真布局示意图。
- 每个页面文档都必须给出“本页会打开哪些页面/面板/对话框”的跳转层级图。
- 跳转图优先说明容器层级，不只说明“能去哪里”。
