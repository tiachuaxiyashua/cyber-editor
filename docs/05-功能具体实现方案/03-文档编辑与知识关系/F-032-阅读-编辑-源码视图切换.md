# F-032 阅读/编辑/源码视图切换

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 文档编辑 / 视图
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../04-UI设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 每个文档标签都支持三种视图：`阅读`、`编辑`、`源码`。
- 三态必须通过同一组图标分段控件切换，位于文档头部右侧。
- 当前视图状态按标签页记忆；切换到其他标签不影响本标签视图。
- 非 Markdown 文档不显示三态，只显示适用视图。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：文档头部图标分段控件
- 深层入口：命令面板
  - `切换到阅读视图`
  - `切换到编辑视图`
  - `切换到源码视图`

## 4. 用户操作与系统反馈
1. 打开 Markdown 文档后，文档头部显示三态图标。
2. 点击 `阅读`：
   - 中央区显示渲染后的 Markdown。
   - Mermaid / 思维导图 / 图片按阅读态渲染。
3. 点击 `编辑`：
   - 显示富文本 Markdown 编辑器。
   - 光标落到上次编辑位置。
4. 点击 `源码`：
   - 显示纯文本源码编辑器。
   - 行号、缩进和代码字体启用。
5. 切换标签再回来：
   - 恢复该标签上次视图。

## 5. 数据与状态
- `tabViewModeByDocPath: Record<string, "read" | "edit" | "source">`
- `lastCursorPositionByDocPath`
- 只持久化在工作台会话状态，不写入文档文件。

## 6. 实现要求
### Renderer
- 视图切换控件统一使用图标按钮，不允许回退成纯文字分段。
- 阅读态和编辑态共用同一文档源，不允许维护双份内容。
- 源码态使用独立文本编辑器组件，但保存仍走统一文档服务。

### Main / Service
- 无独立 IPC。
- 视图切换不得触发文件重读。

## 7. 校验与异常
- 当前文档存在外部冲突时：
  - 阅读态允许查看。
  - 编辑态、源码态允许进入，但顶部必须持续显示冲突提示。
- 如果某类工件不支持阅读态渲染，例如二进制附件，应降级成“预览不可用”提示而不是空白。

## 8. 自动测试
- e2e：
  - Markdown 文档显示三态切换。
  - 切换到源码后可见纯文本。
  - 切回阅读态可见渲染结果。
  - 同时打开两个标签，各自记忆自己的视图。
- 回归：
  - 主题切换、窗口缩放不导致控件文字回流或错位。

## 9. 用户模拟测试
1. 打开带 Mermaid 的 Markdown 文档。
2. 在阅读态确认图块正常显示。
3. 切编辑态修改标题。
4. 切源码态确认 Markdown 原文变化可见。
5. 切到另一个文档再回来，确认当前标签仍停留在源码态。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：该功能的唯一性在于“按标签记忆三态”和“Markdown 三态统一源文件”，不能改成全局单一视图状态。
