# F-088 阶段输出契约配置

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：模板工件与导出 / 输出契约 / 阶段
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)、[流程面板](../../04-UI设计/06-流程面板.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 阶段不只是名字，必须知道该阶段应该产出什么。
2. Guard、导出和流程推进都依赖阶段输出契约。

### 2.2 完成定义
1. 用户可为每个阶段配置：
   - 必需工件
   - 可选工件
   - 输入目录约束
   - 输出目录约束
   - blocker 规则
2. 流程面板能显示阶段契约完成情况。
3. Guard 引擎读取阶段契约，而不是只靠硬编码。

## 3. 用户操作流程
1. 在编排页打开阶段契约资产。
2. 选择某个阶段。
3. 配置该阶段必需工件和输入/输出目录。
4. 保存后，流程面板立即更新检查结果。

## 4. 数据模型
```json
{
  "stageId": "plan",
  "requiredArtifacts": [
    "requirements/feature-tree.md",
    "requirements/feature-list.md"
  ],
  "optionalArtifacts": [
    "review/plan-notes.md"
  ],
  "inputDirectories": ["input/"],
  "outputDirectories": ["requirements/"],
  "blockingRules": ["requiredArtifactsComplete", "noBlockingIssues"]
}
```

## 5. 具体实现方案
### 5.1 Renderer
1. `StageContractEditor`
2. `StageArtifactChecklist`
3. `StageGuardPreview`

### 5.2 Main / Service
1. `artifact-catalog-service`
2. `stage-guard-engine`
3. `flow-asset-persistence`

## 6. 校验与阻断
1. 阶段无必需工件时可保存为空契约，但必须显式显示该阶段无硬要求。
2. 指向不存在工件时阻止保存。
3. 输出目录与 Flow 输出目录冲突时阻止保存。

## 7. 自动测试
1. 阶段契约保存与重开
2. guard 读取阶段契约
3. 工件缺失时阻断确认

## 8. 用户模拟测试
1. 给 `discover` 阶段配置 `01-原始需求.md` 为必需工件。
2. 不生成该工件时查看流程面板，应提示未满足。
3. 生成该工件后，流程面板状态变为已满足。

## 9. 不允许的错误实现
1. 阶段契约只存在文档里，运行时不用。
2. guard 仍然依赖硬编码文件名。
3. 阶段契约不显示给用户。
