# F-115 Flow 输出文档目录配置

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：模板工件与导出 / 工件目录 / Flow 输出目录
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)、[无工程编排模式](../../04-UI设计/10-无工程编排模式.md)

## 2. 用户价值与完成定义
1. Flow 必须明确知道默认把工件写到哪里。
2. 输出目录是阶段契约和导出映射的共同基础。

完成定义：
1. 可配置多个输出目录。
2. 可配置命名规则和是否允许节点覆盖。
3. 运行后工件写入配置目录，而不是产品默认目录。

## 3. 数据模型
```json
{
  "outputDirectories": [
    {
      "path": "requirements/",
      "label": "需求文档",
      "allowNodeOverride": true,
      "namingRule": "{artifactName}.md"
    }
  ]
}
```

## 4. 具体实现方案
### Renderer
1. `FlowOutputDirectoryEditor`
2. `NamingRuleEditor`

### Main / Service
1. `flow-io-directory-service`
2. `artifact-catalog-service`

## 5. 校验与阻断
1. 输出目录必须为相对目录。
2. 命名规则非法时阻止保存。
3. 与导出目标目录冲突时给出显式警告。

## 6. 自动测试
1. 输出目录保存与恢复
2. 命名规则校验
3. 运行后写盘路径校验

## 7. 用户模拟测试
1. 配置输出目录为 `story/`。
2. 运行一个写作节点。
3. 检查工件是否进入 `story/` 而不是默认目录。

## 8. 不允许的错误实现
1. Flow 输出目录不参与真实写盘。
2. 所有工件仍写到产品硬编码目录。

## 9. 当前审计结论
- 审计状态：未完成
- 审计说明：Flow 输出目录仍未成为工件写盘与导出的统一基础。
