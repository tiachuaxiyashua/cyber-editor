# F-080 角色技能绑定、权限边界与实例化

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 角色 / 能力边界
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`、`D-C3`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 角色必须知道自己能做什么、不能做什么。
2. 同一个角色在不同 Flow 或节点中可以有覆盖，但不能无边界漂移。

### 2.2 完成定义
1. 角色默认技能、连接、工具和权限可配置。
2. Flow 级覆盖和节点级覆盖可叠加。
3. 最终生效结果可见。
4. 越权配置必须被阻止。

## 3. 实例化顺序
1. 读取角色包
2. 加载默认技能与权限边界
3. 叠加 Flow 级覆盖
4. 叠加节点级覆盖
5. 生成最终运行实例

## 4. 可见效果与状态
1. Inspector 必须同时展示：
   - 默认技能
   - Flow 覆盖
   - 节点覆盖
   - 最终生效结果
2. 若某技能越权，必须显示红色阻断态。

## 5. 数据模型
```json
{
  "roleId": "red-reviewer",
  "defaultSkills": ["requirements-review"],
  "allowedConnectors": ["local-search"],
  "allowedTools": ["read_artifact", "write_artifact"],
  "hardDenyTools": ["delete_project"],
  "flowOverrides": [],
  "nodeOverrides": []
}
```

## 7. 校验与阻断
1. 技能不存在时阻止保存。
2. 节点覆盖突破硬权限边界时阻止保存。
3. 连接未授权时阻止实例化。

## 8. 自动测试
1. 默认 + Flow + 节点覆盖合并
2. 越权阻断
3. 失效技能阻断

## 9. 用户模拟测试
1. 给角色绑定一个默认技能。
2. 在某个节点上再加一个覆盖技能。
3. 查看最终生效清单。
4. 故意添加未授权工具，确认系统阻止。

## 10. 不允许的错误实现
1. 最终生效结果不可见。
2. Flow 覆盖直接覆盖掉角色包，不可追踪来源。
3. 权限边界只写文档，不在运行前校验。
