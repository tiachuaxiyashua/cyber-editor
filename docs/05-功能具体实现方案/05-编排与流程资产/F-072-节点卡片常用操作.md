# F-072 节点卡片常用操作

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 对象交互 / 卡片动作
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)

## 2. 用户价值与完成定义
1. 高频动作必须贴近节点对象本身。
2. 右键菜单只承载低频动作，不能替代常用操作。

完成定义：
1. 节点卡片至少提供：
   - 删除
   - 复制
   - 运行当前节点
   - 打开子流程（如适用）
2. hover 和选中态的可见规则统一。

## 3. 用户操作流程
1. 用户悬停节点。
2. 看到常用操作条。
3. 直接执行操作，无需先打开深层菜单。

## 4. 具体实现方案
### Renderer
1. `NodeQuickActions`
2. `NodeCardChrome`

## 5. 校验与阻断
1. 危险动作如删除必须二次确认或可撤销。
2. 不适用动作不得显示为可点击。

## 6. 自动测试
1. hover 显示操作
2. 复制、删除、运行动作存在
3. 子流程节点专属动作存在

## 7. 用户模拟测试
1. 悬停普通角色节点，确认看到复制/删除/运行。
2. 悬停子流程节点，确认额外看到“打开子流程”。

## 8. 不允许的错误实现
1. 全部动作都藏在右键菜单。
2. 每种节点的操作条规则完全不同，没有统一逻辑。

## 9. 当前审计结论
- 审计状态：部分完成
- 审计说明：对象级高频动作还没形成统一规范和稳定行为。
