# F-085 Flow 保存、另存、导入、导出

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 资产区 / 草稿生命周期
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)、[无工程编排模式](../../04-UI设计/10-无工程编排模式.md)

## 2. 用户价值与完成定义
1. Flow 必须作为正式资产可保存、导入、导出和另存。

完成定义：
1. 支持保存当前 Flow。
2. 支持另存为新 Flow。
3. 支持导入 Flow 包。
4. 支持导出 Flow 包。

## 3. 自动测试
1. 保存后重开
2. 另存后生成新资产
3. 导出再导入

## 4. 不允许的错误实现
1. 导出只导出节点，不导出角色/工件/映射。
2. 导入后丢失布局。

## 5. 当前审计结论
- 审计状态：部分完成
- 审计说明：Flow 生命周期已部分可用，但资产完整性与兼容处理仍不足。
