# F-071 子流程卡片直接进入编辑

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 流程语义 / 子流程
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
1. 用户必须能从子流程卡片本身直接进入子流程。
2. 返回主流程时必须保留上下文。

完成定义：
1. 子流程卡片上有 `打开子流程` 按钮。
2. 点击后直接切换到子流程编辑视图。
3. 返回主流程时保留视口、滚动和选中状态。

## 3. 用户操作流程
1. 用户在主流程中点击子流程卡片。
2. 进入对应子流程。
3. 编辑后点击返回主流程。
4. 回到原位置。

## 4. 具体实现方案
### Renderer
1. `SubflowNodeCard`
2. `FlowBreadcrumb`
3. `FlowStackState`

### Main / Service
1. `subflow-runtime`
2. `flow-asset-persistence`

## 5. 校验与阻断
1. 子流程不存在时按钮禁用并显示损坏状态。
2. 返回主流程时若主流程已变更失效，必须提示重载。

## 6. 自动测试
1. 打开子流程
2. 返回主流程
3. 保留视口与选中态

## 7. 用户模拟测试
1. 主流程中点击子流程节点。
2. 进入子流程后改一个字段。
3. 返回主流程，确认位置不变。

## 8. 不允许的错误实现
1. 只能在左侧列表里找子流程。
2. 打开子流程后覆盖掉主流程状态。
