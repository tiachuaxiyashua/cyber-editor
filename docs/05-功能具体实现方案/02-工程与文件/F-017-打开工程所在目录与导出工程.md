# F-017 打开工程所在目录与导出工程

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 工程生命周期 / 定位与导出
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[主工作台](../../04-UI设计/03-主工作台.md)
- 共享实现基线：[工程与文件](README.md)

## 2. 完成定义
- 用户可在系统文件管理器中打开当前工程目录。
- 用户可导出整个工程为可分享包。

## 3. 页面入口与层级
- 页面：`P1 主工作台`
- 主入口：顶部对象菜单

## 4. 用户操作与系统反馈
1. 点击打开工程目录。
2. 系统文件管理器打开到当前工程。
3. 点击导出工程。
4. 生成导出包并提示保存位置。

## 5. 数据与状态
- `projectRootPath`
- `exportPackagePath`

## 6. 实现要求
- 导出工程和导出产物是两条链路，不能混为一谈。

## 7. 校验与异常
- 导出失败时提示原因并保留当前工程状态。

## 8. 自动测试
- e2e：触发导出工程动作并验证产物生成。

## 9. 用户模拟测试
1. 打开工程所在目录。
2. 导出工程。
3. 检查导出包存在。
