# F-121 索引新鲜度提示与增量刷新

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档知识底座与上下文管理 / 索引 / 新鲜度
- MSABC 分类：A
- 当前状态：未完成

## 2. 用户价值与完成定义
1. 文档变化后，用户必须知道索引是否过期。

完成定义：
1. 文档改动后索引状态变为“可能过期”。
2. 增量刷新成功后恢复为“最新”。
3. 增量刷新失败有明确反馈。

## 3. 自动测试
1. 变更触发脏状态
2. 增量刷新成功
3. 增量刷新失败

## 4. 当前审计结论
- 审计状态：未完成
- 审计说明：索引新鲜度与增量刷新还未成为用户可感知的正式能力。
