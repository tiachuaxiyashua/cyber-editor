# F-009 从模板创建工程

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 双主入口 / 创建工程
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[新建工程与模板中心](../../04-UI设计/02-新建工程与模板中心.md)
- 上游需求：`D-C1`、`D-C2`、`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 用户不需要手工拼目录结构、默认文档和默认流程。
2. 小白用户可以直接用模板形成第一版工程。
3. 模板不只是“文档模板”，还要同时带出默认 Flow、角色、工件目录和导出映射。

### 2.2 完成定义
1. 用户在新建工程页选择模板后，可以直接创建工程。
2. 创建完成后，工程目录至少包含：
   - 工程元数据
   - 模板预置 Flow
   - 模板预置工件目录
   - 模板预置导出映射
3. 创建完成后进入主工作台，且当前工程已绑定模板来源信息。
4. 如果模板损坏、缺关键资产、版本不兼容，必须阻止创建。

## 3. 页面入口与层级
1. 入口页面：新建工程与模板中心 `P1`
2. 触发动作：模板详情区点击 `创建工程`
3. 目标页面：主工作台 `P1`
4. 返回路径：
   - 创建前取消：返回欢迎页或模板中心
   - 创建后：工程关闭时回到欢迎页

## 4. 用户操作流程
1. 用户进入新建工程页。
2. 在模板列表选择一个模板。
3. 在右侧详情区看到模板说明、工件目录、默认 Flow 和导出映射。
4. 填写：
   - 工程名称
   - 目标路径
5. 点击 `创建工程`。
6. 系统完成目录创建与模板实例化。
7. 自动进入主工作台，并打开模板默认首页文档或主流程说明文档。

## 5. 可见效果与状态
1. 模板未选中时，`创建工程` 按钮禁用。
2. 表单未通过校验时，按钮禁用并显示具体错误。
3. 创建中时：
   - 按钮显示 loading
   - 禁止重复点击
4. 创建成功时：
   - 自动关闭新建工程页
   - 主工作台顶部显示工程名
   - 文件树中出现模板预置目录

## 6. 数据模型
### 6.1 模板实例化输入
```json
{
  "templateId": "software-factory",
  "projectName": "客户管理系统",
  "targetDirectory": "E:/workspace/projects/客户管理系统"
}
```

### 6.2 工程元数据
```json
{
  "projectId": "project_001",
  "name": "客户管理系统",
  "templateId": "software-factory",
  "templateVersion": "1.2.0",
  "createdAt": "2026-04-09T12:00:00Z"
}
```

## 7. 具体实现方案
### 7.1 Renderer
1. `TemplateListPane`
2. `TemplateDetailPane`
3. `CreateProjectForm`

Renderer 责任：
1. 表单校验
2. 模板详情展示
3. 发起 `project:createFromTemplate` IPC
4. 创建成功后刷新 bootstrap 并切入工作台

### 7.2 Main / Service
建议服务：
1. `template-registry-service`
2. `template-scaffold-service`
3. `project-service`

Main 责任：
1. 校验模板状态
2. 校验工程路径
3. 复制模板预置资产
4. 生成工程 manifest
5. 写入最近工程记录

### 7.3 IPC 契约
#### `project:create-from-template`
输入：
```json
{
  "templateId": "software-factory",
  "projectName": "客户管理系统",
  "targetDirectory": "E:/workspace/projects/客户管理系统"
}
```
输出：
```json
{
  "projectId": "project_001",
  "projectPath": "E:/workspace/projects/客户管理系统",
  "bootstrap": {}
}
```

## 8. 校验与阻断
1. 工程名为空时阻止创建。
2. 目标路径无权限时阻止创建。
3. 模板缺 `manifest`、缺默认 Flow 或缺工件目录定义时阻止创建。
4. 模板版本与当前产品不兼容时阻止创建。
5. 若目标目录非空且不允许覆盖，阻止创建并提示用户。

## 9. 自动测试
### 9.1 单元
1. 模板校验
2. 路径校验
3. 实例化脚手架生成

### 9.2 端到端
1. 打开新建工程页
2. 选择模板
3. 填写路径与名称
4. 创建成功后验证文件树与主工作台

### 9.3 回归
1. 空目录创建
2. 已有目录创建
3. 模板损坏
4. 版本不兼容

## 10. 用户模拟测试
1. 进入新建工程页。
2. 选择任一模板。
3. 输入工程名和目标目录。
4. 创建后检查：
   - 工程是否成功打开
   - 文件树是否出现模板预置目录
   - 编排页是否能看到默认 Flow

## 11. 不允许的错误实现
1. 只复制几个 Markdown 文件，不复制 Flow/工件目录/导出映射。
2. 创建成功后仍停留在新建工程页，不进入工作台。
3. 模板损坏时静默回退成空工程。
