# F-047 当前阶段显示与下一步建议

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 阶段控制 / 阶段显示
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[AI会话栏](../../04-UI设计/05-AI会话栏.md)、[流程面板](../../04-UI设计/06-流程面板.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 当前活跃会话必须明确显示其所属阶段。
- 系统必须给出下一步建议，但建议不能替代 guard 判断。
- AI 会话栏与流程面板显示的阶段必须一致。

## 3. 页面入口与层级
- 页面：
  - `P3 AI 会话栏`
  - `P3 流程面板`

## 4. 用户操作与系统反馈
1. 用户切换会话。
2. 右栏顶部阶段徽标同步变化。
3. 底部流程面板的当前阶段卡也同步变化。
4. 如果阶段存在缺失输入，下一步建议显示“先补齐 X”，不是笼统写“继续下一步”。

## 5. 数据与状态
- `currentStage`
- `stageRecommendation`
- `stageBlockingReasons[]`

## 6. 实现要求
### Renderer
- 阶段徽标必须是只读状态展示，不允许点击直接跳过阶段。
- 建议文案来自运行时状态，不是静态写死文案。

### Main / Service
- 建议由 stage guard + 当前工件状态计算。

## 7. 校验与异常
- 如果阶段状态未知，显示“状态未同步”，并禁用确认按钮。

## 8. 自动测试
- e2e：
  - 会话切换后阶段同步显示。
  - guard 不满足时建议内容发生变化。

## 9. 用户模拟测试
1. 在两个不同阶段的会话间切换。
2. 观察右栏和流程面板的阶段标签是否同步。
3. 故意制造 guard 未满足情况，确认建议变成补齐提示。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：阶段显示是状态输出，不是导航控件。
