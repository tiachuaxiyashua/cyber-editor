# F-053 审查问题采纳/忽略/待处理

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 过程可视化 / Issue
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[流程面板](../../04-UI设计/06-流程面板.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 审查问题必须有显式状态：
  - `采纳`
  - `忽略`
  - `待处理`
- blocker 问题默认 `待处理`，且会阻断阶段确认。
- 用户改状态后必须留下审计记录。

## 3. 页面入口与层级
- 页面：`P3 流程面板`
- 主入口：审查结果列表中的问题项

## 4. 用户操作与系统反馈
1. 审查完成后显示问题列表。
2. 每条问题可切换状态。
3. 状态变化后：
   - 列表视觉更新
   - 阻塞计数同步更新

## 5. 数据与状态
- `ReviewIssue`
  - `id`
  - `severity`
  - `status`
  - `resolutionNote`

## 6. 实现要求
### Renderer
- blocker 问题用红色边条或图标。
- 状态切换为忽略时必须要求填写简短原因。

### Main / Service
- 问题状态写入 review store。

## 7. 校验与异常
- 未处理 blocker 存在时，阶段确认必须禁用。

## 8. 自动测试
- e2e：
  - 切换问题状态。
  - blocker 计数变化。

## 9. 用户模拟测试
1. 处理一个普通问题为采纳。
2. 忽略一个问题并填写原因。
3. 保留一个 blocker 为待处理，确认阶段仍不能推进。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
