# INF-019 ModelRouter

## 1. 基本信息
- 类型：内部功能
- 所属层级：智能层 / 模型选择 / 路由
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：设置页、运行态、调试态

## 2. 责任与完成定义
1. 根据角色策略、节点策略和运行上下文选择模型。
2. 支持固定、优先列表、能力匹配、策略路由四种模式。
3. 输出最终选择原因供 UI 展示。

## 3. 核心接口
1. `selectModel(taskContext, modelPolicy)`

## 4. 输入维度
1. 角色包默认策略
2. Flow 覆盖
3. 节点覆盖
4. 当前可用 provider profile
5. 能力要求：
   - tool calling
   - structured output
   - max context
   - privacy

## 5. 自动测试
1. 固定模型模式。
2. 优先列表回退。
3. 能力匹配。

## 6. 不允许的错误实现
1. UI 里有 modelPolicy，运行时仍然永远只用当前激活模型。
2. 路由结果不可解释。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：模型路由已有结构，但仍未在全部主链路上真正按角色/节点策略生效。
