# 10 关键原子功能测试 Oracle 补充

## 1. F-009 从模板创建工程
- 输入：模板 A，父目录 `X`，工程名 `P`
- 预期文件系统：
  - `X/P/` 存在
  - manifest 存在
  - 模板脚手架文件存在
- 预期 UI：
  - 切入工作台
  - 标题显示工程名
- 失败边界：
  - 非法工程名阻断
  - 不可写目录阻断

## 2. F-049 只有满足 guard 才允许阶段确认
- 输入：缺少必需工件
- 预期状态：guard=`blocked`
- 预期 UI：确认按钮禁用，显示阻断原因

## 3. F-064 拖拽节点进入画布
- 输入：从节点库拖拽角色节点到空白画布
- 预期状态：
  - `flowDraft.nodes.length + 1`
  - `dirty=true`
- 预期 UI：
  - 新节点可见
  - Inspector 切到新节点

## 4. F-069 并行分叉与并行汇合配置
- 输入：新增 split 与 join，配置两条分支
- 预期状态：两条分支边存在，join 策略已保存
- 失败边界：缺汇合策略不得运行

## 5. F-088 阶段输出契约配置
- 输入：为 `plan` 阶段添加必需工件
- 预期持久化：`stageContracts` 中存在该阶段记录
- 预期 UI：流程面板 guard 依赖该工件

## 6. F-096 从目录安装技能
- 输入：有效技能目录
- 预期状态：技能列表新增项目
- 预期 UI：技能中心立刻显示已安装

## 7. F-117 工程知识索引状态查看与手动刷新
- 输入：修改文档后点击刷新
- 预期状态：`index_stale -> index_refreshing -> index_ready`
- 预期 UI：新鲜度提示消失
