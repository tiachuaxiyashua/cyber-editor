# 02 核心旅程测试矩阵

| ID | 旅程 | 必测内容 | 证明方式 |
|---|---|---|---|
| T-01 | 打开应用 | 欢迎页、最近工程、创建、打开、开始编排 | 打包应用 UI 测试 |
| T-02 | 创建工程 | 新工程目录、manifest、工作台进入 | UI + 文件断言 |
| T-03 | 文档编辑 | 打开、编辑、保存、外部冲突提示 | UI + 文件断言 |
| T-04 | AI 会话 | 选择上下文、发送、停止、重试、来源展示 | UI + mock/真实 provider 分层 |
| T-05 | AI 写回 | diff、确认、拒绝、冲突合并、回滚 | UI + artifact/document 断言 |
| T-06 | 阶段推进 | guard、生成草稿、确认阶段、阻断原因 | UI，不允许只用命令面板 |
| T-07 | 编排画布 | 创建 Flow、拖节点、连线、保存、恢复布局 | UI + manifest 断言 |
| T-08 | 节点配置 | 点击节点后右侧直接编辑配置 | UI 延迟 + 状态断言 |
| T-09 | 运行控制 | 开始、暂停、恢复、停止、重试 | UI + run event 断言 |
| T-10 | 人工确认 | 待审批出现、批准、拒绝、回退 | UI，不允许只调 API |
| T-11 | 并行/循环/子流程 | 分支、循环、子流程运行和失败恢复 | runtime + UI 组合 |
| T-12 | 工件失效传播 | 上游变化、stale 标记、影响范围、局部重跑 | UI + artifact catalog |
| T-13 | 证据追溯 | 输出到来源消息、节点、模型、审批、时间 | evidence index 断言 |
| T-14 | 安全审查 | 模板/技能导入、本地副作用、风险确认 | UI + audit 断言 |
| T-15 | 打包态 smoke | 启动、打开工程、核心页面无白屏 | `out/package/` |

## 验收口径

所有 P0 测试必须在开发态和打包态至少各验证一次。打包态是最终交付口径。
