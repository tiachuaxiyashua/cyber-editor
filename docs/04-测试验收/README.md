## 口径

1. `01` 和 `02` 定义验收门禁与核心旅程。
2. `03` 和 `04` 定义自动化与手工验证步骤。
3. `05`、`06`、`07` 把代码、测试、证据、原子能力和需求闭环串成可追踪链。
4. `08` 到 `12` 定义测试判定标准、功能域 Oracle 和高风险 MSA 测试补充。
5. `20` 到 `25` 是可执行测试编目与辅助矩阵；`generated/` 保存测试用例全集、覆盖率与质量门禁等脚本生成索引产物，不作为第二套真相源。
