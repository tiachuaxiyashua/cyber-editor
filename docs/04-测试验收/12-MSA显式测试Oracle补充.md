# 12 MSA 显式测试 Oracle 补充

## 1. 目标
把高风险 M/S/A 功能补到“输入、动作、UI、文件系统、状态、错误边界”级别。

## 2. 模板中心与双主入口
### F-009 从模板创建工程
- 输入
  - `templateId=software-factory`
  - `projectName=客户管理系统`
  - 目标目录为空目录
- 动作
  1. 打开新建工程页
  2. 选模板
  3. 填表
  4. 点击创建
- 期望 UI
  - 进入主工作台
  - 顶部显示项目名
  - 文件树出现模板预置目录
- 期望文件系统
  - `<project>/project.json`
  - `<project>/flows/`
  - `<project>/artifacts/`
- 期望状态
  - `bootstrap.project.name == 客户管理系统`
- 失败边界
  - 若模板缺 manifest，必须出现 `TEMPLATE_BROKEN`

### F-013 安装/导入模板
- 输入：一个合法模板目录
- 动作：模板中心点击安装并选择目录
- 期望 UI：模板列表新增条目，详情可见
- 期望文件系统：`templates/<id>/manifest.json`
- 错误边界：损坏目录必须报 `TEMPLATE_INSTALL_FAILED` 或 `TEMPLATE_BROKEN`

## 3. 编排层
### F-064 拖拽节点进入画布
- 输入：节点库存在 `agent` 节点
- 动作：拖拽到画布中心
- 期望 UI：出现新节点并被选中
- 期望状态：`flowDraft.nodes.length + 1`
- 失败边界：不得因缩放/滚动丢失节点

### F-069 并行分叉与并行汇合配置
- 输入：已有起点和两个角色节点
- 动作：创建并行分叉，再连接到汇合节点
- 期望 UI：分叉节点显示 2 条并行分支，汇合节点显示 merge 策略
- 期望状态：新增一分叉一汇合，两条边 branch 不同
- 错误边界：未配置 mergeStrategy 不允许运行

### F-125 编排页自然语言编排对话入口
- 输入：`帮我做一个从需求梳理到 QA 复盘的流程`
- 动作：在编排页打开流程对话，发送消息
- 期望 UI：显示 `flow-conversation-preview` 草稿或 patch 预览面板
- 期望状态：`flowConversationPreview` 非空，用户点击应用前画布未自动改写
- 错误边界：空输入禁止提交

## 4. AI 运行时
### F-049 只有满足 guard 才允许阶段确认
- 输入：阶段缺少必需工件
- 动作：点击阶段确认
- 期望 UI：流程面板显示 blocker 列表，按钮禁用或提示
- 期望状态：阶段不前进
- 错误边界：禁止静默进入下一阶段

### F-053 红蓝裁判审查
- 输入：当前阶段已有待审文档
- 动作：运行审查子流程
- 期望 UI：显示蓝军、红军、裁判结果
- 期望文件系统：生成 review 报告工件
- 失败边界：任一审查失败必须阻断 finalize

## 5. 导出与工件
### F-090 导出映射配置
- 输入：定义 `md/txt/pdf/openspec`
- 动作：保存导出映射
- 期望 UI：导出面板出现对应格式
- 期望文件系统：保存到 `contracts/export-mapping.json`
- 错误边界：缺必需工件时必须 `EXPORT_BLOCKED`

### F-093 导出 openspec 文件夹
- 输入：工件齐全且 review 通过
- 动作：点击导出 OpenSpec
- 期望 UI：显示成功结果与输出目录
- 期望文件系统：`proposal.md/design.md/tasks.md/specs/`
- 失败边界：任一文件失败则整次导出失败，不允许半成功无提示

## 6. 技能、角色、模型
### F-097 从网络下载技能
- 输入：合法远程技能包 URL
- 动作：技能中心点击下载
- 期望 UI：技能列表新增并可启用
- 期望文件系统：`skills/<id>/manifest.json`
- 错误边界：URL 不可达必须有错误条，不允许静默无反应

### F-128 从网络下载角色包
- 输入：合法远程角色包 URL
- 动作：编排页或技能中心点击下载角色包
- 期望 UI：需要审查的远程包先显示 review-required；批准后角色包出现在已安装列表
- 期望文件系统：`role-packages/installed/<id>/role.json`
- 错误边界：兼容性阻断或解析失败时不得写入注册表

## 7. 系统壳层
### F-105 三栏拖拽与宽度记忆
- 输入：默认布局
- 动作：拖拽左栏、右栏、流程面板
- 期望 UI：布局实时变化
- 期望状态：关闭重开后仍恢复
- 错误边界：不得出现遮挡主按钮或不可点击区

### F-110 打包后可启动与基础 smoke
- 输入：安装器或 exe
- 动作：启动应用
- 期望 UI：欢迎页或恢复工作台可见
- 期望状态：无崩溃，无阻塞对话框
- 失败边界：若缺运行依赖，必须显示明确错误说明
