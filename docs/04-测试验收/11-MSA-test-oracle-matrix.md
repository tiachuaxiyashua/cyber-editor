# 11 MSA Test Oracle Matrix

## 1. Goal
1. Provide one oracle entry for every M/S/A atomic capability.
2. The atomic capability document remains the canonical oracle; this matrix is the routing and summary layer.
3. Weak instructions such as "read section N" are forbidden here.

## 2. Column Notes
- Canonical Oracle: the atomic capability document that holds the definitive oracle.
- Key Input / Action / Success / File-State / Error: the first decisive line from each oracle subsection.
- Primary Tests: the primary automated tests that currently cover the capability.
- Runtime Evidence: the main screenshot / artifact evidence currently recorded.
