## 6. 数据与文件
- `.md` 为主文档真源
- 图形工件和图片资源存工程目录
- 表格工件可为 `csv/tsv/xlsx`
- 引用索引和搜索索引为派生缓存

## 6.1 持久化流程
1. Renderer 只维护当前标签、当前编辑态和脏状态。
2. `document.save` 由 Main 统一写盘，不允许 Renderer 直接写文件。
3. 若文档引用了图片、流程图、表格资源，资源先写 `assets/` 或工件目录，再写正文。
4. 保存成功后必须顺序刷新：
   - 引用图
   - 搜索索引
   - bootstrap 派生摘要
5. 保存失败时，不改动磁盘，只保留脏状态和错误提示。

## 7. 关键动作流程
### 7.1 打开文档
1. 文件树点击
2. `document.open`
3. `openTabs` 新增或激活
4. `DocumentViewport` 切换

### 7.2 保存文档
1. 编辑后进入脏状态
2. 用户保存或自动保存
3. `document.save`
4. 保存成功后刷新引用图和 bootstrap 派生数据

### 7.3 引用对比
1. 用户选两篇文档
2. 调 `note.referenceDiff`
3. 显示对比结果

## 8. 错误处理
- 外部文件改动冲突：进入冲突决策
- 文档不存在：显示错误态并关闭无效标签
- 图片/图形解析失败：显示块级错误，不影响整页

## 9. 开发顺序
1. 文件树与文档打开
2. 标签与导航
3. 编辑和保存
4. 图文工件
5. 引用关系
6. 多窗口/分屏
