## 2. 审计标准
文档层达标的定义如下：
1. 需求文档足以让初级产品工程师独立拆出功能树与功能清单。
2. 功能树与功能清单足以让初级交互工程师独立产出高度接近的 UI 方案。
3. UI 设计、原子功能定义、开发设计与代码唯一性文档合起来，足以让初级程序员按图索骥实现主路径代码。
4. 测试与追踪文档足以判断“什么算完成”“证据放在哪里”“哪些功能仍未完成”。
5. 文档必须清楚区分：
   - 文档完备性
   - 代码实现状态
   - 测试执行状态
