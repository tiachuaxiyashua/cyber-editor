# 44 模块失败点与恢复矩阵

## 1. 模板中心
- 失败点：模板目录损坏、版本不兼容、安装来源不可达
- UI：模板详情错误态 + 安装阻断
- 是否可重试：可
- 恢复入口：重新导入、更新模板、查看详情

## 2. 文档工作台
- 失败点：文件不存在、保存失败、外部冲突
- UI：块级错误 / 冲突弹窗
- 是否可重试：视错误而定
- 恢复入口：重载、覆盖、接受外部版本

## 3. AI 运行时
- 失败点：provider 不可达、guard 不通过、结构化结果失败
- UI：流程面板错误、会话气泡失败态
- 是否可重试：可
- 恢复入口：重试、修复配置、补全工件

## 4. 编排页
- 失败点：flow schema 错误、子流程丢失、并行冲突
- UI：Inspector 错误列表、节点 blocked 徽标
- 是否可重试：在修复后可
- 恢复入口：修复配置、恢复快照

## 5. 导出
- 失败点：输出目录不可写、工件缺失、映射错误
- UI：导出阻断提示
- 是否可重试：可
- 恢复入口：修目录、修契约、重新导出

## 6. 知识底座
- 失败点：索引损坏、刷新失败、context pack 预算冲突
- UI：新鲜度/损坏告警
- 是否可重试：可
- 恢复入口：重建索引、手动刷新
