# 43 版本升级与缺字段修复策略

## 1. 目标
定义复杂对象 schema 升级、缺字段补齐和不兼容阻断策略。

## 2. 升级策略
1. 允许小版本自动补齐字段。
2. 大版本不兼容时进入阻断或迁移提示。

## 3. 缺字段补齐
- `updatedAt` 缺失：可用当前时间补齐并记录修复
- `revisionId` 缺失：生成新 revision
- `trustState` 缺失：默认 `warn`

## 4. 不可自动补齐的字段
- `projectId`
- `flowId`
- `roleId`
- `templateId`
- `artifactId`

## 5. 修复记录
每次自动修复必须写入：
- 修复对象 ID
- 修复字段
- 修复时间
- 修复原因

## 6. 测试 Oracle
1. 可补齐字段缺失时允许进入修复流程。
2. 核心主键字段缺失时必须阻断。
