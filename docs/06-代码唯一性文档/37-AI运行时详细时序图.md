# 37 AI 运行时详细时序图

## 1. 发送消息
1. Renderer 读取输入框和上下文选择
2. 本地校验非空
3. 生成 optimistic message
4. 调用 `session.sendMessage`
5. Main 创建 run 记录
6. Runtime 解析上下文包
7. ModelRouter 选模型
8. AIService 发起调用
9. 运行事件逐步回传
10. 成功后写会话历史；失败则标记 run failed

## 2. 阶段草稿生成
1. Renderer 触发 `stage.guard`
2. 通过后调用 `stage.generateDraft`
3. Main 读取阶段契约和上下文 pack
4. StructuredGenerationService 生成结构化结果
5. Repair pipeline 校验并修复
6. Artifact service 写工件
7. 返回工件状态更新

## 3. 阶段确认
1. Renderer 再次调用 `stage.guard`
2. Main 重新计算 guard
3. 若 pass，执行 `stage.confirm`
4. 持久化阶段状态、确认记录
5. 刷新流程面板与会话栏
