# 56 模块级错误枚举与恢复入口

## 1. 模板中心
| 错误码 | 失败点 | UI 表现 | 可重试 | 可恢复 | 恢复入口 |
|---|---|---|---|---|---|
| `TEMPLATE_INSTALL_FAILED` | 远程下载或目录复制失败 | 模板中心顶部错误条 | 是 | 是 | 重新安装 |
| `TEMPLATE_BROKEN` | manifest 缺字段 / package 缺失 | 模板详情页红色状态块 | 否 | 是 | 修复模板 / 删除模板 |
| `TEMPLATE_INCOMPATIBLE` | 版本不兼容 | 模板详情页黄色警告 | 否 | 否 | 升级应用或安装兼容模板 |

## 2. 文档工作台
| 错误码 | 失败点 | UI 表现 | 可重试 | 可恢复 | 恢复入口 |
|---|---|---|---|---|---|
| `DOCUMENT_NOT_FOUND` | 文件被外部删除 | 文档区空态 + 重新定位按钮 | 否 | 是 | 文件树重新定位 |
| `DOCUMENT_SAVE_FAILED` | 写盘失败 | 顶部错误条 + 保存按钮保留 | 是 | 是 | 再次保存 |
| `DOCUMENT_CONFLICT` | 外部冲突 | 冲突对话框 | 否 | 是 | 选择保留版本 |

## 3. AI 运行时
| 错误码 | 失败点 | UI 表现 | 可重试 | 可恢复 | 恢复入口 |
|---|---|---|---|---|---|
| `AI_REQUEST_FAILED` | provider 不可达/超时 | 会话面板错误块 | 是 | 是 | 重试 / 切 provider |
| `AI_REPAIR_FAILED` | 结构化修复失败 | 流程面板 blocker | 是 | 是 | 重试生成 |
| `STAGE_GUARD_BLOCKED` | guard 不通过 | 阶段 blocker 列表 | 否 | 是 | 修复 blocker |

## 4. 编排层
| 错误码 | 失败点 | UI 表现 | 可重试 | 可恢复 | 恢复入口 |
|---|---|---|---|---|---|
| `FLOW_VALIDATION_FAILED` | Flow 结构无效 | Inspector 错误区 | 否 | 是 | 修改节点/边 |
| `FLOW_SAVE_FAILED` | 保存失败 | Header 错误条 | 是 | 是 | 重新保存 |
| `FLOW_RESULT_STALE` | 上游变更导致结果失效 | 节点卡片 stale 徽标 | 否 | 是 | 局部重跑 |
| `SNAPSHOT_RESTORE_FAILED` | 快照不兼容/损坏 | 恢复对话框错误块 | 是 | 是 | 选择其他快照 |

## 5. 导出
| 错误码 | 失败点 | UI 表现 | 可重试 | 可恢复 | 恢复入口 |
|---|---|---|---|---|---|
| `EXPORT_BLOCKED` | 缺工件 / stale / guard 未通过 | 导出面板 blocker 列表 | 否 | 是 | 修复工件 |
| `EXPORT_FAILED` | 生成文件失败 | 导出结果错误块 | 是 | 是 | 重新导出 |

## 6. 回滚原则
1. 任何写盘失败都不覆盖上一次成功版本。
2. 任何自动修复失败都不允许静默落盘。
3. 任何恢复失败都必须保留当前可见状态，不得清空用户画布或文档。
