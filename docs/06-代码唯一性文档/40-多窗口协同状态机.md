# 40 多窗口协同状态机

## 1. 目标
固定多窗口或分屏查看时的协同状态，避免窗口间相互污染。

## 2. 状态集合
- `single_window`
- `secondary_window_opening`
- `multi_window_ready`
- `multi_window_stale`
- `multi_window_conflict`
- `secondary_window_closing`

## 3. 跃迁
1. `single_window -> secondary_window_opening`
   - 条件：用户选择“在新窗口打开”或“分屏查看”
2. `secondary_window_opening -> multi_window_ready`
   - 条件：第二窗口 bootstrap 完成
3. `multi_window_ready -> multi_window_stale`
   - 条件：主窗口或次窗口文档状态变化，另一侧未刷新
4. `multi_window_stale -> multi_window_ready`
   - 条件：目标窗口同步完成
5. `multi_window_ready -> multi_window_conflict`
   - 条件：两个窗口对同一文档产生未协调的编辑冲突
6. `multi_window_ready|multi_window_stale -> secondary_window_closing -> single_window`

## 4. 约束
1. 主窗口与次窗口共享工程状态，但不共享瞬时 UI 选择。
2. 文档冲突必须进入显式冲突流程，不得后写覆盖前写。

## 5. 测试 Oracle
1. 新窗口打开后不得打乱主窗口当前标签。
2. 同文档双窗口编辑时必须出现冲突处理或阻断。
