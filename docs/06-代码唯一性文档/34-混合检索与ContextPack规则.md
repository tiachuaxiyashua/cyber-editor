# 34 混合检索与 Context Pack 规则

## 1. 目标
固定大工程知识底座如何检索、重排、打包上下文，避免 AI 因上下文漂移输出不稳定。

## 2. 检索来源
- 关键词检索
- 语义检索
- 引用扩展
- 手动固定上下文
- 手动排除上下文

## 3. 重排规则
1. 手动固定上下文优先级最高。
2. 直接引用的文档高于仅语义相似文档。
3. 当前阶段目标工件高于历史工件。
4. 最近编辑文档在同分时优先。

## 4. Context Pack 打包策略
1. 必选槽位：
   - 当前活动文档
   - 当前阶段契约
   - 当前会话最近消息摘要
2. 可选槽位：
   - 高分检索命中
   - 上下游工件
   - 用户手动固定项
3. 预算控制：
   - 先保留必选槽位
   - 再按重排分数填充
   - 超预算时优先裁掉低分语义命中

## 5. 新鲜度规则
1. 文档变更后需标记索引过期。
2. 过期期间允许使用旧索引，但必须给出 `stale_index_warning`。

## 6. 测试 Oracle
1. 手动固定项不得被预算裁掉。
2. 文档修改后必须出现新鲜度提示。
3. 相同查询在相同索引状态下应返回稳定排序。
