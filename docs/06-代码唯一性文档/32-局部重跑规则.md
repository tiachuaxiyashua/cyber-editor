# 32 局部重跑规则

## 1. 目标
定义节点级重跑、“从此继续”和结果失效传播规则。

## 2. 触发方式
- 从失败节点重跑
- 从选中节点继续
- 从某个子流程入口继续

## 3. 前置条件
1. 当前 draft 已保存或已显式确认使用未保存草稿重跑。
2. 所有被依赖的输入工件处于可用状态。
3. 目标节点之前的必要上游结果仍有效。

## 4. 失效传播
1. 当节点配置变化时：
   - 本节点结果失效
   - 依赖其输出的下游节点结果失效
2. 当共享工件变化时：
   - 读取该工件的所有后继节点结果失效

## 5. 重跑规则
1. `rerun_node`
   - 仅重跑当前节点
   - 前提：上游结果仍有效
2. `continue_from_node`
   - 从当前节点开始，后续链路全部重新执行
3. `rerun_subflow`
   - 重跑子流程内部全部节点

## 6. UI 约束
1. 失效节点必须显示 `stale` 或等价状态。
2. 右键菜单和 Inspector 都必须能触发局部重跑。

## 7. 测试 Oracle
1. 修改节点配置后，下游运行结果必须标记失效。
2. 仅当上游有效时才允许 `rerun_node`。
3. `continue_from_node` 后，后续节点应产生新的 run id。
