# 23 编排层细化状态机

## 1. 目标
1. 把编排层中最容易导致实现分叉的状态显式写清。
2. 防止不同实现者把编排页做成“能画图但没有稳定编辑语义”的可视化壳。

## 2. Flow 草稿顶层状态机
```text
not_loaded
  -> loaded_clean
loaded_clean
  -> loaded_dirty
loaded_dirty
  -> validating
validating
  -> validation_blocked
  -> loaded_dirty
  -> saving
saving
  -> loaded_clean
  -> save_error
loaded_dirty
  -> snapshotting
snapshotting
  -> loaded_dirty
save_error
  -> loaded_dirty
```

约束：
- 节点位置变化、面板布局变化、Inspector 改动、边增删都属于 `loaded_dirty`。
- `validation_blocked` 不等于保存失败；它表示结构不完整但草稿仍保留。
- 任意失败都不得丢失用户当前画布布局和选中态。

## 3. 节点选择状态机
```text
none_selected
  -> node_selected
node_selected
  -> edge_selected
node_selected
  -> multi_selected
edge_selected
  -> node_selected
multi_selected
  -> node_selected
multi_selected
  -> none_selected
```

约束：
- `node_selected` 时 Inspector 必须展示节点配置。
- `edge_selected` 时 Inspector 必须切换到边配置。
- `multi_selected` 时不允许继续显示某个旧节点的单节点配置。

## 4. 拖拽创建状态机
```text
palette_idle
  -> dragging_from_palette
dragging_from_palette
  -> hover_canvas_valid
  -> hover_canvas_invalid
hover_canvas_valid
  -> drop_commit
drop_commit
  -> node_selected
hover_canvas_invalid
  -> palette_idle
```

约束：
- `drop_commit` 后必须同步完成三件事：
  - 追加节点到 `flowDraft.nodes`
  - 计算并写入画布坐标
  - 让 Inspector 切到新节点
- 无效落点不得偷偷创建到默认坐标。

## 5. 连线编辑状态机
```text
edge_idle
  -> edge_dragging
edge_dragging
  -> edge_preview_valid
  -> edge_preview_invalid
edge_preview_valid
  -> edge_created
edge_preview_invalid
  -> edge_rejected
edge_created
  -> edge_selected
```

约束：
- 新边创建前必须做端口兼容性校验。
- `edge_rejected` 必须给出拒绝原因，不得静默失败。
- 边创建成功后必须让画布保持当前位置，不得触发布局重排。

## 6. 设计态 / 运行态状态机
```text
design_mode
  -> run_ready
run_ready
  -> run_running
run_running
  -> run_succeeded
  -> run_failed
  -> run_blocked
run_succeeded
  -> design_mode
run_failed
  -> design_mode
run_blocked
  -> design_mode
```

约束：
- `run_ready` 前必须完成结构校验、目录校验、契约校验。
- 进入 `run_running` 后，结构编辑控件必须隐藏或禁用。
- 从运行态返回设计态时，必须保留原来的视口与选中态。

## 7. 子流程导航状态机
```text
parent_flow
  -> subflow_entering
subflow_entering
  -> subflow_active
subflow_active
  -> parent_restoring
parent_restoring
  -> parent_flow
```

约束：
- 进入子流程前必须记录：
  - 父流程 ID
  - 父流程视口
  - 父流程选中对象
  - 父流程滚动位置
- 返回父流程时必须恢复上述状态。

## 8. 并行与循环配置状态机
### 8.1 循环节点
```text
loop_unconfigured
  -> loop_partially_configured
loop_partially_configured
  -> loop_ready
loop_ready
  -> loop_blocked
loop_blocked
  -> loop_ready
```

`loop_ready` 必须同时满足：
- 退出条件已定义
- 最大轮次已定义
- 超限策略已定义
- 循环体已绑定

### 8.2 并行节点
```text
parallel_unconfigured
  -> branches_defined
branches_defined
  -> join_defined
join_defined
  -> communication_defined
communication_defined
  -> parallel_ready
parallel_ready
  -> parallel_blocked
```

`parallel_ready` 必须同时满足：
- 分支集合存在
- 汇合策略存在
- 失败策略存在
- 分支通信规则存在

## 9. 调试态状态机
```text
debug_idle
  -> debug_preparing
debug_preparing
  -> debug_running
  -> debug_blocked
debug_running
  -> debug_succeeded
  -> debug_failed
debug_succeeded
  -> debug_idle
debug_failed
  -> debug_idle
```

约束：
- `debug_preparing` 必须明确显示：
  - 从哪个节点开始
  - 复用哪些旧结果
  - 清空哪些结果
- `debug_failed` 后不得自动把整个 Flow 标记为完全失败，除非失败策略如此定义。

## 10. 错误实现示例
1. 切换资产区后节点位置被重置。
2. 子流程返回父流程时视口跳回默认位置。
3. 进入运行态后仍可偷偷改节点结构。
4. 循环节点缺少退出条件却允许进入运行。
5. 并行分支没有通信配置却默认共享全部上下文。
