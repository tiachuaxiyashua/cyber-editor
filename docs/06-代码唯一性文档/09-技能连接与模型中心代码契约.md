# 09 技能连接与模型中心代码契约

## 1. 目标
- 锁定技能、连接、脚本工具、Provider 配置中心的代码边界。

## 2. 不允许变化的语义
- 技能中心同时管理：
  - 已安装技能
  - 可安装技能
  - 已配置连接
  - 脚本工具
- 安装/导入类动作属于深层强动作，不应抢占首层焦点。
- 技能启用范围至少包含：
  - 全局
  - 工程
  - 会话

## 3. 技能安装路径
- 本地安装：`skill.installFromDirectory`
- 远程安装：`skill.installFromRemote`
- 删除：`skill.remove`
- 改范围：`skill.setScope`
- 不允许 renderer 直接写技能目录。

## 4. 连接健康检查
- 连接健康检查结果必须结构化：
  - `status`
  - `authorized`
  - `lastCheckedAt`
  - `recentErrors[]`
- 不允许只返回“连接成功/失败”字符串。

## 5. 脚本工具适配
- 脚本工具必须通过受控适配器进入系统。
- 不允许任意脚本路径直接裸执行。
- 适配器至少声明：
  - 可执行目标
  - 参数 schema
  - 输出 schema
  - 超时
  - 权限边界

## 6. Provider 配置
- Provider 配置在设置页编辑，但连接/健康信息可在本中心查看。
- Provider 选择即激活的规则在此中心和设置页保持一致，不允许两套语义。

## 7. 测试 oracle
- 从目录安装技能后列表必须更新。
- 改技能范围后当前会话或工程作用域必须变化。
- 连接健康检查失败时必须展示结构化错误。
- 脚本工具未授权或配置不合法时必须阻断执行。
