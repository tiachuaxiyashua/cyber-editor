## 6. 关键规则
1. 选中 provider profile 即激活。
2. 技能启用范围优先级：
   - 会话 > 工程 > 全局
3. 删除技能前必须检查引用范围。

## 6.1 持久化流程
1. provider profile 保存到用户设置目录。
2. 技能安装清单和来源信息保存到技能注册目录。
3. 技能作用域绑定保存到：
   - 全局设置
   - 工程 manifest
   - Flow 草稿
   - 会话运行草稿
4. 连接器配置与授权句柄分离保存；敏感凭据只保存受保护引用。
5. 角色包下载记录独立保存到角色包注册目录，不与技能注册目录混用。

## 7. 错误处理
- 目录中无有效技能包
- provider 不可达
- Ollama 模型不存在
- profile 配置不完整

## 8. 开发顺序
1. profile CRUD
2. 选中即激活
3. 本地 Ollama 诊断
4. 技能目录安装
5. 作用范围编辑
6. 连接器健康状态
