# F-117 工程知识索引状态查看与手动刷新

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档知识底座与上下文管理 / 索引 / 状态
- MSABC 分类：A
- 当前状态：部分完成

## 2. 当前代码事实

当前主链路已经存在：

1. `src/main/services/knowledge-index-service.ts`
   - 读取 `.project/runtime/knowledge/index.json`。
   - 判断 `missing / ready / stale / error`。
   - 统计 `documentCount` 和 `staleDocumentPaths`。
   - 支持 `refresh(rootPath, 'manual' | 'incremental')`。
2. `src/main/services/runtime-service.ts`
   - `getKnowledgeIndexState()` 暴露索引状态。
   - `refreshKnowledgeIndex()` 触发刷新。
3. `src/main/ipc/register-runtime-platform-ipc.ts`
   - 注册 `knowledge:get-status` 与 `knowledge:refresh`。
4. `src/renderer/components/AppShellSections.tsx`
   - 右侧上下文面板显示知识索引状态、文档数、过期文档和刷新按钮。
5. `src/renderer/App.tsx`
   - `refreshKnowledgeIndex()` 调用 `window.api.refreshKnowledgeIndex('manual')` 并 hydrate bootstrap。

## 3. 用户路径

1. 用户打开工程。
2. Bootstrap 返回 `knowledgeIndexState`。
3. 右侧 AI / 上下文面板展示索引状态：
   - 未初始化
   - ready
   - stale
   - error
4. 用户点击“刷新索引”。
5. Renderer 调用 `knowledge:refresh`。
6. 主进程扫描工程知识文件，生成索引单元并写入 `.project/runtime/knowledge/index.json`。
7. Renderer 重新 hydrate，状态变为 ready 或 error。

## 4. 数据契约

| 字段 | 含义 |
|---|---|
| `version` | 索引结构版本，目前为 `1` |
| `builtAt` | 最近构建时间 |
| `status` | `missing / ready / stale / error` |
| `documentCount` | 当前工程可索引文档数量 |
| `staleDocumentPaths[]` | 缺失、修改或删除导致过期的文档路径 |
| `units[]` | `KnowledgeIndexUnit` 列表 |
| `lastError` | 最近索引错误 |

## 5. 当前差距

1. 用户可见状态和刷新按钮已经存在，但刷新过程没有细粒度进度条。
2. 错误状态能通过 `lastError` 表达，但 UI 仍需统一错误文案与恢复入口。
3. 打包态专项证据尚未单独记录，因此保持“部分完成”。

## 7. 不允许的错误实现

1. 不允许索引缺失时静默返回空上下文。
2. 不允许刷新按钮只改 UI 状态而不写 `.project/runtime/knowledge/index.json`。
3. 不允许 Renderer 直接扫描工程目录生成索引。
