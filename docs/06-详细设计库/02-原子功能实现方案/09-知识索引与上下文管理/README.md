# 知识索引与上下文管理

本分类用于解决大工程中的文档规模问题。

目标不是“把全部文档塞进上下文”，而是提供一套本地、可追溯、可增量更新的知识底座，用于：

- 文档检索
- 图谱关联
- 上下文推荐
- 引用追溯
- 运行时上下文打包

本分类中的能力与 AI 会话、流程面板、编排页、模板中心都有关联，但它们是独立能力域，不能继续散落在搜索、会话或工件功能中。
