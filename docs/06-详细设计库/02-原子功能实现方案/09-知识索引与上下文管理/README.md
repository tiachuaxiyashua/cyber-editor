# 知识索引与上下文管理

本分类用于解决大工程中的文档规模问题。

目标不是“把全部文档塞进上下文”，而是提供一套本地、可追溯、可增量更新的知识底座，用于：

- 文档检索
- 图谱关联
- 上下文推荐
- 引用追溯
- 运行时上下文打包

本分类中的能力与 AI 会话、流程面板、编排页、模板中心都有关联，但它们是独立能力域，不能继续散落在搜索、会话或工件功能中。

## 代码事实

当前能力不再是纯方案：

- `KnowledgeIndexService` 已实现索引状态、manual/incremental refresh 和 stale 判定。
- `HybridRetrievalService` 已实现 keyword、轻量 semantic、reference 三路召回。
- `RuntimeService` 已把检索结果、预算、固定/排除控制和 provenance 写入 context pack。
- `ContextPane` 已显示知识索引、命中原因、来源证据和固定/排除入口。
- `ProvenanceService` 已提供结构化来源记录。

仍需保持谨慎的原因是：向量语义召回、段落级来源跳转、索引错误恢复 UI、watcher 驱动刷新和打包态专项证据尚未全部收口。
