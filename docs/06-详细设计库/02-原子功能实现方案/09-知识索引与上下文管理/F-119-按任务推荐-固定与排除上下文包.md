# F-119 按任务推荐、固定与排除上下文包

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档知识底座与上下文管理 / 检索 / 上下文包
- MSABC 分类：S
- 当前状态：部分完成

## 2. 当前代码事实

当前主链路已经存在：

1. `SessionContextControls`
   - `pinnedDocumentPaths[]`
   - `excludedDocumentPaths[]`
   - `updatedAt`
2. `ProjectService.loadSessions()` / `saveSessions()`
   - 会话持久化保存上下文控制。
3. `src/main/ipc/register-settings-session-ai-ipc.ts`
   - `knowledge:update-session-context-controls` 更新会话上下文控制。
4. `RuntimeService.applySessionContextControls()`
   - 排除文档从 context documents 和 retrieval hits 中移除。
   - 固定文档被强制加入并提升 score。
5. `RuntimeService.buildContextPack()`
   - 将 pinned/excluded、retrieval hits、预算和 provenance 写入 `ContextPack`。
6. `ContextPane`
   - 展示固定/排除列表。
   - 支持对当前文档或命中文档执行固定/取消固定、排除/取消排除。

## 3. 用户路径

1. 用户在右侧上下文面板查看最近上下文包。
2. 用户对当前文档或命中文档点击“固定”。
3. 用户对不希望进入 AI 上下文的文档点击“排除”。
4. Renderer 调用 `knowledge:update-session-context-controls`。
5. 后续 AI 运行通过 `RuntimeService.applySessionContextControls()` 应用控制。
6. 新 context pack 记录 pinned/excluded 列表和预算结果。

## 4. 数据与状态

| 对象 | 字段 | 作用 |
|---|---|---|
| `AiSession` | `contextControls` | 会话级上下文控制 |
| `ContextPack` | `pinnedDocumentPaths` | 本次运行强制加入的文档 |
| `ContextPack` | `excludedDocumentPaths` | 本次运行排除的文档 |
| `RetrievalHit` | `pinned` | 固定文档命中标记 |
| `RuntimeBudgetPlan` | `selectedRetrievalHitCount` 等 | 解释预算如何选择命中 |

## 5. 当前差距

1. 固定/排除主链路已存在，但“替换条目”还没有独立交互。
2. 当前控制粒度是文档路径，尚未细化到章节或表格区域。
3. 打包态专项证据尚未单独记录，因此状态保持为“部分完成”。

## 7. 不允许的错误实现

1. 不允许 UI 显示排除但运行时仍读取该文档。
2. 不允许固定文档被普通召回排序挤掉。
3. 不允许 context pack 缺少 pinned/excluded 快照。
