# F-003 欢迎页最近工程管理

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 欢迎页与空状态 / 最近工程
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[欢迎页](../../01-UI详细设计/01-欢迎页.md)
- 上游需求：`D-A1`

## 2. 用户价值与完成定义
1. 用户需要在欢迎页直接管理最近工程，而不是只能被动看到它们。
2. 支持重命名显示名、移除、清理失效项。

## 3. 操作集合
1. 固定/取消固定
2. 重命名显示名
3. 在系统中显示
4. 从列表移除
5. 清理失效项

## 4. 具体实现方案
### 4.1 Renderer
1. 最近工程项对象级图标按钮
2. 右键或更多菜单承载低频动作

### 4.2 Main / Service
1. `recent-project-template-store`

## 5. 自动测试
1. 重命名显示名。
2. 移除单项。
3. 清理失效项。

## 6. 用户模拟测试
1. 在欢迎页对某个最近工程执行重命名。
2. 执行移除。
3. 重新打开欢迎页确认结果保持。

## 7. 不允许的错误实现
1. 管理动作跳到系统设置页。
2. 移除只改 UI 不改持久化数据。

## 8. 当前审计结论
- 审计状态：已完成
- 审计说明：最近工程管理基本可用，但仍需与最近模板管理保持视觉和交互一致。
