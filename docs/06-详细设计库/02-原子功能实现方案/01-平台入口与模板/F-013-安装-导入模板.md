# F-013 安装/导入模板

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 模板中心 / 安装
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[新建工程与模板中心](../../04-UI设计/02-新建工程与模板中心.md)
- 上游需求：`D-C2`、`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 模板中心要像“资产中心”，而不是只靠内置模板生存。
2. 用户必须能把自己做的模板导入，也能从网络下载标准模板。
3. 模板安装后要立刻变成可用平台资产，而不是目录里多一个文件。

### 2.2 完成定义
1. 模板中心支持两个独立入口：
   - 从本地导入模板
   - 从远程下载模板
2. 安装完成后模板立刻进入模板列表，并显示来源、版本、信任状态。
3. 安装失败时给出明确原因，不允许无反馈。
4. 损坏模板、重复模板、版本不兼容模板都能被识别。

## 3. 页面入口与层级
1. 入口页面：模板中心 `P1`
2. 一级动作：
   - `导入模板`
   - `下载模板`
3. 深层动作：
   - 查看安装日志
   - 修复状态
   - 覆盖安装

## 4. 用户操作流程
### 4.1 本地导入
1. 用户点击 `导入模板`。
2. 选择模板包目录或模板包文件。
3. 系统先做预检：
   - manifest 是否存在
   - 版本是否兼容
   - 是否与现有模板 ID 冲突
4. 预检通过后执行安装。
5. 安装完成后，模板立即进入模板列表并默认选中。

### 4.2 远程下载
1. 用户点击 `下载模板`。
2. 打开远程模板搜索页或远程列表抽屉。
3. 用户选择模板并点击安装。
4. 系统显示下载进度、校验进度和安装结果。

## 5. 可见效果与状态
1. 安装中：
   - 显示进度
   - 显示当前阶段：下载/解压/校验/注册
2. 成功：
   - 模板列表增加该模板
   - 模板详情区显示来源、版本、信任状态
3. 失败：
   - 顶部通知 + 模板中心内联错误
   - 保留原列表状态
4. 冲突：
   - 弹出覆盖/并存/取消选择

## 6. 数据模型
```json
{
  "templateId": "novel-studio",
  "version": "1.0.0",
  "source": "local-import",
  "trustState": "user-imported",
  "compatibility": {
    "minAppVersion": "0.1.0",
    "maxAppVersion": null
  },
  "installState": "installed"
}
```

## 7. 具体实现方案
### 7.1 Renderer
1. `TemplateImportButton`
2. `RemoteTemplateDialog`
3. `TemplateInstallProgress`

Renderer 责任：
1. 触发本地目录选择或远程下载面板
2. 展示预检结果
3. 展示安装过程和最终状态

### 7.2 Main / Service
建议服务：
1. `template-registry-service`
2. `template-package-validator`
3. `remote-template-client`
4. `template-installer-service`

Main 责任：
1. 解压或复制模板包
2. 校验 manifest 与结构
3. 写入注册表
4. 更新最近模板记录

## 8. 校验与阻断
1. 缺失 `template.json` 或 `manifest` 时阻断安装。
2. Flow 文件缺失时阻断安装。
3. 工件目录定义缺失时阻断安装。
4. 版本不兼容时阻断安装。
5. 模板 ID 冲突时必须让用户选择：
   - 覆盖
   - 保留旧版并取消本次
6. 模板来源不可信时，模板状态必须标为 `未验证`。

## 9. 自动测试
### 9.1 单元
1. 模板包校验
2. 冲突检测
3. 版本兼容检测

### 9.2 端到端
1. 导入一个本地模板包
2. 验证模板进入列表
3. 选择模板并进入详情区

### 9.3 回归
1. 重复安装
2. 模板损坏
3. 远程下载中断
4. 版本不兼容

## 10. 用户模拟测试
1. 进入模板中心。
2. 点击 `导入模板` 并选择一个模板包。
3. 等待安装完成。
4. 确认模板出现在列表中，且详情区显示来源和版本。
5. 再导入同 ID 模板，确认系统要求处理冲突。

## 11. 不允许的错误实现
1. 只把模板文件复制到目录，不写入注册表。
2. 安装失败但界面没有明确错误。
3. 安装后用户必须重启应用才能看到模板。
