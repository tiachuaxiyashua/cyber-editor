# F-001 启动后进入欢迎页或恢复工作台

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 欢迎页与空状态 / 首页启动
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[欢迎页](../../01-UI详细设计/01-欢迎页.md)、[主工作台](../../01-UI详细设计/03-主工作台.md)
- 上游需求：`D-A1`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 用户启动应用后必须立即落在明确起点，不应看到半初始化工作台。
2. 启动行为决定产品第一印象和主路径理解。

### 2.2 完成定义
1. 若存在可恢复工作上下文，进入工作台。
2. 否则进入欢迎页。
3. 不出现中间空白态或未绑定工程的残缺工作台。

## 3. 启动判断规则
1. 最近一次仍在编辑的工程有效且可打开 -> 恢复工作台
2. 最近一次为无工程编排草稿且用户未要求总是回欢迎页 -> 恢复无工程编排工作台
3. 其他情况 -> 欢迎页

## 4. 具体实现方案
### 4.1 Renderer
1. 启动壳层只负责显示加载态和接收 bootstrap。
2. 根据 bootstrap 决定进入欢迎页或工作台。

### 4.2 Main / Service
1. `recent-project-template-store`
2. `project-service`

## 5. 自动测试
1. 首次启动进入欢迎页。
2. 存在有效最近工程时恢复工作台。
3. 最近工程损坏时回欢迎页。

## 6. 用户模拟测试
1. 清空用户数据后启动，确认进入欢迎页。
2. 打开工程再关闭应用，重启确认恢复工作台。

## 7. 不允许的错误实现
1. 总是无条件恢复上次页面。
2. 最近工程失效时进入残缺工作台。

## 8. 当前审计结论
- 审计状态：已完成
- 审计说明：主路径已存在，但恢复策略仍受更高层布局与最近记录逻辑约束。
