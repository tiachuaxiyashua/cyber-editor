# F-008 新建工程的命名与路径校验

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 双主入口 / 创建工程
- MSABC 分类：M
- 当前状态：部分完成
- 关联页面：[新建工程与模板中心](../../04-UI设计/02-新建工程与模板中心.md)

## 2. 用户价值与完成定义
1. 工程名和路径是创建工程的硬前置，必须提前校验。
2. 校验结果要在表单中即时可见，而不是点击创建后才报错。

## 3. 校验项
1. 工程名不能为空
2. 工程名不得包含非法路径字符
3. 最终目标路径不得冲突
4. 目标父目录必须存在且可写

## 4. 具体实现方案
### 4.1 Renderer
1. 表单字段级即时校验。
2. 路径预览。

### 4.2 Main / Service
1. `project-service`

## 5. 自动测试
1. 非法字符校验。
2. 路径冲突校验。
3. 父目录权限校验。

## 6. 用户模拟测试
1. 输入非法工程名，确认立即报错。
2. 输入已存在目录名，确认创建按钮不可用。

## 7. 不允许的错误实现
1. 所有校验都拖到最后一步才做。
2. 错误提示不指出具体字段。
