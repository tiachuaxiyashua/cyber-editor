# F-012 模板中心搜索筛选

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 模板中心 / 浏览
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[新建工程与模板中心](../../01-UI详细设计/02-新建工程与模板中心.md)
- 上游需求：`D-A2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 模板数量增加后，没有搜索筛选就无法快速找到合适流程。
2. 用户选择模板时最关心场景、来源、状态、最近使用。

### 2.2 完成定义
1. 支持按名称、标签和说明搜索。
2. 支持按来源、状态、类型筛选。
3. 支持排序：
   - 最近使用
   - 最近更新
   - 内置优先
4. 搜索和筛选结果即时作用于列表。

## 3. 页面入口与层级
1. 入口页面：模板中心
2. 入口区域：
   - 顶部搜索框
   - 筛选条
   - 排序菜单

## 4. 用户操作流程
1. 用户输入关键词。
2. 列表即时过滤。
3. 用户再勾选“只看内置模板”或“只看未验证模板”等筛选项。
4. 用户切换排序方式。

## 5. 可见效果与状态
1. 搜索框实时显示命中数量。
2. 无结果时显示可清除筛选的空状态。
3. 激活筛选项必须显式高亮。

## 6. 数据模型
```json
{
  "query": "脚本",
  "filters": {
    "source": ["builtin"],
    "status": ["healthy"]
  },
  "sort": "recently_used"
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `TemplateSearchInput`
2. `TemplateFilterBar`
3. `TemplateSortMenu`
4. `TemplateEmptyState`

### 7.2 Main / Service
服务：
1. `template-registry`
2. `recent-project-template-store`

Main 责任：
1. 返回模板列表及其搜索字段。
2. 支持最近使用时间和更新时间排序。

## 8. 校验与阻断
1. 搜索和筛选必须是同一数据源上的组合，不允许各算各的。
2. 空状态必须能一键清除筛选条件。

## 9. 自动测试
### 9.1 单元
1. 搜索命中逻辑
2. 筛选组合
3. 排序优先级

### 9.2 端到端
1. 搜索模板名称。
2. 勾选来源筛选。
3. 切换排序并确认列表顺序变化。

## 10. 用户模拟测试
1. 搜索“脚本”。
2. 再筛选只看内置模板。
3. 清空搜索和筛选，确认列表恢复。

## 11. 不允许的错误实现
1. 搜索只匹配标题，不匹配标签和说明。
2. 筛选和搜索互相覆盖，不能叠加。
3. 空状态没有恢复路径。

## 12. 当前审计结论
- 审计状态：部分完成
- 审计说明：模板搜索筛选仍缺少稳定的组合规则和空状态恢复语义。
