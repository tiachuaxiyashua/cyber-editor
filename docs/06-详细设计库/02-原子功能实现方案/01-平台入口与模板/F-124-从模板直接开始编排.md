# F-124 从模板直接开始编排

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 模板中心 / 路径
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[新建工程与模板中心](../../04-UI设计/02-新建工程与模板中心.md)、[无工程编排模式](../../04-UI设计/10-无工程编排模式.md)、[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`、`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 用户不必把模板只当作“创建工程脚手架”。
2. 模板应该既能创建工程，也能直接作为编排起点。
3. 这条路径保证“创建编排”和“创建工程”是并列主路径，而不是口头并列。

### 2.2 完成定义
1. 模板详情区必须同时显示两个并列主动作：
   - `创建工程`
   - `开始编排`
2. 点击 `开始编排` 后，进入无工程编排模式。
3. 模板的默认 Flow、角色、工件目录、输入/输出目录、导出映射被加载到草稿中。
4. 用户随后可以：
   - 保存草稿
   - 保存为模板
   - 绑定工程
   - 导出 Flow 包

## 3. 页面入口与层级
1. 入口页面：模板中心 `P1`
2. 触发动作：模板详情区点击 `开始编排`
3. 目标页面：无工程编排模式 `P1`
4. 返回目标：
   - 返回模板中心
   - 绑定工程后进入主工作台

## 4. 用户操作流程
1. 用户进入模板中心并选中一个模板。
2. 用户查看模板详情：
   - 默认 Flow
   - 工件目录
   - 输入目录
   - 输出目录
   - 导出映射
3. 用户点击 `开始编排`。
4. 系统创建无工程草稿，并把模板的默认资产写入草稿。
5. 用户在编排页继续编辑。

## 5. 可见效果与状态
1. 按钮位置：
   - `创建工程` 与 `开始编排` 并列，不允许把其中一个折进二级菜单
2. 进入无工程编排模式后，页面标题应显示：
   - 当前模板名
   - 无工程草稿状态
3. 若模板缺失默认 Flow，`开始编排` 必须禁用并显示原因

## 6. 数据模型
```json
{
  "draftId": "draft_100",
  "sourceTemplateId": "software-factory",
  "sourceTemplateVersion": "1.2.0",
  "mode": "orchestration-draft",
  "projectId": null
}
```

## 7. 具体实现方案
### 7.1 Renderer
1. 在模板详情区固定放置两个主按钮。
2. 点击 `开始编排` 后发起 `template:startOrchestrationDraft` IPC。
3. 成功后切换至无工程编排模式并加载返回的草稿 bootstrap。

### 7.2 Main / Service
建议服务：
1. `template-registry-service`
2. `flow-asset-persistence-service`
3. `draft-registry-service`

Main 责任：
1. 读取模板默认资产。
2. 创建无工程草稿。
3. 将模板资产复制到草稿工作区，而不是复制到工程目录。
4. 记录模板来源与版本。

### 7.3 IPC 契约
#### `template:start-orchestration-draft`
输入：
```json
{
  "templateId": "software-factory"
}
```
输出：
```json
{
  "draftId": "draft_100",
  "mode": "orchestration-draft",
  "bootstrap": {}
}
```

## 8. 校验与阻断
1. 模板缺默认 Flow 时阻止开始编排。
2. 模板损坏、版本不兼容或信任状态不允许时阻止开始编排。
3. 草稿创建失败时，不允许进入空白编排页。

## 9. 自动测试
### 9.1 单元
1. 模板到草稿的实例化
2. 模板版本记录
3. 模板缺资产阻断

### 9.2 端到端
1. 在模板中心选择模板
2. 点击 `开始编排`
3. 验证进入无工程编排模式
4. 验证模板预置 Flow 与工件目录已出现

## 10. 用户模拟测试
1. 进入模板中心。
2. 选择模板。
3. 点击 `开始编排`。
4. 进入编排页后检查：
   - 不是工程模式
   - 已有模板默认主流程
   - 已有模板默认工件目录

## 11. 不允许的错误实现
1. 点击 `开始编排` 后实际创建工程目录。
2. 只加载 Flow，不加载工件目录和导出映射。
3. 把 `开始编排` 藏进更多菜单，导致它不再是主路径。
