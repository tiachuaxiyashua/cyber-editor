# INF-004 Recent project/template store

## 1. 基本信息
- 类型：内部功能
- 所属层级：壳层与文档底座 / 最近记录 / 索引
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：欢迎页、模板中心
- 共享实现基线：[平台入口与模板](README.md)

## 2. 责任与完成定义
1. 保存最近工程和最近模板记录。
2. 支持固定、移除、重命名显示名、最近使用时间更新。
3. 为欢迎页、启动恢复、模板中心提供同一数据源。

## 3. 核心接口
1. `listRecentProjects()`
2. `listRecentTemplates()`
3. `pinRecentItem(id)`
4. `removeRecentItem(id)`

## 4. 自动测试
1. 最近项新增。
2. 最近项更新。
3. 固定与移除。

## 5. 不允许的错误实现
1. 工程和模板各维护一套完全独立的最近记录逻辑。

## 6. 当前审计结论
- 审计状态：已完成
- 审计说明：最近记录服务主链路已存在，但仍需配合模板元数据和损坏状态判断一起工作。
