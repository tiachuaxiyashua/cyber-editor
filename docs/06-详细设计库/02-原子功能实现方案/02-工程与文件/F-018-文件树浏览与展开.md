# F-018 文件树浏览与展开

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 浏览
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 用户必须能浏览工程目录并定位文件。
2. 目录节点支持展开、折叠、当前文件高亮。
3. 展开状态在当前工程会话内保持。

## 3. 页面行为
1. 单击目录箭头只切换展开状态。
2. 单击文件节点打开文件。
3. 当前打开文件所在路径自动展开并高亮。

## 4. 具体实现方案
### 4.1 Renderer
1. `ProjectTree`
2. `TreeFolderRow`
3. `TreeFileRow`

### 4.2 Main / Service
1. `file-tree-index-watch`
2. `tab-navigation-state-service`

## 5. 校验与阻断
1. 不允许目录节点点击后误打开文件。
2. 文件树刷新后不应丢失用户已展开的目录，除非该目录已不存在。

## 6. 自动测试
1. 展开目录。
2. 打开文件后自动高亮。
3. 刷新工程后保留展开状态。

## 7. 用户模拟测试
1. 展开两级目录。
2. 打开深层文件。
3. 确认父目录保持展开且文件高亮。

## 8. 不允许的错误实现
1. 文件树刷新后全部折叠。
2. 当前文件高亮和实际打开标签不同步。

## 9. 当前审计结论
- 审计状态：已完成
- 审计说明：文件树浏览主链路已完成，但仍需和多窗口/分屏浏览能力联动。
