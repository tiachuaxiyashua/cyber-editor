# F-023 删除文件或文件夹

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 删除
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 用户必须能删除不需要的文件和目录。
2. 删除是危险动作，必须有确认与后续 UI 收口。

## 3. 页面行为
1. 对象级删除按钮和右键删除入口都可触发。
2. 文件夹删除前显示包含内容摘要。
3. 删除成功后关闭相关打开标签并刷新树。

## 4. 具体实现方案
### 4.1 Renderer
1. `DeleteConfirmDialog`

### 4.2 Main / Service
1. `document read/write service`
2. `tab-navigation-state-service`

## 5. 校验与阻断
1. 正在使用的关键系统目录禁止删除。
2. 删除失败时保留原选择和上下文。

## 6. 自动测试
1. 删除文件。
2. 删除文件夹。
3. 删除后标签关闭。

## 7. 用户模拟测试
1. 打开一个文件。
2. 删除它。
3. 确认文件树刷新且标签关闭。

## 8. 不允许的错误实现
1. 删除后标签残留坏路径。
2. 删除文件夹不做确认。

## 9. 当前审计结论
- 审计状态：已完成
- 审计说明：删除主链路已完成，仍需和系统目录保护规则保持一致。
