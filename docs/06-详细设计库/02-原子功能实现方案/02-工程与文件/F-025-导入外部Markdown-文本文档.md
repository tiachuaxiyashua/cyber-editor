# F-025 导入外部 Markdown/文本文档

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 导入
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 用户能把外部已有文档纳入工程。
2. 导入后文件立即进入工程结构并可打开编辑。

## 3. 具体实现方案
### 3.1 Renderer
1. 导入入口位于深层菜单或对象级动作。

### 3.2 Main / Service
1. `document read/write service`

## 4. 校验与阻断
1. 仅支持声明范围内格式。
2. 同名冲突时要求确认重命名或取消。

## 5. 自动测试
1. 导入 Markdown。
2. 导入纯文本。
3. 冲突文件名处理。

## 6. 用户模拟测试
1. 从外部导入一个 Markdown。
2. 确认文件树出现且自动打开。

## 7. 不允许的错误实现
1. 导入后只是复制到磁盘，不进入树和标签。
