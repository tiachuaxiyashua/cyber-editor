# F-022 重命名文件或文件夹

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 重命名
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 文件和目录需要可重命名。
2. 重命名后，打开标签、引用关系和路径摘要要同步更新。

## 3. 页面行为
1. 右键或对象级菜单选择重命名。
2. 输入新名称。
3. 成功后树节点、标签、面包屑同时更新。

## 4. 具体实现方案
### 4.1 Renderer
1. `RenameTreeItemDialog` 或内联编辑

### 4.2 Main / Service
1. `document read/write service`
2. `tab-navigation-state-service`
3. `reference graph indexer`

## 5. 校验与阻断
1. 同级重名阻止。
2. 非法字符阻止。
3. 打开的文档如果被重命名，不允许标签保留旧路径。

## 6. 自动测试
1. 文件重命名后标签更新。
2. 文件夹重命名后树路径更新。
3. 引用索引刷新。

## 7. 用户模拟测试
1. 打开一个文件。
2. 在树中重命名它。
3. 确认标签名称和路径同时变化。

## 8. 不允许的错误实现
1. 文件系统改名了，但 UI 仍显示旧名。
2. 重命名目录后子项路径摘要错误。

## 9. 当前审计结论
- 审计状态：已完成
- 审计说明：重命名主链路已完成，但仍需和多窗口与引用刷新保持一致。
