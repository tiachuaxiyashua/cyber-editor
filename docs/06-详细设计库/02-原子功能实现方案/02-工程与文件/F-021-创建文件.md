# F-021 创建文件

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 创建
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 用户必须能在工程内创建文档和其他工件文件。
2. 创建后应立即打开或定位到新文件。

## 3. 页面行为
1. 用户选择目标目录。
2. 执行“新建文件”。
3. 输入文件名。
4. 创建成功后自动打开该文件。

## 4. 具体实现方案
### 4.1 Renderer
1. `CreateFileDialog`

### 4.2 Main / Service
1. `document read/write service`

## 5. 校验与阻断
1. 文件名不能为空。
2. 同级重名阻止。
3. 后缀允许为空，但模板或工件推荐类型要给默认值。

## 6. 自动测试
1. 创建 Markdown 文件。
2. 自动打开标签。
3. 重名阻止。

## 7. 用户模拟测试
1. 新建一个 Markdown 文件。
2. 确认中间文档区自动打开。

## 8. 不允许的错误实现
1. 创建成功但不打开文件。
2. 创建临时文件名后不允许重命名。

## 9. 当前审计结论
- 审计状态：已完成
- 审计说明：创建文件主链路已完成，仍需与表格和图形工件类型联动。
