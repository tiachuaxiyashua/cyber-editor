# 00 原子功能实现总则

## 文档定位

本目录承接 `F-*` 与 `INF-*` 原子能力的实现级说明。它不替代需求、功能树、功能清单、代码契约或模块开发设计；它回答的是“这个能力怎么被触发、怎么流转、怎么验证”。

## 实施规则

1. 任何功能只有同时满足“主链路代码存在、自动化测试存在、真实程序执行过”三项，才允许标记为“已完成”。
2. 如果代码里只有类型、UI 外壳或占位接口，没有主链路，就只能记为“部分完成”或“未完成”。
3. 每个原子功能都要单独成文，文档必须能让不了解背景的初级程序员按顺序复原 90% 以上实现。
4. 任何页面设计都必须服务于功能，不允许只有视觉稿没有具体交互和调用关系。
5. 所有功能文档都必须包含自动测试和用户模拟测试建议。
6. 所有编排相关功能都要先检查工件契约、阶段 guard、运行态/设计态、调试态和历史恢复，再谈按钮和排版。

## 状态定义

- 已完成：代码主链路可用，测试已覆盖，用户路径已走通。
- 部分完成：有代码或骨架，但交互、约束、稳定性或测试未收口。
- 未完成：只有方案或零散尝试，当前不可用。
