# F-108 小白降噪与高手深层入口

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：系统辅助与体验 / 布局 / 渐进暴露
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[欢迎页](../../04-UI设计/01-欢迎页.md)、[主工作台](../../04-UI设计/03-主工作台.md)、[编排页](../../04-UI设计/07-编排页.md)、[技能与连接中心](../../04-UI设计/08-技能与连接中心.md)
- 上游需求：`D-A4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. Cyber Editor 的主要对象包含不会梳理想法的小白用户，也包含会自定义流程的高手用户。
2. 小白需要低噪音、清晰主路径。
3. 高手需要命令面板、右键、Inspector 高级区和资产中心等深层能力。

### 2.2 完成定义
1. 首层页面只展示当前任务必须动作。
2. 低频复杂能力统一下沉到深层入口。
3. 高频对象操作贴近对象本身。
4. 同一功能同时具备：
   - 小白可发现路径
   - 高手快捷路径

## 3. 页面级规则
### 3.1 欢迎页
1. 只展示：
   - 创建工程
   - 创建编排
   - 最近工程
   - 最近模板
2. 不展示复杂模板安装列表和连接配置。

### 3.2 主工作台
1. 文档区保持安静。
2. 高级导入、导出、切换类动作进入对象级菜单或命令面板。

### 3.3 编排页
1. 常用动作贴在节点卡片、画布和顶部少量工具条。
2. 低频动作进入右键菜单、更多菜单和历史/调试抽屉。

### 3.4 技能与连接中心
1. 主区展示资源状态。
2. 安装和导入通过图标化深层入口进入。

## 4. 双路径设计
### 4.1 小白路径
1. 欢迎页
2. 选模板
3. 创建工程或开始编排
4. 跟着阶段和主按钮走

### 4.2 高手路径
1. 命令面板
2. 右键菜单
3. Inspector 高级区
4. 资产中心

## 5. 具体实现方案
### 5.1 Renderer
组件：
1. `PrimaryActionStrip`
2. `AdvancedEntryMenu`
3. `InspectorAdvancedSection`
4. `CommandPaletteActionMap`

Renderer 责任：
1. 按页面规则控制哪些动作在首层出现。
2. 为被下沉的动作提供可发现的替代入口。

### 5.2 Main / Service
服务：
1. `command-registry`
2. `ui-responsive-layout-engine`

Main 责任：
1. 维护统一动作注册表，保证同一动作既能从深层入口进入，也能从命令面板进入。

## 6. 校验与阻断
1. 同一页面首层超过定义范围的低频动作，视为违规。
2. 高级动作下沉后若无其他发现路径，视为违规。
3. 页面层级调整不得破坏现有主路径。

## 7. 自动测试
### 7.1 审核型回归
1. 欢迎页首屏动作数量和类型
2. 主工作台工具栏按钮数量
3. 编排页对象级按钮与右键菜单的职责分工

### 7.2 端到端
1. 小白路径：欢迎页 -> 模板 -> 创建工程
2. 高手路径：命令面板 -> 进入安装/导入/调试动作

## 8. 用户模拟测试
1. 让一个完全不懂编排的用户打开欢迎页，确认 10 秒内能看出两个主路径。
2. 让熟练用户直接使用右键、命令面板和 Inspector 完成相同任务。
3. 对比两条路径是否都能完成任务且互不干扰。

## 9. 不允许的错误实现
1. 为了照顾高手，把低频复杂动作常驻在首页。
2. 为了降噪，把复杂动作彻底藏没了。
3. 不同页面对相同动作给出完全不同的入口哲学。

## 10. 当前审计结论
- 审计状态：未完成
- 审计说明：当前产品仍缺一套严格执行到各页面的“首层降噪、深层可达”机制。
