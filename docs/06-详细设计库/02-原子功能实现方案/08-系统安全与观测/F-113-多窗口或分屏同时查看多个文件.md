# F-113 多窗口或分屏同时查看多个文件

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 多文件查看 / 多窗口/分屏
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[主工作台](../../01-UI详细设计/03-主工作台.md)、[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[系统安全与观测](README.md)

## 2. 功能目标
- 支持用户同时查看多个文件，至少包含：
  - 标签多开
  - 主工作台内分屏
  - 独立文档窗口

## 3. 触发与前置条件
- 触发方式：标签右键、对象级更多菜单、命令面板。
- 前置依赖：[INF-051 Multi-window workspace coordinator](./INF-051-Multi-windowworkspacecoordinator.md)

## 4. 具体实现方案
- 同窗口分屏优先，独立窗口作为增强模式。
- 独立窗口只展示文档与必要上下文，不复制整套工作台噪音。
- 多窗口状态必须与主工作台共享同一工程和文档保存链路。

## 5. 自动测试
- e2e：从标签页打开分屏、打开独立窗口、关闭后状态恢复。

## 6. 用户模拟测试
1. 同时打开两个文档。
2. 将第二个文档放到分屏或新窗口。
3. 同时修改并保存，确认不会相互覆盖。

## 7. 当前审计结论
- 审计状态：未完成
- 审计说明：当前只有标签切换，没有真正的多文件同时查看能力。
