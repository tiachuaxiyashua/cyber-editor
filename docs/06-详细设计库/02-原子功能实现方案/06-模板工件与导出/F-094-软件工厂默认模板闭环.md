# F-094 软件工厂默认模板闭环

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：模板工件与导出 / 模板闭环 / 默认模板
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[主工作台](../../01-UI详细设计/03-主工作台.md)、[流程面板](../../01-UI详细设计/06-流程面板.md)、[编排页](../../01-UI详细设计/07-编排页.md)
- 上游需求：`D-A2`

## 2. 用户价值与完成定义
1. 软件工厂模板是默认示例模板，必须证明平台能从模糊想法走到可交付文本产物。

### 2.2 完成定义
1. 模板定义完整的阶段、工件目录、导出映射。
2. 用户可用该模板完成：
   - 原始需求
   - 澄清
   - 规划
   - 审查
   - 导出
3. 输出可落到 Markdown、OpenSpec 等交付格式。

## 3. 具体实现方案
### 3.1 组成要素
1. 模板元数据
2. 默认 Flow
3. 角色包
4. 工件目录
5. 阶段契约
6. 导出映射

### 3.2 运行要求
1. 阶段 guard 必须生效。
2. 审查子流程必须可触发。
3. 导出必须基于当前工件状态。

## 4. 自动测试
1. 用默认模板创建工程。
2. 跑一遍最小流程。
3. 导出 OpenSpec。

## 5. 用户模拟测试
1. 从欢迎页选择软件工厂模板。
2. 录入一句话需求。
3. 推进阶段直到导出。

## 6. 不允许的错误实现
1. 默认模板只是几份示例文档，没有完整 Flow 和导出结构。
2. 无法用它证明平台主闭环。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：默认模板已具备基本闭环，但仍未完全体现最新编排、工件契约和知识底座要求。
