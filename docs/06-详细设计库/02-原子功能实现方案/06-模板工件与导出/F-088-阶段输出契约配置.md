# F-088 阶段输出契约配置

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：模板工件与导出 / 输出契约 / 阶段
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)、[流程面板](../../01-UI详细设计/06-流程面板.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 阶段不只是名字，必须知道该阶段应该产出什么。
2. Guard、导出和流程推进都依赖阶段输出契约。

### 2.2 完成定义
1. 用户可为每个阶段配置：
   - 必需工件路径
   - 校验器集合
   - 阻断策略
   - 是否允许人工绕过
2. 流程面板能显示阶段契约完成情况。
3. Guard 引擎读取阶段契约，而不是只靠硬编码。
4. 若模板未显式声明 `stageContracts`，运行时必须从 `stageDocuments` 自动生成默认 `StageOutputContract`。

## 3. 用户操作流程
1. 在编排页打开阶段契约资产。
2. 选择某个阶段。
3. 配置该阶段 `requiredArtifactPaths`、`validatorIds`、`blockingPolicy` 和 `allowManualBypass`。
4. 保存后，流程面板立即更新检查结果。

## 4. 数据模型
```json
{
  "stageId": "plan",
  "requiredArtifactPaths": [
    "01-requirements/03-功能树.md",
    "01-requirements/04-功能清单.md",
    "02-solution/01-技术方案.md"
  ],
  "validatorIds": [
    "feature-tree",
    "feature-list",
    "technology-solution"
  ],
  "blockingPolicy": "all_required",
  "allowManualBypass": false
}
```

当前代码口径：
- 数据类型为 `StageOutputContract`。
- 字段定义见 `src/shared/types.ts`。
- 模板可显式声明 `stageContracts`，也可只声明 `stageDocuments`，由运行时自动推导默认契约。
- 输入/输出目录约束不属于阶段契约对象本身，而属于 `PlatformFlowAsset.pathConfig / FlowPathConfig`。

## 6. 校验与阻断
1. 阶段无必需工件时可保存为空契约，但必须显式显示该阶段无硬要求。
2. 指向不存在工件时阻止保存。
3. `validatorIds` 指向不存在的校验器时阻止保存。
4. `blockingPolicy` 仅允许当前代码支持的枚举值：`all_required`、`allow_warnings`。
5. `allowManualBypass=false` 时，阶段确认必须严格受契约阻断；`allowManualBypass=true` 时也必须在 UI 中显式标记为人工绕过。

## 7. 自动测试
1. 阶段契约保存与重开
2. guard 读取阶段契约
3. 工件缺失时阻断确认

## 8. 用户模拟测试
1. 给 `discover` 阶段配置 `01-requirements/01-原始需求.md` 为必需工件路径。
2. 不生成该工件时查看流程面板，应提示未满足。
3. 生成该工件后，流程面板状态变为已满足。

## 9. 不允许的错误实现
1. 阶段契约只存在文档里，运行时不用。
2. guard 仍然依赖硬编码文件名。
3. 阶段契约不显示给用户。
