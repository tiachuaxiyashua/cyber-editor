# F-044 新建、重命名、归档和删除会话

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 会话管理 / 管理动作
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[AI会话栏](../../01-UI详细设计/05-AI会话栏.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 用户可在当前工程下：
  - 新建会话
  - 重命名会话
  - 归档会话
  - 删除会话
- 删除必须二次确认。
- 删除当前活跃会话后，系统必须自动选中下一个可用会话或创建空白会话。

## 3. 页面入口与层级
- 页面：`P3 AI 会话栏`
- 主入口：
  - 顶部 `+` 新建
  - 会话卡对象级图标
- 深层入口：
  - 右键菜单
  - 命令面板

## 4. 用户操作与系统反馈
1. 点击 `+` 新建会话：
   - 会话列表新增一项。
   - 默认名称按模板生成，如“需求澄清会话 2”。
2. 重命名：
   - 就地编辑标题。
3. 归档：
   - 会话移到归档分组。
4. 删除：
   - 弹确认框。
   - 删除后列表刷新。

## 5. 数据与状态
- `AiSession`
  - `id`
  - `title`
  - `archived`
  - `createdAt`
  - `updatedAt`

## 6. 实现要求
### Renderer
- 高频动作贴对象，不放到全局悬空菜单。
- 删除按钮用危险色。

### Main / Service
- 持久化由 session 服务完成。
- 不能仅删 UI 里的会话卡。

## 7. 校验与异常
- 名称为空时不能保存。
- 删除唯一活跃会话时，系统必须保证工作台仍有可用会话上下文。

## 8. 自动测试
- e2e：
  - 新建、重命名、归档、删除全链路。
  - 删除当前活跃会话后有新的活跃会话。

## 9. 用户模拟测试
1. 建三个会话。
2. 修改其中一个名称。
3. 归档另一个。
4. 删除当前活跃会话，确认系统自动切到剩余会话。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：会话管理动作必须是对象级动作，不允许全部塞进顶部全局菜单。
