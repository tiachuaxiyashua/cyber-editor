# INF-024 Review engine

## 1. 基本信息
- 类型：内部功能
- 所属层级：编排层 / 审查引擎 / 红蓝裁判
- MSABC 分类：S
- 当前状态：部分完成

## 2. 责任与完成定义
1. 驱动红蓝裁判审查子流程。
2. 管理审查轮次、角色执行顺序、审查结果收敛。

## 3. 核心接口
1. `runReviewSubflow(reviewConfig, runtimeContext)`

## 4. 自动测试
1. 一轮审查。
2. 多轮审查。
3. 审查退出条件。

## 5. 不允许的错误实现
1. 红蓝裁判只是三次独立 prompt 调用，没有统一引擎。
2. 审查结果不写工件、不进入流程控制。

## 6. 当前审计结论
- 审计状态：部分完成
- 审计说明：审查引擎已有原型，但仍未完全标准化为统一子流程运行器。
