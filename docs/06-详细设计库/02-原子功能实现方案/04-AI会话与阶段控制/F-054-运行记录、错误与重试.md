# F-054 运行记录、错误与重试

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 运行记录 / 记录与重试
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[流程面板](../../04-UI设计/06-流程面板.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 每次 AI 运行都要生成一条可追溯的运行记录。
- 运行记录至少展示：
  - 触发动作
  - 运行时间
  - 成功/失败/已停止
  - 使用模型
  - 可重试入口

## 3. 页面入口与层级
- 页面：`P3 流程面板`
- 主入口：运行记录区

## 4. 用户操作与系统反馈
1. 触发任何 AI 运行。
2. 流程面板追加一条运行记录。
3. 失败时显示错误摘要和 `重试`。
4. 点击重试后生成新运行记录，不覆盖旧记录。

## 5. 数据与状态
- `RuntimeRun`
- `RuntimeEvent[]`
- `errorSummary`
- `retryOfRunId`

## 6. 实现要求
### Renderer
- 运行记录按时间倒序。
- 失败记录默认展开错误摘要。

### Main / Service
- Runtime store 是唯一事实源。

## 7. 校验与异常
- 相同运行不可重复重试并发触发。

## 8. 自动测试
- e2e：
  - 成功/失败/停止三种记录出现。
  - 失败重试生成新记录。

## 9. 用户模拟测试
1. 触发一次成功运行。
2. 再触发一次失败运行。
3. 对失败记录点击重试，确认新增记录而不是覆盖旧记录。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
