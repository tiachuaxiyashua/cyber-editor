# F-058 角色实际命中模型可见

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 模型配置 / 命中可见
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[流程面板](../../01-UI详细设计/06-流程面板.md)、[AI会话栏](../../01-UI详细设计/05-AI会话栏.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 当某个角色或运行实际命中某个模型时，用户必须能看到：
  - 角色名
  - 命中模型
  - provider
- 如果发生 fallback，也要显示“已回退到 X 模型”。

## 3. 页面入口与层级
- 页面：
  - `P3 流程面板`
  - `P3 AI 会话栏`
- 主入口：运行记录详情 / 过程卡

## 4. 用户操作与系统反馈
1. 用户触发一个 AI 运行。
2. 过程卡显示 `角色：需求分析师`、`模型：qwen3:8bm` 这类信息。
3. 如果路由后实际用了别的模型，明确显示实际命中值。

## 5. 数据与状态
- `resolvedModel`
- `requestedModelPolicy`
- `fallbackReason`

## 6. 实现要求
### Renderer
- 该信息属于运行详情，不应常驻占用首屏大空间。

### Main / Service
- ModelRouter 需要返回结构化路由结果，而不是只返回最终字符串。

## 7. 校验与异常
- 当前状态为“部分完成”，表示已有部分可见信息，但模型路由的完整命中证据和 fallback 说明尚未完全打通。

## 8. 自动测试
- unit：
  - 路由结果包含 resolved model。
- e2e：
  - 运行详情可见模型命中信息。

## 9. 用户模拟测试
1. 触发一次运行。
2. 打开运行详情。
3. 确认能看到角色与实际命中模型。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
