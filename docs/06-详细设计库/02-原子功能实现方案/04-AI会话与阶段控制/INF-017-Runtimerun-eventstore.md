# INF-017 Runtime run/event store

## 1. 基本信息
- 类型：内部能力
- 所属层级：编排层 / 运行记录 / 存储
- MSABC 分类：A
- 当前状态：已完成
- 对应功能：
  - [F-051 AI 内部过程显性化展示](./F-051-AI内部过程显性化展示.md)
  - [F-054 运行记录、错误与重试](./F-054-运行记录、错误与重试.md)

## 2. 能力目标
- 统一记录 AI 运行、阶段草稿、审查子流程的 run 与 event。

## 3. 输入输出
- 输入：运行开始/结束/错误/工件写入/中断事件
- 输出：`RuntimeRun`、`RuntimeEvent[]`

## 4. 实现要求
- 事件必须有时间戳、类型、runId、sessionId。
- 运行状态只能通过该 store 更新。

## 5. 校验与异常
- 不允许覆盖旧记录，只允许追加新 run。

## 6. 自动测试
- unit：事件追加、状态迁移、重试关联。
