## 2. 能力目标
- 存储项目记忆、会话记忆和每轮审查结果引用。

## 3. 输入输出
- 输入：运行结果、审查轮次、用户确认结论
- 输出：可追溯的 memory + review round records

## 4. 实现要求
- 项目记忆和会话记忆分开存。
- 审查轮次要能回溯到对应工件。

## 5. 校验与异常
