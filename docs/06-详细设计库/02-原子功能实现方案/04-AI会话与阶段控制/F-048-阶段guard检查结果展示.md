# F-048 阶段 guard 检查结果展示

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 阶段控制 / Guard
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[流程面板](../../04-UI设计/06-流程面板.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 流程面板必须显示当前阶段的 guard 结果。
- 结果至少分三类：
  - 已满足
  - 缺失输入
  - 存在阻塞问题
- 每条结果都要能定位到对应工件或问题对象。

## 3. 页面入口与层级
- 页面：`P3 流程面板`
- 展示区域：当前阶段卡下方 `检查结果`

## 4. 用户操作与系统反馈
1. 用户打开流程面板。
2. 当前阶段卡下方显示 guard 列表。
3. 每条 guard 项显示：
   - 状态图标
   - 短描述
   - `定位` 按钮
4. 点击 `定位`：
   - 打开对应工件、问题项或配置页面。

## 5. 数据与状态
- `StageGuardStatus`
  - `items[]`
  - `severity`
  - `blocking`
  - `targetRef`

## 6. 实现要求
### Renderer
- guard 列表默认折叠摘要，支持展开查看详情。
- 阻塞项必须用危险色或强警示样式。

### Main / Service
- guard 结果由 StageGuardEngine 返回结构化数据，不由前端拼字符串。

## 7. 校验与异常
- 当 guard 还未计算完成时，显示“正在检查”而不是空白。
- 当前状态为“部分完成”，表示 guard 结构已有，但可定位性、覆盖率或实时性未完全收口。

## 8. 自动测试
- e2e：
  - 当前阶段显示 guard 列表。
  - 缺失工件时显示阻塞项。
  - 点击定位跳到目标工件。
- unit：
  - guard 结构到 UI 映射。

## 9. 用户模拟测试
1. 打开一个 guard 不满足的工程。
2. 展开流程面板 guard 列表。
3. 点击某条阻塞项的定位按钮。
4. 确认跳到正确文档。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
- 审计备注：不能把 guard 结果做成一句“尚未完成”的泛提示，必须可定位。
