# F-055 Provider 选择即激活

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 模型配置 / 激活
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[设置与模型配置](../../04-UI设计/09-设置与模型配置.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 用户在 provider profile 列表中点击某配置后，该配置立即成为当前激活配置。
- 不再需要额外“激活”按钮。
- 激活状态必须即时反馈到：
  - 设置页
  - AI 会话运行链路

## 3. 页面入口与层级
- 页面：`P4 设置与模型配置`
- 主入口：Provider profile 列表项点击

## 4. 用户操作与系统反馈
1. 用户打开设置。
2. 点击某 profile。
3. 该 profile 进入激活态样式。
4. 顶部或列表说明显示“当前使用”。

## 5. 数据与状态
- `providerProfiles[]`
- `activeProviderProfileId`

## 6. 实现要求
### Renderer
- 选中态与激活态统一，不允许“双击选中、再点激活”双步骤。

### Main / Service
- 激活写入设置持久化。

## 7. 校验与异常
- 无效 profile 不能激活。
- 删除当前激活 profile 时必须回退到默认可用 profile。

## 8. 自动测试
- e2e：
  - 点击 profile 即激活。
  - 关闭重开设置后状态仍在。

## 9. 用户模拟测试
1. 切换到另一个 profile。
2. 关闭设置再重开。
3. 确认激活状态仍然正确。

- 审计状态：实现级文档已补齐。
