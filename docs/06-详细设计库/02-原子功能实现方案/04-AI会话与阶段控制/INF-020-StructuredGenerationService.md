# INF-020 StructuredGenerationService

## 1. 基本信息
- 类型：内部功能
- 所属层级：智能层 / 生成控制 / 结构化生成
- MSABC 分类：S
- 当前状态：部分完成

## 2. 责任与完成定义
1. 提供统一的文本生成和结构化生成入口。
2. 支持 schema 校验和失败修复。
3. 为阶段生成、审查和运行节点提供统一输出约束。

## 3. 核心接口
1. `generateText(input)`
2. `generateStructured(input, schema)`

## 4. 实现要求
1. 结构化生成优先尝试 JSON/schema 输出。
2. 失败时进入 Repair/Fallback pipeline。
3. 保存原始输出、修复输出和最终输出。

## 5. 自动测试
1. 合法 JSON 输出。
2. 非法 JSON 修复。
3. schema 不匹配失败。

## 6. 不允许的错误实现
1. 全部生成都退回纯文本，不做结构校验。
2. 修复后覆盖原始输出，导致无法审计。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：结构化生成已有服务层设计，但仍未覆盖所有关键生成路径。
