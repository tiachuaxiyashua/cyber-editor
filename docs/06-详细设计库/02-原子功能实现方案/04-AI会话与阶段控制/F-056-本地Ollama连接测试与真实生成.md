# F-056 本地 Ollama 连接测试与真实生成

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 模型配置 / 本地模型
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[设置与模型配置](../../01-UI详细设计/09-设置与模型配置.md)、[AI会话栏](../../01-UI详细设计/05-AI会话栏.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 用户可配置本地 Ollama 地址和模型名。
- 设置页可执行“连接测试”。
- 测试通过后，用户在真实会话中可以使用该模型完成生成，而不是只返回占位文本。

## 3. 页面入口与层级
- 页面：
  - `P4 设置与模型配置`
  - `P3 AI 会话栏`

## 4. 用户操作与系统反馈
1. 用户填写：
   - base URL
   - model，例如 `qwen3:8bm`
2. 点击 `连接测试`。
3. 测试成功显示模型可用。
4. 回到会话栏发送消息，运行记录中显示本次使用 Ollama 模型。

## 5. 数据与状态
- `ollamaBaseUrl`
- `ollamaModelName`
- `providerCapabilities`
- `lastConnectivityCheck`

## 6. 实现要求
### Renderer
- 连接测试结果需展示往返时间和能力标签摘要。

### Main / Service
- Provider adapter 负责真正发请求给 Ollama。
- 会话生成必须走真实模型调用，不能在 Ollama 路径里走 mock 或空实现。

## 7. 校验与异常
- 地址错误、模型不存在、超时、连接拒绝都必须给出区分后的错误信息。
- 当前状态为“部分完成”，表示已有真实链路，但稳定性和某些边界仍未完全收口。

## 8. 自动测试
- e2e：
  - 配置 Ollama。
  - 连接测试通过。
  - 发送消息有真实返回。
- 回归：
  - 超时/拒绝连接有正确提示。

## 9. 用户模拟测试
1. 在设置里配置 `qwen3:8bm`。
2. 执行连接测试。
3. 回到会话栏发送消息。
4. 确认收到真实输出而不是空响应。
