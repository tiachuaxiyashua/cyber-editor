# F-045 发送消息、停止生成与重试

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 对话输入 / 消息发送
- MSABC 分类：M
- 当前状态：部分完成
- 关联页面：[AI会话栏](../../01-UI详细设计/05-AI会话栏.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 输入区支持：
  - 发送消息
  - 停止当前生成
  - 对上一条失败运行重试
- 发送后必须立即出现用户消息占位和运行中状态。
- 停止后运行状态要变为“已停止”，而不是“失败”。

## 3. 页面入口与层级
- 页面：`P3 AI 会话栏`
- 主入口：
  - 输入框回车发送
  - 发送按钮
  - 运行中停止按钮
- 深层入口：
  - 失败消息卡中的 `重试`

## 4. 用户操作与系统反馈
1. 用户输入文本并发送。
2. 会话流立即追加：
   - 用户消息气泡/记录项
   - AI 运行中占位项
3. 生成过程中：
   - 输入区发送按钮切换成停止按钮。
   - 流程面板新增运行记录。
4. 点击停止：
   - 当前 AI 占位项变为“已停止”。
   - 保留已生成内容，不再继续追加。
5. 失败时：
   - 失败消息项显示 `重试`。
   - 点击重试后复用相同上下文再跑一次。

## 5. 数据与状态
- `messageDraft`
- `activeRunId`
- `runStatus`
- `lastFailedRunId`
- `streamedAssistantContent`

## 6. 实现要求
### Renderer
- 输入框在运行中默认仍允许编辑下一条草稿，但禁止再次发送直到当前运行结束或停止。
- 停止按钮必须替换发送按钮，不要同时显示两个主按钮。

### Main / Service
- RuntimeService 负责创建 `run`、写入事件流、处理停止信号。
- 停止生成必须是可中断请求，不允许仅在前端假装停掉。

## 7. 校验与异常
- 空消息不能发送。
- Provider 未就绪时发送按钮禁用并显示原因。
- 当前状态为“部分完成”，表示存在主链路，但停止/重试与事件流的一致性仍未完全收口。

## 8. 自动测试
- e2e：
  - 发送消息后出现运行中占位。
  - 运行中停止可中断。
  - 失败后点击重试可再次触发。
- unit：
  - run 状态机。

## 9. 用户模拟测试
1. 发一条普通消息。
2. 在生成中点击停止。
3. 再发一条消息并制造失败。
4. 点击重试，确认重新生成。
