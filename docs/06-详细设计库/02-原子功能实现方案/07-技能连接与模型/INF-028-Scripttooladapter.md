# INF-028 Script tool adapter

## 1. 基本信息
- 类型：内部能力
- 所属层级：连接层 / 工具 / 适配
- MSABC 分类：A
- 当前状态：部分完成
- 对应功能：
  - [F-082 工具资产管理](../05-编排与流程资产/F-082-工具资产管理.md)

## 2. 能力目标
- 把受控脚本工具统一包装成平台能力。

## 3. 输入输出
- 输入：脚本路径、参数 schema、超时、白名单目录
- 输出：结构化工具执行结果

## 4. 实现要求
- 不支持任意裸脚本无限制运行。
- 必须有参数校验、超时和工作目录边界。

## 5. 校验与异常
- 非白名单脚本阻断。
- 返回码异常转为结构化错误。

## 6. 自动测试
- unit：schema 校验、超时、路径边界。

## 7. 审计结论
- 审计状态：实现级文档已补齐，能力本身仍部分完成。
