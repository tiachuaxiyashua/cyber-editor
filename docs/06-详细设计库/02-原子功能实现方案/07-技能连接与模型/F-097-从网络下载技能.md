# F-097 从网络下载技能

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：技能、连接与模型 / 技能中心 / 安装
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[技能与连接中心](../../01-UI详细设计/08-技能与连接中心.md)
- 共享实现基线：[技能、连接与模型](README.md)

## 2. 完成定义
- 用户可从远程技能目录下载技能。
- 下载前必须看到来源、版本、校验状态和权限摘要。
- 安装后进入已安装列表并记录来源 URL。

## 3. 页面入口与层级
- 页面：`P1 技能与连接中心`
- 主入口：来源区 `远程目录`

## 4. 用户操作与系统反馈
1. 用户进入远程来源列表。
2. 点击某个技能。
3. 查看详情后点 `安装`。
4. 安装进度可见，完成后刷新列表。

## 5. 数据与状态
- `RemoteSkillCatalogItem`
- `downloadState`
- `checksumStatus`

## 6. 实现要求
- 下载链路必须支持校验和来源记录。
- 不允许静默安装。

## 7. 校验与异常
- 校验失败时阻断安装。
- 网络错误时保留重试入口。

## 8. 自动测试
- e2e：模拟远程目录、安装、失败重试。

## 9. 用户模拟测试
1. 选择一个远程技能。
2. 查看元数据和权限摘要。
3. 安装后确认已进入已安装列表。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍未完成。
