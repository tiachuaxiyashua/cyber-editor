# F-033 文本录入与删除

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 文档编辑 / 文本输入
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户能在编辑态与源码态录入、删除、换行、粘贴文本。
- 中文输入法、英文输入、选区删除、批量粘贴都必须正常。
- 文本修改后必须立即进入脏状态。
- 编辑器不能吞键、错位插入或在切换视图时丢内容。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 前置：当前标签切到 `编辑` 或 `源码`

## 4. 用户操作与系统反馈
1. 用户进入编辑态，点击正文任意位置。
2. 用户输入文本：
   - 光标后内容实时更新。
   - 文档标签出现脏状态圆点。
3. 用户按 `Backspace/Delete`：
   - 删除当前字符或选区。
4. 用户用输入法上屏：
   - 组合态不应被错误保存成中间态。
5. 用户切到阅读态再切回：
   - 未保存内容仍保留在编辑缓存中。

## 5. 数据与状态
- `draftContentByDocPath`
- `isDirtyByDocPath`
- `selectionStateByDocPath`
- 保存前仅在 renderer 持有草稿；保存后以主进程写盘为准。

## 6. 实现要求
### Renderer
- 编辑态使用结构化编辑器，源码态使用纯文本编辑器。
- 两者共享同一草稿源字符串。
- 输入法组合期间不得触发结构化变换或自动补全干预。

### Main / Service
- 不在每次按键时写盘。
- 仅在显式保存、自动保存或标签切换触发保存策略时走主进程。

## 7. 校验与异常
- 只要文档可编辑，就不能因为当前行包含 Mermaid/图块而阻断普通文本输入。
- 如果文档已变为只读态，应立即禁用编辑器并提示原因。
- 保存失败时，草稿内容必须保留。

## 8. 自动测试
- e2e：
  - 输入中文、英文、换行。
  - 删除选区。
  - 切换视图后草稿仍在。
- 回归：
  - 输入法组合期间不出现重复字符。
  - 长文档下输入不丢光标。

## 9. 用户模拟测试
1. 打开一个 Markdown 文档。
2. 输入三行中文与一行英文。
3. 删除中间一行。
4. 切阅读态再切回。
5. 确认剩余内容、换行和光标位置符合预期。

- 审计状态：实现级文档已补齐。
- 审计备注：该功能不允许被“自动保存成功”假象替代，保存失败时草稿保留是硬要求。
