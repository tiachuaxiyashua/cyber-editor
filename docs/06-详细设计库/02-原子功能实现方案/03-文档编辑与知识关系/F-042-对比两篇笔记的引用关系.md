# F-042 对比两篇笔记的引用关系

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 知识关系 / 对比
- MSABC 分类：B
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户能选择两篇笔记并查看：
  - 共同引用
  - 仅 A 引用
  - 仅 B 引用
  - 共同被引用来源
- 对比结果必须是结构化列表，不能只是两份列表并排堆放。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 当前文档关系面板中的“对比引用”
  - 第二篇文档标签右键 `与当前文档比较引用`

## 4. 用户操作与系统反馈
1. 用户先打开文档 A。
2. 选择 `对比引用`。
3. 系统要求选择文档 B。
4. 打开对比面板后，展示四个分区：
   - 共同引用
   - A 独有
   - B 独有
   - 共同来源
5. 点击任一项可跳转到目标文档。

## 5. 数据与状态
- `NoteReferenceComparison`
- `leftDocPath`
- `rightDocPath`
- `comparisonSections`

## 6. 实现要求
### Renderer
- 对比结果放在文档区辅助面板，不覆盖正文。
- 左右文档名称必须固定显示，避免用户忘记当前比较对象。

### Main / Service
- 使用主进程比较服务基于引用图计算，不在 renderer 拼接集合运算。

## 7. 校验与异常
- 不能拿同一篇文档和自己比较；选择时直接阻止。
- 任一文档失效时，对比面板退出并提示文档已不存在。

## 8. 自动测试
- unit：
  - 比较服务能正确输出共同/独有集合。
- e2e：
  - 选择两篇笔记后出现四分区结果。
  - 点击结果项可跳转。

## 9. 用户模拟测试
1. 打开两篇相关笔记。
2. 对比它们的引用关系。
3. 确认共同引用和独有引用分组正确。
4. 点击其中一个引用项确认跳转。
