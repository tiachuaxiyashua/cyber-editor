# F-036 Mermaid 插入与渲染

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 图文混排 / Mermaid
- MSABC 分类：S
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户可插入 ` ```mermaid ` 代码块。
- 阅读态必须把代码块渲染成流程图。
- 编辑态必须显示图预览与源码编辑切换，不允许只有纯文本。
- Mermaid 解析失败时显示错误提示卡，不得空白。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 斜杠命令：`Mermaid 图`
  - 图文插入工具菜单
- 深层入口：
  - 手写 ` ```mermaid `

## 4. 用户操作与系统反馈
1. 用户插入 Mermaid 块。
2. 编辑器写入默认模板：
   ```md
   ```mermaid
   flowchart TD
     A[开始] --> B[结束]
   ```
   ```
3. 阅读态显示渲染图。
4. 编辑态支持在块头切换：
   - `预览`
   - `源码`
5. 语法错误时：
   - 图预览区显示错误摘要。
   - 源码仍保留。

## 5. 数据与状态
- Mermaid 真源保存在 Markdown 文件中。
- 不单独保存图 JSON。

## 6. 实现要求
### Renderer
- Mermaid 预览区需有最小高度，避免空块坍塌。
- 预览失败时保留源码编辑能力。

### Main / Service
- 无独立 IPC。
- 渲染可在 renderer 完成。

## 7. 校验与异常
- 非 Mermaid 代码块不得误渲染。
- 大图溢出时容器横向滚动，不挤坏页面布局。

## 8. 自动测试
- e2e：
  - 插入 Mermaid 模板。
  - 阅读态渲染图可见。
  - 非法语法时错误卡可见。
- unit：
  - 解析失败分支。

## 9. 用户模拟测试
1. 插入 Mermaid 模板。
2. 改成三节点流程图。
3. 切阅读态确认图出现。
4. 故意删掉一行语法。
5. 确认出现错误卡但源码仍在。

- 审计状态：实现级文档已补齐。
