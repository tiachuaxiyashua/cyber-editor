# F-112 图形/表格工件超链接与嵌入

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 图文混排 / 链接与嵌入
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 文档可插入以下工件的链接或嵌入：
  - Mermaid 图
  - 思维导图
  - 图片
  - 表格工件
- 链接模式：点击后在当前工作台打开目标工件。
- 嵌入模式：在文档内显示预览块。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 斜杠命令：`插入工件链接`
  - 斜杠命令：`插入工件嵌入`
  - 资源选择器

## 4. 用户操作与系统反馈
1. 用户在文档中选择“插入工件链接”。
2. 资源选择器列出当前工程中可嵌入工件。
3. 用户选择模式：
   - `链接`
   - `嵌入`
4. 系统插入标准 Markdown/扩展语法。
5. 阅读态显示预览块或可点击链接。

## 5. 数据与状态
- 只在 Markdown 中保存相对路径与嵌入元标记。
- 不额外维护一份嵌入物副本。

## 6. 实现要求
### Renderer
- 嵌入块必须有统一卡片外观和类型图标。
- 点击嵌入块标题应打开原工件。

### Main / Service
- 路径解析和目标类型识别由共享 resolver 完成。

## 7. 校验与异常
- 目标文件不存在时显示失效嵌入块。
- 循环嵌入必须阻断，例如 A 文档嵌入 B，B 再嵌入 A 的同一视图链。

## 8. 自动测试
- e2e：
  - 插入表格链接。
  - 插入图片嵌入。
  - 阅读态打开目标工件。
- unit：
  - 路径解析与嵌入类型识别。

## 9. 用户模拟测试
1. 在 Markdown 文档里插入一个图片嵌入。
2. 再插入一个表格链接。
3. 切阅读态确认两者显示方式不同。
4. 点击表格链接确认打开表格查看器。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍未完成。
- 审计备注：不能把该功能降级成单纯插入普通文本链接，嵌入与链接是两个明确模式。
