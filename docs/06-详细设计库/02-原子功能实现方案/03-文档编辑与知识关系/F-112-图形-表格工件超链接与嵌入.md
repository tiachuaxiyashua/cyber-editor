## 3. 用户路径

链接模式：

1. 用户在 Markdown 源码视图点击“插入工件链接”。
2. 对话框列出当前工程文件。
3. 用户选择文件并填写显示标签。
4. 系统写入 wiki link 风格的稳定引用，例如 `[[table.csv|打开表格]]`。
5. 阅读态点击链接后调用 `window.api.openArtifact(href, documentPath)` 并在工作台打开目标工件。

嵌入模式：

1. 用户点击“插入工件嵌入”。
2. 选择目标文件。
3. 系统写入 Markdown 图片/嵌入语法。
4. 阅读态根据目标类型显示表格预览、图形预览、思维导图预览、文本摘要或图片。

## 4. 数据与语法

| 模式 | Markdown 表达 | 解析位置 | 展示 |
|---|---|---|---|
| 链接 | `[[target|label]]` 或普通本地链接 | `MarkdownContent` / `ProjectService.resolveArtifactPath` | `inline-artifact-link` |
| 嵌入 | 本地 `img` 目标 | `MarkdownContent.EmbeddedArtifact` | 类型化预览卡片 |
| 表格预览 | `.csv / .tsv / .xlsx` | `TableArtifactService.openArtifact` | 前 6 列、前 6 行预览 |
| 图形预览 | `.mmd / .mermaid` | `MermaidBlock` | Mermaid 渲染 |
| 思维导图预览 | `.mindmap / .markmap` | `MindMapBlock` | 层级导图 |

## 5. 异常与恢复

1. 目标文件不存在时返回 `unsupported` payload，并显示错误信息或不可预览状态。
2. 目标格式不支持时显示 unsupported，不允许伪造成功预览。
3. 相对路径必须以源文档为基准解析，再经过工程边界校验。
4. 嵌入预览失败时保留打开按钮，用户仍可尝试打开原工件。

## 8. 不允许的错误实现

1. 不允许只插入普通文本而没有可点击/可嵌入语义。
2. 不允许 Renderer 直接拼绝对路径绕过主进程解析。
3. 不允许嵌入块失败时显示空白。
4. 不允许复制目标工件形成第二份不可追踪副本。
