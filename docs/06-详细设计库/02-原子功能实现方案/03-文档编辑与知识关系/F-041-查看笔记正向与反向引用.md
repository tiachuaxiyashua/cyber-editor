# F-041 查看笔记正向与反向引用

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 知识关系 / 引用
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)、[AI会话栏](../../01-UI详细设计/05-AI会话栏.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 当前打开的 Markdown 文档必须能看到：
  - 它引用了哪些笔记（正向引用）
  - 哪些笔记引用了它（反向引用）
- 引用类型至少支持：
  - Markdown 相对链接
  - Wiki 链接 `[[note]]`
- 点击引用项必须能直接跳转到对应文档。

## 3. 页面入口与层级
- 页面：
  - `P2 文件树与文档区`
  - `P3 AI 会话栏上下文区`
- 主入口：
  - 文档头部关系入口
  - AI 会话栏 `引用文档` 区域

## 4. 用户操作与系统反馈
1. 用户打开某篇笔记。
2. 右侧上下文区显示：
   - `引用出去`
   - `被这些笔记引用`
3. 每个条目展示：
   - 文档名
   - 相对路径摘要
4. 点击某条引用：
   - 中央区打开目标文档。
   - 原文档仍保留在标签栏。

## 5. 数据与状态
- `NoteReferenceGraph`
- `outgoingRefsByDocPath`
- `incomingRefsByDocPath`
- 保存文档后必须刷新引用图快照。

## 6. 实现要求
### Renderer
- 引用列表默认显示前 `5` 项，超过后提供“展开更多”。
- 列表为空时显示明确空状态，不显示空白框。

### Main / Service
- 引用图由主进程索引服务计算。
- Renderer 不自行正则重算全工程引用关系。

## 7. 校验与异常
- 不存在的目标链接标为“失效引用”，点击时弹提示而不是报错。
- 当前文档未保存的新链接不应误显示为已生效引用，除非保存成功并刷新索引。

## 8. 自动测试
- unit：
  - Markdown 链接与 Wiki 链接索引正确。
- e2e：
  - 当前文档显示正反向引用。
  - 点击引用后跳转成功。
  - 失效引用样式正确。

## 9. 用户模拟测试
1. 打开两篇互相引用的笔记。
2. 在第一篇里查看正向和反向引用。
3. 点击反向引用，确认跳到第二篇。
4. 删除一个目标文件，回到第一篇确认显示失效引用提示。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：该功能必须以“当前文档为中心”展示，不能改成脱离上下文的独立关系页面。
