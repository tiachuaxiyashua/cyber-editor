# F-035 Markdown 结构化编辑

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 文档编辑 / 结构化
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 在编辑态支持以下结构化块的插入和修改：
  - 标题 `H1-H4`
  - 无序列表
  - 有序列表
  - 任务列表
  - 引用块
  - 代码块
  - 表格占位
  - Mermaid 块占位
  - 思维导图块占位
- 结构化操作通过斜杠命令和轻量工具条提供，不允许首屏堆满按钮。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 编辑器内输入 `/`
  - 选区浮动工具条
- 深层入口：
  - 命令面板：`插入标题`
  - 命令面板：`插入 Mermaid`

## 4. 用户操作与系统反馈
1. 用户在空行输入 `/`。
2. 弹出结构化命令菜单，按分类展示：
   - 文本结构
   - 图文块
   - 工件链接
3. 用户选择 `任务列表`：
   - 当前行转成 `- [ ] ` 格式。
4. 用户选择 `Mermaid`：
   - 插入标准代码块模板。
   - 光标定位到图定义区域。
5. 结构化块选中时，右侧 Inspector 显示块级属性（仅对支持的块）。

## 5. 数据与状态
- 真实源仍为 Markdown 文本。
- 结构化编辑器只负责把用户动作映射成 Markdown 语法。
- 块级元数据不允许单独脱离 Markdown 文件存储。

## 6. 实现要求
### Renderer
- 结构化命令菜单必须支持键盘上下选择和回车确认。
- 不允许引入与 Markdown 真源冲突的专有富文本格式。

### Main / Service
- 不需要独立 IPC。

## 7. 校验与异常
- 在代码块内输入 `/` 不弹结构化菜单。
- 当光标位于 Mermaid/思维导图代码块内部时，普通文本结构化操作应禁用或提示不可用。
- 当前状态为“部分完成”，表示已有部分结构化操作，但块级属性、斜杠命令完整度和表格入口仍未完全收口。

## 8. 自动测试
- e2e：
  - 斜杠菜单可打开。
  - 插入标题、任务列表、Mermaid 模板。
  - 块内容正确写入 Markdown。
- 回归：
  - 代码块内 `/` 不误触发。

## 9. 用户模拟测试
1. 在新文档输入 `/`。
2. 依次插入标题、任务列表、代码块。
3. 再插入 Mermaid 模板。
4. 切源码态确认 Markdown 语法正确。
