# F-034 复制/剪切/粘贴/撤销/重做

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 文档编辑 / 基础操作
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 支持标准快捷键：
  - `Ctrl+C`
  - `Ctrl+X`
  - `Ctrl+V`
  - `Ctrl+Z`
  - `Ctrl+Y` / `Ctrl+Shift+Z`
- 在编辑态和源码态都可用。
- 复制/剪切不能破坏 Markdown 结构。
- 粘贴纯文本与富文本时都应落成 Markdown 文本。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：快捷键
- 深层入口：右键菜单、编辑菜单、命令面板

## 4. 用户操作与系统反馈
1. 用户选中一段文本后复制：
   - 剪贴板写入文本内容。
2. 用户剪切：
   - 原文删除。
   - 文档变脏。
3. 用户粘贴：
   - 纯文本直接插入。
   - 富文本去样式后转 Markdown 文本。
4. 用户撤销/重做：
   - 内容按编辑历史回退/前进。
   - 视图切换不丢历史栈。

## 5. 数据与状态
- `undoStackByDocPath`
- `redoStackByDocPath`
- 编辑器本地状态为主；保存不清空撤销栈。

## 6. 实现要求
### Renderer
- 右键菜单必须根据当前选区和焦点启用/禁用相关项。
- 图像粘贴不走本功能，交给 [F-038 图片粘贴与拖拽导入](./F-038-图片粘贴与拖拽导入.md)。

### Main / Service
- 不需要主进程参与普通文本剪贴板逻辑。
- 若系统剪贴板不可用，应在通知区提示。

## 7. 校验与异常
- 无选区时禁用 `复制`、`剪切`。
- 撤销栈为空时禁用 `撤销`。
- 粘贴大块内容不能阻塞 UI；超过阈值时显示处理中提示。

## 8. 自动测试
- e2e：
  - 复制/剪切/粘贴后正文变化正确。
  - 连续撤销和重做恢复正确内容。
  - 右键菜单启用状态正确。
- 回归：
  - 在编辑态与源码态各跑一遍。

## 9. 用户模拟测试
1. 在正文中选中一段话并复制。
2. 移到下一行粘贴。
3. 剪切刚粘贴的文本。
4. 连续撤销两次，再重做两次。
5. 确认最终内容与预期一致。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：粘贴图片必须分流到资源导入链路，不能和普通文本粘贴混用。
