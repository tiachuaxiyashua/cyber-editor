# INF-049 Table artifact adapter

## 1. 基本信息
- 类型：内部功能
- 所属层级：壳层与文档底座 / 编辑器底座 / 表格
- MSABC 分类：A
- 当前状态：未完成

## 2. 功能目标
- 统一处理 CSV/TSV/XLSX 的读取、预览模型、保存和导出。

## 3. 具体实现方案
- 读入层：按扩展名选择解析器。
- 中间层：转换为统一 `TableArtifactModel`。
- 写回层：支持 CSV 和 XLSX。
- 视图层只消费统一模型，不直接消费原始格式。

## 4. 自动测试
- 单元：解析正确性、空值处理、列宽推断、回写一致性。
