# F-038 图片粘贴与拖拽导入

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 图文混排 / 图片
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户可通过 `Ctrl+V` 粘贴截图/图片。
- 用户可把本地图片拖进文档区。
- 系统必须把图片复制到工程资源目录，再插入相对路径 Markdown 图片语法。
- 不能直接引用系统临时路径。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 编辑器内粘贴
  - 文件拖拽到编辑区
- 深层入口：
  - 文件树右键 `导入图片`

## 4. 用户操作与系统反馈
1. 用户在编辑态粘贴截图。
2. 系统把图片保存到资源目录，例如 `assets/images/2026-04-09-001.png`。
3. 编辑器插入：
   ```md
   ![](../assets/images/2026-04-09-001.png)
   ```
4. 阅读态显示图片。
5. 导入失败时通知区提示错误原因。

## 5. 数据与状态
- 图片文件真实落盘。
- Markdown 中只保存相对路径。
- 资源目录策略由工程配置统一控制。

## 6. 实现要求
### Renderer
- 拖拽悬停时显示导入投放态。
- 粘贴图片不能被普通文本粘贴逻辑吞掉。

### Main / Service
- 主进程负责文件写入、命名冲突处理和路径返回。

## 7. 校验与异常
- 非图片拖拽交给普通文件导入链路，不在这里处理。
- 文件过大时提示压缩建议或导入失败原因。
- 同名冲突采用自动重命名，不覆盖已有资源。

## 8. 自动测试
- e2e：
  - 粘贴图片后 Markdown 中插入相对路径。
  - 拖拽图片导入成功。
  - 阅读态可见图片。
- unit：
  - 文件命名与冲突处理。

## 9. 用户模拟测试
1. 在文档中粘贴截图。
2. 保存文档。
3. 在文件树定位生成的资源文件。
4. 切阅读态确认图片显示。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：不能把图片导入做成“仅插入临时路径”，必须是工程内资源文件。
