## 2. 当前代码事实

当前主链路已经存在：

1. `src/main/services/table-artifact-service.ts`
   - 识别 `.csv / .tsv / .xlsx`。
   - 将表格统一转换为 `TableArtifactModel`。
   - 对 CSV/TSV 执行文本解析和写回。
   - 对 XLSX 使用 `exceljs` 读取与写回。
   - 对超过 5MB 的表格文件提前阻断，避免主进程解析超大文件。
2. `src/main/services/project-service.ts`
   - `openArtifact()` 统一解析相对路径与工程边界。
   - `saveArtifact()` 只允许表格工件写回，并记录快照、文档变更和审计日志。
3. `src/renderer/components/TableArtifactView.tsx`
   - 支持工作表切换、筛选、修改表头、修改单元格、新增列、新增行和删除行。
   - 只读模式下禁用编辑入口。
4. `src/renderer/App.tsx`
   - 文件树打开表格时进入表格视图。
   - 表格修改后通过 `artifact:save` 写回主进程。

## 3. 用户路径

1. 用户在文件树点击 `table.csv`、`table.tsv` 或 `table.xlsx`。
2. Renderer 调用 `window.api.openArtifact(filePath)`。
3. 主进程通过 `ProjectService.openArtifact()` 和 `TableArtifactService.openArtifact()` 返回统一 `ArtifactOpenPayload`。
4. 工作台中央区展示 `TableArtifactView`。
5. 用户修改单元格、列名、行列结构或筛选当前工作表。
6. 用户保存后，Renderer 调用 `window.api.saveArtifact(filePath, artifact)`。
7. 主进程写回源文件，生成快照、变更记录和审计记录，再返回最新工件模型。

## 4. 数据契约

核心对象为 `TableArtifactModel`：

| 字段 | 含义 | 来源 |
|---|---|---|
| `filePath` | 表格文件绝对路径 | `TableArtifactService.open()` |
| `title` | 显示标题，默认为文件名 | `fileTitle()` |
| `format` | `csv / tsv / xlsx` | 文件扩展名 |
| `activeSheetId` | 当前工作表 ID | 首个 sheet 或用户切换 |
| `sheets[]` | 统一工作表模型 | CSV/TSV 单 sheet，XLSX 多 sheet |
| `warnings[]` | 解析修复提示 | 行列数不一致等情况 |

`TableArtifactSheet` 至少包含：

| 字段 | 含义 |
|---|---|
| `id` | `${format}:${sheetName}` |
| `name` | 工作表名 |
| `columns[]` | 表头列 |
| `rows[][]` | 正文单元格，全部归一为字符串 |

## 5. 异常与安全

1. 不支持的格式返回 `unsupported`，不得进入可编辑表格。
2. 文件不存在时返回带 `errorMessage` 的 unsupported payload。
3. 超过大小上限的表格必须阻断解析。
4. CSV/TSV 行列数不一致时自动补空单元格，并在 `warnings` 中提示。
5. XLSX 作为二进制工件保存，不读取旧文本内容做 diff。
6. Renderer 不直接解析 XLSX 二进制。

## 6. 当前差距

1. 已有筛选、增删行列和单元格编辑，但还没有专门的大表虚拟滚动实现。
2. 脏状态依赖工作台层的 artifact 变更追踪，文档页尚未把“表格脏单元格集合”单独可视化。
3. 打包态专项表格旅程证据尚未在本页记录，因此状态保持为“部分完成”。

## 8. 不允许的错误实现

1. 不允许把表格工件降级为系统默认应用打开。
2. 不允许 Renderer 自行解析 XLSX。
3. 不允许保存时跳过快照、变更记录和审计记录。
4. 不允许把 CSV 行列不一致静默截断。
