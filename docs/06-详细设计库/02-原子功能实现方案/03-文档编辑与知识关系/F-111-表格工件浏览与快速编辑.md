# F-111 表格工件浏览与快速编辑

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 图文混排 / 表格
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 工作台可打开 `csv / tsv / xlsx` 表格工件。
- 表格默认进入“浏览态”，支持：
  - 固定表头
  - 行列滚动
  - 关键字过滤
- 支持轻量编辑：
  - 修改单元格
  - 新增/删除行
  - 自动标记脏状态
- 不要求替代 полноценный Excel，但必须满足“快速查看和轻量整理”。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 文件树直接打开表格工件
  - 文档中的表格工件链接点击打开

## 4. 用户操作与系统反馈
1. 用户打开 `table.csv`。
2. 中央区显示表格查看器，不是 Markdown 编辑器。
3. 用户双击单元格进入编辑。
4. 修改后标签页出现脏点。
5. 保存后写回原表格文件。

## 5. 数据与状态
- `TableArtifactModel`
  - `columns`
  - `rows`
  - `format`
  - `dirtyCells`
- `activeCell`
- `filterQuery`

## 6. 实现要求
### Renderer
- 统一表格查看器组件支持 CSV/TSV/XLSX。
- 大表格必须虚拟滚动，避免卡死。

### Main / Service
- 主进程负责文件解析与写回。
- Renderer 不直接解析 xlsx 二进制。

## 7. 校验与异常
- 只读模式下禁用编辑。
- xlsx 解析失败时显示“文件损坏或格式不支持”。
- 列数不一致的 CSV 必须给出导入修复提示。

## 8. 自动测试
- unit：
  - CSV/TSV/XLSX 解析与回写。
- e2e：
  - 打开表格。
  - 修改单元格并保存。
  - 重开确认内容持久化。

## 9. 用户模拟测试
1. 打开一个 CSV。
2. 查看表头是否固定。
3. 修改一个单元格、新增一行并保存。
4. 关闭再重开，确认改动存在。
