# INF-010 Image asset importer

## 1. 基本信息
- 类型：内部能力
- 所属层级：壳层与文档底座 / 资源管理 / 图片
- MSABC 分类：A
- 当前状态：已完成
- 对应功能：
  - [F-026 导入外部图片资源](../02-工程与文件/F-026-导入外部图片资源.md)
  - [F-038 图片粘贴与拖拽导入](./F-038-图片粘贴与拖拽导入.md)

## 2. 能力目标
- 统一处理图片导入、命名、冲突规避、相对路径回写。

## 3. 输入输出
- 输入：
  - 源图片文件/剪贴板图片
  - 目标工程路径
  - 资源目录策略
- 输出：
  - 最终落盘路径
  - 相对引用路径
  - 文件元数据

## 4. 实现要求
- 主进程执行文件写入。
- 支持按日期+递增序号命名。
- 同名冲突自动重命名，不覆盖旧资源。

## 5. 校验与异常
- 非图片 MIME 阻断。
- 超大文件返回明确错误码。

## 6. 自动测试
- unit：命名与路径计算。
- integration：剪贴板图、拖拽图、外部导入三条链路。
