# F-037 思维导图插入与渲染

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 图文混排 / 思维导图
- MSABC 分类：S
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../01-UI详细设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户可插入思维导图块。
- 阅读态显示可展开的思维导图。
- 编辑态保留源码编辑入口。
- 思维导图内容仍以 Markdown/Markmap 兼容语法保存在文档内。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 斜杠命令：`思维导图`
  - 图文插入工具菜单

## 4. 用户操作与系统反馈
1. 插入思维导图块后写入模板：
   ```md
   ```markmap
   # 主题
   ## 分支 A
   ## 分支 B
   ```
   ```
2. 阅读态展示导图。
3. 导图节点过多时允许局部缩放和拖动。
4. 源码错误时显示“导图解析失败”卡片。

## 5. 数据与状态
- 真源保存在 Markdown 文件。
- 不额外保存导图布局坐标。

## 6. 实现要求
### Renderer
- 导图容器高度默认不低于 `320px`。
- 缩放只作用于当前导图块。

### Main / Service
- 无独立 IPC。

## 7. 校验与异常
- 空块时不渲染空白画布，应显示空状态提示。
- 大导图必须容器内滚动。

## 8. 自动测试
- e2e：
  - 插入导图模板。
  - 阅读态渲染成功。
  - 错误语法显示失败卡。

## 9. 用户模拟测试
1. 插入思维导图。
2. 写三层节点。
3. 切阅读态确认导图显示。
4. 删除主节点标题，确认出现错误提示。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
- 审计备注：该功能与 Mermaid 一样，必须坚持“文本真源、阅读态渲染、编辑态源码可改”三项统一。
