# F-086 Flow 历史、快照与恢复

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 资产区 / 草稿生命周期
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)

## 2. 用户价值与完成定义
1. 用户需要回到某个稳定版本，而不是只靠撤销。

完成定义：
1. 保存后自动形成快照。
2. 可查看历史列表。
3. 可恢复到任一历史版本。

## 3. 自动测试
1. 连续保存形成多个快照
2. 恢复旧快照
3. 恢复后布局和资产一致

## 4. 不允许的错误实现
1. 历史只记标题不记内容。
2. 恢复后节点位置或边绑定丢失。
