# F-065 节点拖动与位置持久化

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 画布编辑 / 布局
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 用户手动排列节点就是在表达自己的理解结构。
2. 节点位置重置会直接破坏工作成果。

### 2.2 完成定义
1. 节点可被拖动。
2. 拖动后位置实时反馈。
3. 松手后位置写入草稿。
4. 切换资产、编辑 Inspector、保存并重开后位置仍在。

## 3. 具体实现方案
### 3.1 Renderer
1. 拖动中只更新本地草稿。
2. 拖动结束时提交最终位置。

### 3.2 Main / Service
1. `canvas-layout-state-store`
2. `flow-asset-persistence`

## 4. 校验与阻断
1. 普通非结构编辑不得重置位置。
2. 自动布局前必须要求确认或先生成快照。

## 5. 自动测试
1. 拖动节点后切换资产栏，位置不丢。
2. 保存并重开位置不丢。
3. Inspector 编辑后位置不丢。

## 6. 用户模拟测试
1. 把 3 个节点拖成三角布局。
2. 编辑其中一个节点配置。
3. 保存后重开，确认三角布局仍在。

## 7. 不允许的错误实现
1. 位置只在 React 内存里。
2. 切换节点或切换资产就重置位置。
3. 保存时只保存节点结构，不保存位置。

## 8. 当前审计结论
- 审计状态：部分完成
- 审计说明：位置持久化已有局部实现，但仍缺“任何普通编辑都不重置布局”的系统保证。
