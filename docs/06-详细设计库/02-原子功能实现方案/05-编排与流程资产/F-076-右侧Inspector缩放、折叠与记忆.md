# F-076 右侧 Inspector 缩放、折叠与记忆

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 布局 / 右侧面板
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. Inspector 是深层配置区，必须可伸缩，否则会过度挤压画布。
2. 专业用户会频繁开关 Inspector，因此它的行为必须稳定且可记忆。

### 2.2 完成定义
1. Inspector 可拖拽调整宽度。
2. Inspector 可折叠和展开。
3. 切换节点、切换 Flow、切换设计态/运行态后，宽度和折叠状态按规则保持。
4. 折叠后画布和左侧面板重新分配空间，不发生重叠。

## 3. 页面入口与层级
1. 入口页面：编排页
2. 操作对象：
   - 右侧分隔条
   - Inspector 折叠按钮
3. 所在层级：`P1 编排页 -> P2 Inspector`

## 4. 用户操作流程
1. 用户选中任意节点，Inspector 展开。
2. 用户拖动右侧分隔条修改宽度。
3. 用户切换不同节点，宽度保持不变。
4. 用户折叠 Inspector，再展开，恢复上次宽度。

## 5. 可见效果与状态
1. Inspector 默认宽度应在 `320px-380px`。
2. 最小宽度固定为 `300px`，保证中文字段和表单不堆叠。
3. 折叠态仅保留展开入口和必要状态提示。
4. 运行态可使用更窄的只读 Inspector，但设计态不得自动压缩到不可编辑。

## 6. 数据模型
```json
{
  "inspector": {
    "width": 360,
    "collapsed": false,
    "lastExpandedWidth": 360
  }
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `ResizableInspector`
2. `InspectorResizeHandle`
3. `InspectorCollapseToggle`

Renderer 责任：
1. 在选中对象切换时保持宽度状态。
2. 切换设计态/运行态时沿用当前宽度，但允许按模式切换内容结构。

### 7.2 Main / Service
服务：
1. `settings-layout-persistence`
2. `ui-responsive-layout-engine`

Main 责任：
1. 持久化 Inspector 布局状态。
2. 对极端窗口宽度提供恢复保护。

## 8. 校验与阻断
1. 不允许把 Inspector 压缩到表单完全错位。
2. 切换节点时不允许因为内容不同而重置宽度。
3. 运行态只读模式不得覆盖用户手动设置的设计态宽度。

## 9. 自动测试
### 9.1 单元
1. 最小宽度约束
2. 折叠/展开状态机
3. 设计态与运行态下的记忆规则

### 9.2 端到端
1. 拖动 Inspector 宽度。
2. 切换多个节点确认宽度稳定。
3. 折叠再展开确认恢复。
4. 切换设计态/运行态确认宽度不重置。

## 10. 用户模拟测试
1. 选中一个节点并把 Inspector 拖宽。
2. 切换到另一个节点，确认宽度不变。
3. 折叠 Inspector，再展开确认恢复。
4. 切换到运行态再回设计态，确认宽度仍在。

## 11. 不允许的错误实现
1. Inspector 只靠 `display:none` 临时隐藏，没有持久状态。
2. 每次切换节点就重置宽度。
3. 宽度过窄导致字段竖排堆叠。

## 12. 当前审计结论
- 审计状态：未完成
- 审计说明：Inspector 仍缺少稳定的尺寸记忆、模式切换规则和窄宽度保护。
