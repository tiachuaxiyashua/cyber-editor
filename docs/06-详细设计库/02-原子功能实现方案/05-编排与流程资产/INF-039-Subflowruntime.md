# INF-039 Subflow runtime

## 1. 基本信息
- 类型：内部功能
- 所属层级：编排层 / 流程语义 / 子流程
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：编排页、运行态
- 共享实现基线：[编排与流程资产](README.md)

## 2. 责任与完成定义
### 2.1 服务责任
1. 执行子流程节点。
2. 把父 Flow 上下文传给子流程。
3. 接收子流程输出返回父 Flow。

### 2.2 完成定义
1. 子流程节点绑定的目标 Flow 能被真正执行。
2. 父子流程之间可传递输入工件、消息和信号。
3. 子流程失败时可定位到父 Flow 中的节点。

## 3. 核心接口
1. `runSubflow(subflowNodeId, parentRuntimeContext)`
2. `mapParentToSubflowInputs(bindingConfig)`
3. `mapSubflowOutputsToParent(bindingConfig)`

## 4. 实现要求
1. 子流程不能只是 UI 跳转，必须有真实运行语义。
2. 父子流程边界必须显式配置输入输出映射。
3. 子流程运行记录要能回到父 Flow 查看。

## 5. 自动测试
### 5.1 单元
1. 输入映射
2. 输出映射
3. 错误回溯

### 5.2 集成
1. 父 Flow 调用红蓝审查子流程
2. 子流程输出写回父 Flow

## 6. 不允许的错误实现
1. 子流程只是“打开另一个页面”。
2. 父子流程之间没有显式输入输出映射。
3. 子流程失败后父 Flow 无法定位错误节点。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：子流程仍缺真实执行、映射和错误回溯的主链路。
