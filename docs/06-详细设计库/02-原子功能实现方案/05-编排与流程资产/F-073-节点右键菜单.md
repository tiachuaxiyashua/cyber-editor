# F-073 节点右键菜单

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 对象交互 / 右键
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)
- 上游需求：`D-C2`、`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 高手用户需要在不离开画布的情况下完成低频但关键的对象操作。
2. 节点卡片上的常用按钮只能承载高频动作，剩余动作必须有稳定且一致的右键入口。
3. 右键菜单是专业编排器的基本交互，不具备会显著降低效率。

### 2.2 完成定义
1. 右键任意节点时，光标附近弹出节点上下文菜单。
2. 菜单项按固定分组展示，顺序不能漂移。
3. 菜单内容会根据节点类型变化，但公共动作保持一致。
4. 选择菜单项后，动作必须立即作用在当前节点，不允许跳错对象。
5. 菜单关闭后，节点选中状态保持不丢失。

## 3. 页面入口与层级
1. 入口页面：编排页设计态
2. 入口动作：鼠标右键单击节点
3. 所在层级：`P1 编排页 -> P2 画布对象层 -> P3 上下文菜单`

## 4. 用户操作流程
1. 用户在画布中右键一个节点。
2. 系统先将该节点设为当前选中节点。
3. 系统在鼠标位置弹出菜单。
4. 用户选择一个动作。
5. 系统执行动作，并在需要时：
   - 打开 Inspector 指向对应配置区
   - 打开子流程
   - 复制节点
   - 删除节点
   - 显示节点 ID 或调试信息

## 5. 菜单结构与可见效果
### 5.1 公共菜单分组
1. 对象操作
   - 复制节点
   - 复制节点 ID
   - 删除节点
2. 画布定位
   - 聚焦到节点
   - 查看上游
   - 查看下游
3. 编辑与调试
   - 打开 Inspector
   - 从此节点继续运行
   - 查看最近一次运行结果

### 5.2 节点类型专属项
1. 子流程节点
   - 打开子流程
   - 替换目标子流程
2. 角色节点
   - 打开角色详情
   - 替换角色包
3. 条件/循环/并行节点
   - 打开控制规则
4. 工具节点
   - 测试工具绑定

### 5.3 视觉规则
1. 菜单宽度固定为 `240px` 左右，不能跟随文字宽度剧烈跳动。
2. 危险动作单独放在底部分组，并使用危险色图标。
3. 不允许把菜单做成全屏覆盖层或大型侧板。

## 6. 数据模型
```json
{
  "targetNodeId": "node_review_red_001",
  "targetNodeType": "role",
  "menuSections": [
    { "id": "object", "items": ["duplicate", "copy_id", "delete"] },
    { "id": "focus", "items": ["focus", "show_upstream", "show_downstream"] },
    { "id": "runtime", "items": ["open_inspector", "run_from_here", "show_last_run"] }
  ]
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `NodeContextMenu`
2. `NodeContextMenuSection`
3. `NodeContextMenuTrigger`

Renderer 责任：
1. 在右键前先同步当前选中节点。
2. 根据节点类型生成菜单项。
3. 保证菜单定位在可视区域内，不越出窗口边缘。
4. 菜单关闭时恢复焦点给画布。

### 7.2 Main / Service
服务：
1. `flow-asset-persistence`
2. `runtime-service`

Main 责任：
1. 执行会影响 Flow 结构或运行状态的动作。
2. 处理复制、删除、从此继续等动作的真正数据变更。

### 7.3 IPC 契约
```ts
type NodeContextAction =
  | { type: 'duplicate-node'; flowId: string; nodeId: string }
  | { type: 'delete-node'; flowId: string; nodeId: string }
  | { type: 'run-from-node'; flowId: string; nodeId: string }
  | { type: 'open-subflow'; flowId: string; nodeId: string };
```

## 8. 校验与阻断
1. 如果节点不可删除，例如唯一开始节点，菜单中“删除”必须禁用并带原因说明。
2. `run-from-node` 仅在运行态支持并具备调试前提时可用。
3. 子流程节点未绑定目标时，“打开子流程”禁用，显示“未绑定子流程”。
4. 菜单动作失败后必须保留原节点选中态和原画布位置。

## 9. 自动测试
### 9.1 单元
1. 节点类型到菜单项的映射
2. 禁用规则映射
3. 菜单边缘定位修正

### 9.2 端到端
1. 右键角色节点，验证菜单弹出与分组正确。
2. 选择“复制节点”，确认节点复制且位置偏移固定。
3. 右键子流程节点，选择“打开子流程”，确认进入子流程编辑。
4. 右键开始节点，确认“删除节点”禁用。

## 10. 用户模拟测试
1. 打开编排页并选中一个普通角色节点。
2. 右键打开菜单，确认能看到复制、删除、打开 Inspector。
3. 点击复制节点，确认新节点被创建。
4. 对子流程节点右键，确认可直接进入子流程。
5. 对开始节点右键，确认危险动作被禁用而非静默消失。

## 11. 不允许的错误实现
1. 右键菜单和节点对象脱钩，点错节点也能触发上一次节点的动作。
2. 右键菜单承载高频动作，导致卡片本身过空。
3. 菜单打开时把整个页面遮住。
4. 菜单动作只改 UI，不改真正 Flow 数据。

## 12. 当前审计结论

- 审计说明：当前右键菜单仍缺少稳定分组、类型专属项和真实动作闭环。
