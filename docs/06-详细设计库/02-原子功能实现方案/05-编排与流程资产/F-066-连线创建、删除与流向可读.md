# F-066 连线创建、删除与流向可读

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 画布编辑 / 连线
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 如果画布上看不出流向，流程编辑器就退化成摆卡片工具。
2. 连线的创建、删除和箭头方向必须明确。

### 2.2 完成定义
1. 用户可从节点输出端拖出连线。
2. 连到目标节点输入端后创建边。
3. 边可选中、删除、查看配置。
4. 箭头和视觉样式让流向一眼可读。

## 3. 具体实现方案
### 3.1 Renderer
1. 节点显式输出端和输入端。
2. 边选中后显示高亮和删除入口。
3. 边类型根据语义显示：
   - 普通
   - 并行域
   - 条件
   - 错误

### 3.2 Main / Service
1. `flow-validation-engine`
2. `node-io-contract-service`

## 4. 校验与阻断
1. 不允许自环到不支持的节点。
2. 不允许一条边连接到不存在端口。
3. 不允许边删除后留下非法结构而不提示。

## 5. 自动测试
1. 创建一条普通边。
2. 删除边。
3. 条件边和普通边的视觉区分。

## 6. 用户模拟测试
1. 从角色节点连到工具节点。
2. 选中边并打开边配置。
3. 删除边，确认结构变化和校验提示。

## 7. 不允许的错误实现
1. 没有箭头方向。
2. 只能程序内置边，用户不能交互创建。
3. 删除边后画布和数据不同步。

## 8. 当前审计结论
- 审计状态：部分完成
- 审计说明：连线能力仍缺端口级语义和删除后的结构校验闭环。
