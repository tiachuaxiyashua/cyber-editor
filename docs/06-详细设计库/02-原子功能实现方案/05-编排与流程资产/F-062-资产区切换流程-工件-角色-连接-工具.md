# F-062 资产区切换流程/工件/角色/连接/工具

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 资产栏 / 切换
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../01-UI详细设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 资产栏是编排页的“对象导航器”，必须清楚区分流程、工件、角色、连接、工具。
2. 切换资产类型不能影响画布布局和当前节点选中。

### 2.2 完成定义
1. 资产栏支持切换：
   - Flow/Subflow
   - 工件
   - 角色
   - 连接
   - 工具
2. 每个分组都有独立列表和详情。
3. 切换分组不重置画布位置和节点布局。

## 3. 页面入口与层级
1. 入口页面：编排页左侧资产栏
2. 层级：`P1 编排页 -> P2 左侧资产栏`

## 4. 用户操作流程
1. 用户点击某个资产分组图标或标签。
2. 左侧列表切换到对应资产类型。
3. 右侧详情区显示该资产类型的当前对象详情。
4. 画布保持当前视图和选中状态。

## 5. 可见效果与状态
1. 当前激活资产分组必须高亮。
2. 不同资产类型列表项字段不同，但列表骨架一致。
3. 资产为空时显示对象级空状态，而不是全页空白。

## 6. 数据模型
```json
{
  "activeAssetTab": "roles",
  "selectedAssetId": "role_red_reviewer"
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `AssetTabBar`
2. `AssetListPanel`
3. `AssetEmptyState`

Renderer 责任：
1. 保存当前激活资产分组。
2. 切换分组时不触碰画布状态。
3. 为每类资产显示统一的列表壳层。

### 7.2 Main / Service
服务：
1. `flow-asset-persistence`
2. `artifact-catalog-service`
3. `connector-registry`
4. `capability-registry`

## 8. 校验与阻断
1. 资产分组切换不允许引起节点位置或选中状态重置。
2. 空状态必须提供该分组的创建入口。

## 9. 自动测试
### 9.1 端到端
1. 在不同资产分组间来回切换。
2. 验证画布保持不变。
3. 在空状态下创建对应资产。

## 10. 用户模拟测试
1. 先拖几个节点到画布。
2. 依次切换流程、角色、连接、工具。
3. 确认画布不重置、选中节点不丢。

## 11. 不允许的错误实现
1. 切换资产类型就触发整页重置。
2. 不同资产类型各用一套完全不同的入口样式。
3. 空状态没有对象级创建入口。

## 12. 当前审计结论
- 审计状态：部分完成
- 审计说明：资产栏当前仍缺对象导航器级别的稳定性和空状态语义。
