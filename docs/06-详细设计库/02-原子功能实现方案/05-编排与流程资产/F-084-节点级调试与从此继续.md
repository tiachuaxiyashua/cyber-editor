# F-084 节点级调试与从此继续

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 运行与调试 / 调试
- MSABC 分类：S
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
1. 用户必须能单步验证节点，而不是每次整条 Flow 全跑。
2. “从此继续”必须让用户看清会复用什么、重置什么。

完成定义：
1. 节点上存在 `运行当前节点` 与 `从此继续`。
2. 运行后可查看输入、输出、消息、信号。
3. 从此继续前显示影响范围。

## 3. 用户操作流程
1. 选中一个节点。
2. 点击 `运行当前节点`。
3. 查看运行结果。
4. 点击 `从此继续`。
5. 确认影响范围后继续。

## 4. 可见效果与状态
1. 运行中：节点显示活动态
2. 成功：显示最近输出摘要
3. 失败：显示错误和重试入口

## 5. 具体实现方案
### Renderer
1. `NodeRunToolbar`
2. `NodeRunResultPanel`
3. `ResumeImpactDialog`

### Main / Service
1. `node-debug-engine`
2. `runtime-run-store`
3. `artifact-catalog-service`

## 6. 校验与阻断
1. 节点依赖缺失时阻止运行。
2. 从此继续前必须校验上游结果是否可复用。

## 7. 自动测试
1. 运行单节点
2. 查看单节点输出
3. 从失败点继续

## 8. 不允许的错误实现
1. “从此继续”只是重新跑全流程。
2. 调试运行结果不可见。
