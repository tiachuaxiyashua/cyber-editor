# F-078 多角色定义与切换

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 角色 / 管理
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`、`D-C3`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 同一条 Flow 往往需要多个 Agent 角色，不能只支持单角色思维。
2. 角色必须被看作 Flow 资产，而不是零散挂在节点上的一段 prompt。
3. 用户需要明确知道每个角色负责什么、服务谁、拥有哪些技能和权限。

### 2.2 完成定义
1. Flow 资产区支持展示多个角色。
2. 角色列表支持创建、导入、复制、重命名、删除、切换查看。
3. 角色切换不会影响当前画布布局和选中节点。
4. 节点可绑定 Flow 中任一角色。
5. 角色详情区可以看到身份、人格、协作规则、用户画像、技能、记忆摘要。

## 3. 页面入口与层级
1. 入口页面：编排页设计态
2. 入口区域：左侧资产栏 `角色`
3. 层级：`P1 编排页 -> P2 资产栏角色列表 -> P3 右侧角色 Inspector`

## 4. 用户操作流程
1. 用户切换到左侧资产栏的“角色”分组。
2. 查看当前 Flow 已挂载的角色列表。
3. 点击某个角色查看详情。
4. 可执行：
   - 新建角色
   - 导入角色包
   - 复制角色
   - 删除角色
5. 在节点 Inspector 中切换绑定角色，立即看到当前节点绑定结果。

## 5. 可见效果与状态
1. 角色列表项固定显示：
   - 角色名称
   - 角色标签/职责
   - 技能数量
   - 绑定节点数量
2. 当前角色详情显示为分页或分区：
   - 身份
   - 原则
   - 协作
   - 用户画像
   - 技能
   - 记忆
3. 角色被节点占用时，删除动作必须先弹出影响说明。

## 6. 数据模型
```json
{
  "roleId": "role_red_reviewer",
  "name": "红军审查员",
  "packagePath": ".roles/red-reviewer",
  "summary": "负责攻击方案漏洞与遗漏",
  "boundNodeCount": 3,
  "defaultSkills": ["requirements-review"],
  "memorySummary": "偏好找基础设施缺口"
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `RoleAssetList`
2. `RoleAssetRow`
3. `RoleDetailTabs`
4. `RoleCreateDialog`

Renderer 责任：
1. 管理角色列表的选中态。
2. 切换角色时不重置画布视图。
3. 在角色详情区按固定顺序展示角色包信息。

### 7.2 Main / Service
服务：
1. `flow-asset-persistence`
2. `role-package-loader`

Main 责任：
1. 创建和删除 Flow 内的角色引用。
2. 复制角色时生成新的角色资产 ID。
3. 删除角色前检查被哪些节点引用。

### 7.3 IPC 契约
```ts
type FlowRoleSummary = {
  roleId: string;
  packagePath: string;
  name: string;
  summary: string;
  boundNodeCount: number;
};
```

## 8. 校验与阻断
1. 不允许两个角色使用相同 `roleId`。
2. 已被节点引用的角色删除前必须要求用户二次确认。
3. 角色包缺失关键文件时，角色列表显示损坏态，不允许绑定到节点。

## 9. 自动测试
### 9.1 单元
1. 角色列表排序与计数
2. 删除前引用检查
3. 复制角色 ID 重写

### 9.2 端到端
1. 创建两个角色并切换查看详情。
2. 将不同节点绑定到不同角色。
3. 删除被引用角色时确认阻断提示正确。

## 10. 用户模拟测试
1. 打开编排页角色资产区。
2. 新建一个“作者”和一个“审校”角色。
3. 切换两个角色，确认详情区内容同步切换。
4. 把某个节点绑定到“作者”角色。
5. 尝试删除“作者”，确认系统提示其被节点引用。

## 11. 不允许的错误实现
1. 角色只是节点上的下拉选项，没有独立资产列表。
2. 角色切换会重置画布。
3. 角色详情只显示名称，不显示包内设定。
4. 删除角色不检查节点引用。

## 12. 当前审计结论
- 审计状态：部分完成
- 审计说明：当前多角色管理仍缺资产级列表、详情分页和引用阻断闭环。
