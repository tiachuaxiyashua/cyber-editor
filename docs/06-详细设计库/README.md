# 06 详细设计库

本目录只承接不能塞进 PRD、产品设计、架构总册和测试总册里的实现级细节。它不是第二套需求库，也不是测试口径目录。

## 使用顺序

1. 先读 `docs/README.md`。
2. 先按 `01-需求与PRD/`、`02-产品设计/`、`03-架构实现/`、`04-测试验收/` 判断当前能力的裁决口径。
3. 再进入本目录查实现级细节。
4. 如果本目录与当前 PRD、关键交互、架构或测试口径冲突，必须迁移或改写细节，不能继续把过时细节当真相源。

## 当前内容

1. UI 详细设计与低保真线框。
2. 原子功能实现方案与 INF 内部能力设计。
3. 代码契约、状态机、时序、错误与恢复规则。
4. 程序员向模块开发设计与组件拆分设计。
5. 参考分析报告与模板来源研究。

## 目录说明

| 路径 | 说明 |
|---|---|
| `01-UI详细设计/` | 页面级细节、跳转图、低保真线框、页面动作说明 |
| `02-原子功能实现方案/` | F/INF 原子能力实现方案 |
| `03-代码契约与唯一性/` | 契约、状态机、时序、错误与恢复约束 |
| `04-模块开发设计/` | 程序员向模块开发设计和组件拆分设计 |
| `05-参考分析报告/` | 外部工程分析、模板提取与参考研究 |

## 后续整理规则

1. 合并同主题文档时，先把细节迁移到当前设计文件或本目录对应位置。
2. 只有确认细节已经迁移，才允许删除重复或过时表述。
3. 不允许用“文档简洁”作为删除实现细节的理由。
4. 不允许让本目录重新变成多套真相源；裁决仍看 PRD、关键设计、架构总册和测试总册。
