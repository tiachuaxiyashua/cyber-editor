# 06 详细设计库

本目录保存从旧文档恢复并继续保留的详细材料，包括原始需求、UI 页面说明、原子功能实现方案和评审输入。这里不是废弃区，也不是历史垃圾桶；它是实现细节库。

## 使用顺序

1. 先读 `docs/README.md`。
2. 先按 `01-需求与PRD/`、`02-产品设计/`、`03-架构实现/`、`04-测试验收/` 判断当前方向。
3. 再进入本目录查详细实现细节。
4. 如果本目录与当前 PRD 或关键交互裁决冲突，以当前 PRD 和裁决为准，但不能删除细节；必须迁移、改写或标注冲突。

## 当前内容

本目录当前恢复了旧文档基线和额外评审输入，覆盖：

1. 早期行动路线、需求、功能树、功能清单。
2. UI 页面详细说明。
3. 功能具体实现方案。
4. 评审输入。

## 后续整理规则

1. 合并同主题文档时，先把细节迁移到当前设计文件或本目录对应位置。
2. 只有确认细节已经迁移，才允许删除重复或过时表述。
3. 不允许用“文档简洁”作为删除实现细节的理由。
4. 不允许让本目录重新变成多个真相源；它提供细节，裁决仍看 PRD 和关键设计文件。
