# 52 缺失关键时序补充

## 1. 模板安装 / 更新 / 修复
1. 用户进入模板中心
2. 点击安装或更新
3. Renderer 调 `template.installFromDirectory` / `template.installFromRemote`
4. Main 创建临时目录并拉取资源
5. 校验 manifest / package / compatibility
6. 成功则原子替换模板目录
7. 失败则删除临时目录并返回错误码
8. Renderer 刷新模板列表并显示结果

## 2. 阶段确认
1. 用户点击阶段确认
2. Renderer 读取当前 `StageGuardStatus`
3. 若存在 blocker，阻断并在流程面板列出 blocker
4. 若通过，调用 `stage.confirm`
5. Main 写入阶段确认记录与时间戳
6. 若该阶段有导出或快照动作，先写临时对象再提交
7. UI 更新阶段 chip 和进度

## 3. 审查子流程
1. 用户点击 `运行审查子流程`
2. Main 读取蓝军、红军、裁判节点与工件绑定
3. 依次运行蓝军 -> 红军 -> 裁判
4. 裁判输出 blocker / warning / pass
5. 若 blocker > 0，流程面板进入 `blocked`
6. 若通过，允许下游阶段继续

## 4. Flow 运行
1. 用户点击运行
2. Main 校验 `flowDraft`、输入目录、输出目录、stage contract
3. 创建 `run` 与快照
4. 按拓扑顺序调度节点
5. 节点输出写入临时工件
6. 节点成功后提交工件并广播事件
7. 失败则进入错误恢复或停止
8. 全部成功后刷新工件目录与运行摘要

## 5. AI 消息到工件落盘
1. 用户发送消息
2. Main 生成结构化或文本结果
3. 若目标为正式工件，先走 schema/guard 校验
4. 写入临时文件
5. 校验通过后替换正式文件
6. Renderer 刷新活动文档和引用关系

## 6. 导出交付包
1. 用户点击导出
2. Main 读取 `ExportMapping`
3. 校验所有 required artifacts 已提交且非 stale
4. 创建 `<project>/exports/<timestamp>/`
5. 生成 `md/txt/pdf/openspec`
6. 写 `export-manifest.json`
7. 返回导出结果与输出目录

## 7. 从此继续 / 局部重跑
1. 用户在运行抽屉选择节点
2. Renderer 调 `runtime.runFromNode`
3. Main 读取最近成功快照
4. 标记下游受影响节点 `stale`
5. 重跑目标节点及受影响下游
6. 成功后清空对应 stale 状态

## 8. 快照恢复
1. 用户打开快照列表
2. 选择快照并点击恢复
3. Main 校验快照完整性与版本
4. 若冲突，弹出恢复冲突选择
5. 恢复成功后重建 `flowDraft`、`ui.json`、`contracts`
6. Renderer 重新加载画布和 Inspector
