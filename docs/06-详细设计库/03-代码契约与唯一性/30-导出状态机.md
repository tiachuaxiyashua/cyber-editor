# 30 导出状态机

## 1. 目标
固定文档与工件导出流程的状态，防止不同实现把导出做成一次性黑盒。

## 2. 状态集合
- `export_idle`
- `export_validating`
- `export_blocked`
- `export_running`
- `export_writing`
- `export_completed`
- `export_failed`

## 3. 跃迁
1. `export_idle -> export_validating`
   - 用户点击导出
2. `export_validating -> export_blocked`
   - 条件：输出目录缺失、工件不完整、导出映射非法
3. `export_validating -> export_running`
   - 条件：校验通过
4. `export_running -> export_writing`
   - 条件：开始写文件
5. `export_writing -> export_completed`
   - 条件：全部目标文件写入成功
6. `export_running|export_writing -> export_failed`
   - 条件：中途任一写入失败且无法恢复

## 4. 导出种类
- `markdown_export`
- `text_export`
- `pdf_export`
- `openspec_export`

## 5. 约束
1. 导出前必须经过校验，不允许直接写盘。
2. 导出失败不得覆盖已存在的有效目录结构。
3. `openspec_export` 必须校验 proposal/design/tasks/specs 目录结构。

## 6. UI 约束
1. 导出开始后显示进度。
2. 被阻断时显示阻断原因与修复入口。
3. 导出成功后显示打开目录动作。

## 7. 测试 Oracle
1. 输出目录不存在时必须进入 `export_blocked`。
2. 写盘失败时必须进入 `export_failed`。
3. 导出成功后目标目录和文件必须可见。
