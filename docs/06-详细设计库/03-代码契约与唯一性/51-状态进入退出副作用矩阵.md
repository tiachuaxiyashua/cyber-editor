# 51 状态进入退出副作用矩阵

## 1. 目标
把复杂状态机补到“进入条件 / 退出条件 / 副作用 / UI 禁用 / 错误入口 / 恢复入口”级别。

## 2. 编排层
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| FlowDraft | `clean` | 打开已保存 Flow 或刚保存成功 | 任一结构变更 | 清空 `saveError` | 无 | 无 | 无 |
| FlowDraft | `dirty` | 节点/边/契约/导出映射被编辑 | 保存成功 / 放弃修改 | 标记 `dirty=true` | 禁止切到 run 态（若 validation 不通过） | `FLOW_SAVE_REQUIRED` | 保存或放弃 |
| FlowDraft | `invalid` | 结构/契约校验失败 | 错误字段被修正 | 生成 `validation.errors` | 禁止运行 / 禁止阶段确认 | `FLOW_VALIDATION_FAILED` | Inspector 修正 |
| FlowDraft | `saving` | 点击保存且本地校验通过 | 保存成功 / 失败 | 写临时目录 | 禁止重复保存、禁止切换 Flow | `FLOW_SAVE_FAILED` | 重试保存 |
| FlowDraft | `stale` | 上游节点 IO/契约变化影响下游 | 局部重跑或重新确认 | 标记受影响节点 | 禁止把 stale 结果当作有效产物导出 | `FLOW_RESULT_STALE` | 局部重跑 |

## 3. AI 运行时
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| 会话运行 | `idle` | 首次进入或运行结束 | 发送消息 / 生成草稿 | 无 | 无 | 无 | 无 |
| 会话运行 | `submitting` | 发送消息或请求结构化生成 | 获得响应 / 超时 / 失败 | 写 `runAccepted` | 禁止再次发送同类请求 | `AI_REQUEST_FAILED` | 重试 |
| 会话运行 | `repairing` | 首次结构化解析失败 | repair 成功 / 失败 | 写 repair 事件 | 禁止阶段确认 | `AI_REPAIR_FAILED` | 重试或切 provider |
| 会话运行 | `awaiting_confirm` | 结果生成完但需用户确认 | 用户确认/拒绝 | 缓存 pending result | 禁止自动写正式工件 | `AI_CONFIRMATION_MISSING` | 确认或拒绝 |

## 4. 模板与安装
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| 模板安装 | `installing` | 发起目录/远程安装 | 成功 / 失败 | 创建临时目录 | 禁止二次安装同模板 | `TEMPLATE_INSTALL_FAILED` | 重试 |
| 模板安装 | `broken` | manifest 缺字段 / 版本不兼容 / 资源缺失 | 修复成功 / 删除 | 标记 trust/compatibility 失败 | 禁止创建工程 | `TEMPLATE_BROKEN` | 修复或删除 |
| 模板安装 | `updating` | 发起更新 | 成功 / 失败 | 临时目录替换 | 禁止创建工程 | `TEMPLATE_UPDATE_FAILED` | 重试 / 回滚旧版本 |

## 5. 导出
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| 导出 | `ready` | 输入目录、输出目录、映射均通过 | 开始导出 | 清空旧错误 | 无 | 无 | 无 |
| 导出 | `exporting` | 点击导出 | 成功 / 失败 | 写 `export manifest` 临时对象 | 禁止再次导出 | `EXPORT_FAILED` | 重试 |
| 导出 | `blocked` | 缺工件 / stale / guard 不通过 | 阻塞条件解除 | 显示 blocker 列表 | 禁止导出 | `EXPORT_BLOCKED` | 修复工件或 guard |

## 6. 知识底座
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| 索引 | `fresh` | 增量更新完成 | 文件变化 / 手动刷新 | 更新时间戳 | 无 | 无 | 无 |
| 索引 | `stale` | 文档变化未索引 | 索引完成 | 标记命中新鲜度警告 | 禁止把旧引文当最终证据 | `INDEX_STALE` | 增量刷新 |
| 索引 | `rebuilding` | 全量重建 | 完成 / 失败 | 更新进度 | 禁止删除索引目录 | `INDEX_REBUILD_FAILED` | 重新构建 |

## 7. 多窗口协同
| 状态机 | 状态 | 进入条件 | 退出条件 | 副作用 | UI 禁用 | 错误入口 | 恢复入口 |
|---|---|---|---|---|---|---|---|
| 窗口协同 | `single` | 仅一个工作台窗口 | 打开第二窗口 | 无 | 无 | 无 | 无 |
| 窗口协同 | `shared-read` | 第二窗口只读打开同项目 | 转主写窗口 / 关闭 | 锁定只读态 | 禁止双写 | `WINDOW_LOCK_CONFLICT` | 切为只读或夺取写锁 |
| 窗口协同 | `reconcile` | 外部变更被检测 | 用户完成选择 | 显示冲突对话框 | 禁止保存冲突文件 | `WINDOW_STATE_CONFLICT` | 选择保留版本 |
