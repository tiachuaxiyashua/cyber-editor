# 38 模板与导出详细时序图

## 1. 模板安装/更新
1. 用户选择安装来源
2. Renderer 调 `template.install*`
3. Main 校验 manifest、版本、来源、兼容性
4. Main 写入模板注册表目录
5. 若同名版本已存在：
   - 进入更新逻辑
   - 比较版本
   - 写入新 revision
6. Renderer 刷新模板中心列表

## 2. 保存为模板
1. Renderer 收集当前工程或 flow 元数据
2. Main 生成模板 manifest
3. Main 复制必要脚手架和元数据
4. Main 更新模板中心索引
5. Renderer 显示新模板详情

## 3. 交付导出
1. 用户点击导出
2. Renderer 调 `export.validate`
3. Main 校验输出目录、工件、映射
4. 通过后启动导出 run
5. DeliveryExportService 依次写：
   - markdown/txt/pdf
   - openspec 文件夹
6. Main 返回结果目录
7. Renderer 展示“打开目录”
