# 03 核心数据契约

## 1. 目标
- 本文档只定义高风险对象的“字段集合和语义”，不绑定具体 TypeScript 文件名。
- 允许字段顺序不同，不允许核心字段缺失或改义。

## 13. 唯一性要求
- 另一套 AI 可以在实现语言层做适配，但不能删掉这些对象的核心字段类别。
- 特别禁止：
  - 把 `StageGuardStatus` 简化成单字符串
  - 把 `RuntimeRun` 和 `RuntimeEvent` 合并成一条日志文本
  - 把 `FlowDraft` 做成没有 `stageContracts/exportMappings` 的纯画布 JSON
