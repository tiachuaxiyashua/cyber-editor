# 11 复杂页面状态矩阵

## 1. 目标
- 固定复杂页面在不同状态下的可见区域、主动作、阻断信息和不允许行为。

## 2. 欢迎页

| 状态 | 进入条件 | 必须可见 | 禁止出现 |
|---|---|---|---|
| `blank_welcome` | 首启且无最近项 | 开始编排 / 新建工程 / 打开工程 | 工作台三栏 |
| `recent_projects_ready` | 有最近工程 | 最近工程列表、对象级动作 | 仅剩单按钮入口 |
| `recent_templates_ready` | 有最近模板 | 最近模板列表 | 模板被藏到二级弹层 |
| `open_project_picker` | 点击打开工程 | 原生目录选择器 | 自制伪目录树 |

## 3. 新建工程与模板中心

| 状态 | 必须可见 | 主动作 | 阻断 |
|---|---|---|---|
| `template_list_idle` | 模板列表 + 详情 + 创建区 | 选模板、创建工程 | 无 |
| `template_detail_ready` | 来源、版本、信任、兼容性、工件目录 | 创建工程 / 直接开始编排 | 无 |
| `project_path_invalid` | 错误提示留在表单区 | 修正目录/名称 | 禁止创建 |
| `template_invalid` | 模板损坏原因 | 修复/删除/查看详情 | 禁止使用 |
| `downloading_template` | 下载进度 | 取消 | 禁止重复安装 |

## 4. 文件树与文档区

| 状态 | 必须可见 | 主动作 | 禁止出现 |
|---|---|---|---|
| `doc_clean` | 标签、标题、保存状态、内容 | 编辑/切换视图 | 假脏状态 |
| `doc_dirty` | 脏标记、可保存 | 保存 / 撤销 / 继续编辑 | 切视图清脏 |
| `doc_conflict` | 冲突说明、恢复选择 | 保留本地 / 重新加载 | 静默覆盖 |
| `table_artifact_open` | 表格视图与保存状态 | 快速编辑 / 导出 | 当普通 Markdown 渲染 |

## 5. AI 会话栏

| 状态 | 必须可见 | 主动作 | 阻断 |
|---|---|---|---|
| `session_idle` | 会话列表、输入框 | 新建会话 / 发送 | 无 |
| `run_queued` | 运行状态块 | 停止 | 删除当前运行态 |
| `run_running` | 消息流增长、命中模型 | 停止 | 允许阶段确认 |
| `run_failed` | 错误信息、重试 | 重试 / 查看详情 | 假装成功 |
| `review_visible` | 蓝红裁判过程块 | 采纳/忽略/待处理 | 仅保留最终一句总结 |

## 6. 流程面板

| 状态 | 必须可见 | 主动作 | 阻断 |
|---|---|---|---|
| `guard_ready` | 全部 checkItems、ready=true | 确认阶段 | 无 |
| `guard_blocked` | blockingReasons、目标引用 | 修复问题 | 禁止确认 |
| `critical_running` | 当前关键运行状态 | 查看详情 / 停止 | 禁止确认 |
| `issues_pending` | issue 列表、采纳状态 | 处理 issue | 导出最终交付 |

## 7. 编排页

| 状态 | 必须可见 | 主动作 | 禁止出现 |
|---|---|---|---|
| `design_clean` | 资产栏、节点库、画布、Inspector | 拖拽节点 / 编辑配置 | 运行调试覆盖整页 |
| `design_dirty` | 脏状态、保存入口 | 保存 / 快照 | 普通切换导致位置重置 |
| `node_selected` | 节点对象级动作、Inspector | 编辑 / 删除 / 打开子流程 | 只能去远处全局菜单操作 |
| `run_debugging` | 运行抽屉、节点状态、变量/工件 | 局部重跑 / 从此继续 | 把设计态挤没 |
| `compact_layout` | 面板可折叠或可拉伸 | 继续编辑 | 文本堆叠、按钮不可点击 |

## 8. 技能与连接中心

| 状态 | 必须可见 | 主动作 | 禁止出现 |
|---|---|---|---|
| `installed_skills` | 已装技能 + 范围状态 | 设置范围 / 禁用 / 删除 | 只有静态列表 |
| `available_skills` | 来源、版本、信任 | 安装 | 无点击反馈 |
| `connector_health_failed` | 最近错误、授权状态 | 重试检查 / 查看详情 | 仅 toast |

## 9. 设置与模型配置

| 状态 | 必须可见 | 主动作 | 禁止出现 |
|---|---|---|---|
| `profile_list_ready` | profile 列表、当前激活 | 选择即激活 | 额外激活按钮作为必经路径 |
| `profile_editing` | 表单、保存、校验 | 保存 / 测试连接 | 编辑后无持久化 |
| `profile_test_failed` | 结构化诊断结果 | 修改配置 / 重试 | 空白失败 |

## 10. 唯一性要求
- 状态矩阵是实现约束，不是测试建议。
- 页面实现缺少某个状态面，就不算满足本矩阵。
