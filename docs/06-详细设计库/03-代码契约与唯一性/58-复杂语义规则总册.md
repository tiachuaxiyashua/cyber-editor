# 58 复杂语义规则总册

## 1. 范围
本总册把复杂语义规则集中到一个入口，避免实现时遗漏。

## 2. 必读规则
1. [31-并行分支通信冲突规则](./31-并行分支通信冲突规则.md)
2. [32-局部重跑规则](./32-局部重跑规则.md)
3. [33-快照恢复冲突规则](./33-快照恢复冲突规则.md)
4. [34-混合检索与ContextPack规则](./34-混合检索与ContextPack规则.md)
5. [35-StageGuard计算规则](./35-StageGuard计算规则.md)
6. [47-工件失效传播规则](./47-工件失效传播规则.md)

## 3. 总约束
1. 并行分支默认隔离，只有显式消息通道允许通信。
2. 局部重跑必须沿依赖图传播 stale，不允许只重跑单节点却保留脏下游结果。
3. 快照恢复必须先校验版本与完整性，再允许覆盖当前草稿。
4. ContextPack 打包必须服从 token budget，超预算时按证据优先级裁剪。
5. StageGuard 是硬阻断，不是警告。
6. 工件失效传播必须落到节点徽标、导出阻断和阶段 blocker 三个层面。
