# F-031 文档内查找与替换

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：文档编辑与知识关系 / 文档编辑 / 查找
- MSABC 分类：A
- 当前状态：已完成
- 关联页面：[文件树与文档区](../../04-UI设计/04-文件树与文档区.md)
- 共享实现基线：[文档编辑与知识关系](README.md)

## 2. 完成定义
- 用户在当前活动文档中按 `Ctrl+F` 打开查找条，按 `Ctrl+H` 切到替换模式。
- 查找条必须固定在文档头部下方，不允许遮挡正文首行。
- 支持 `下一处`、`上一处`、`替换当前`、`全部替换`。
- 查找结果必须展示 `当前命中序号 / 总命中数`。
- 替换动作只能作用于当前文档，不能误改其他打开标签。

## 3. 页面入口与层级
- 页面：`P2 文件树与文档区`
- 主入口：
  - 文档头部查找图标
  - `Ctrl+F`
  - `Ctrl+H`
- 深层入口：
  - 命令面板：`在当前文档查找`
  - 命令面板：`在当前文档替换`

## 4. 用户操作与系统反馈
1. 用户打开一个 Markdown 文档。
2. 用户按 `Ctrl+F`，文档头部下方出现查找条，焦点自动落到输入框。
3. 用户输入关键词后：
   - 编辑器高亮全部命中项。
   - 主高亮聚焦当前命中。
   - 查找条右侧显示 `1/7` 这类计数。
4. 用户点击向下箭头或按 `Enter`：
   - 跳到下一处命中。
   - 当前命中滚动到可视区域中部附近。
5. 用户按 `Ctrl+H` 或点击替换图标：
   - 第二输入框展开。
   - `替换当前` 只改当前命中。
   - `全部替换` 弹一次确认，提示替换总数。
6. 用户按 `Esc`：
   - 关闭查找条。
   - 清除高亮，但不修改光标位置。

## 5. 数据与状态
- Renderer 状态：
  - `isFindOpen`
  - `isReplaceOpen`
  - `query`
  - `replaceValue`
  - `matches`
  - `activeMatchIndex`
- 不单独持久化到工程文件。
- 关闭标签页时丢弃查找状态；同标签内视图切换时保留。

## 6. 实现要求
### Renderer
- 文档视图容器维护查找条状态。
- 编辑器适配层必须提供：
  - `find(query)`
  - `replaceCurrent(value)`
  - `replaceAll(value)`
  - `focusMatch(index)`
- 阅读态不允许直接替换；进入替换模式时必须自动切到编辑态。

### Main / Service
- 不经过 IPC。
- 仅在触发 `全部替换` 后走保存链路。

## 7. 校验与异常
- 空查询时禁用 `上一处`、`下一处`、`替换当前`、`全部替换`。
- 无命中时计数显示 `0/0`，并给出“未找到匹配内容”。
- 替换导致文档变脏后，必须触发脏状态提示。
- 如果外部变更冲突已挂起，查找仍可用，但替换操作必须被阻断并提示先处理冲突。

## 8. 自动测试
- e2e：
  - `Ctrl+F` 打开查找条。
  - 输入关键词后显示正确命中数。
  - `下一处` 会改变高亮位置。
  - `Ctrl+H` 后可执行 `替换当前` 和 `全部替换`。
  - 关闭查找条后高亮消失。
- 回归：
  - 阅读态进入替换时自动切编辑态。
  - 文档切标签后重新回来，查找条状态按设计保留/关闭。

## 9. 用户模拟测试
1. 打开 `01-原始需求.md`。
2. 搜索“模板”。
3. 连续点两次 `下一处`，确认正文滚动和高亮同步变化。
4. 切到替换模式，把“模板”替换成“流程模板”，只替换当前一处。
5. 关闭查找条，确认文档内容保留、脏状态点亮。
