# INF-011 Reference graph indexer

## 1. 基本信息
- 类型：内部能力
- 所属层级：壳层与文档底座 / 知识关系 / 索引
- MSABC 分类：A
- 当前状态：已完成
- 对应功能：
  - [F-041 查看笔记正向与反向引用](./F-041-查看笔记正向与反向引用.md)

## 2. 能力目标
- 扫描工程内 Markdown 文档，建立正向/反向引用图。

## 3. 输入输出
- 输入：工程文档列表
- 输出：`NoteReferenceGraph`
  - `outgoing`
  - `incoming`
  - `brokenRefs`

## 4. 实现要求
- 支持 Markdown 链接与 Wiki 链接。
- 保存文档后增量刷新。
- 索引结果挂到 bootstrap，供 renderer 直接使用。

## 5. 校验与异常
- 失效链接保留在图中并标记状态。
- 索引失败不阻断普通文档打开。

## 6. 自动测试
- unit：链接解析、图构建、失效引用识别。

## 7. 审计结论
- 审计状态：实现级文档已补齐。
