# F-024 移动文件或文件夹

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 文件树 / 移动
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[文件树与文档区](../../04-UI设计/04-文件树与文档区.md)

## 2. 用户价值与完成定义
1. 用户需要通过拖拽或移动命令重组工程结构。
2. 移动后引用、标签、树路径都要同步。

## 3. 页面行为
1. 支持拖拽移动。
2. 支持“移动到…”命令。
3. 目标目录高亮并显示可放置/不可放置状态。

## 4. 具体实现方案
### 4.1 Renderer
1. `TreeDragIndicator`
2. `MoveItemDialog`

### 4.2 Main / Service
1. `project-manifest-scaffold`
2. `document read/write service`
3. `reference graph indexer`

## 5. 校验与阻断
1. 不允许把目录移动到自己的子目录下。
2. 同级重名阻止。
3. 打开的文档移动后标签与路径摘要同步更新。

## 6. 自动测试
1. 拖拽移动文件。
2. 拖拽移动文件夹。
3. 非法目标阻止。

## 7. 用户模拟测试
1. 把一个文件拖到另一目录。
2. 确认树位置变化、标签路径更新。
3. 尝试把目录拖进自己的子目录，确认被阻止。

## 8. 不允许的错误实现
1. 移动后 UI 更新但文件系统未移动。
2. 非法目标静默失败。

## 9. 当前审计结论
- 审计状态：部分完成
- 审计说明：移动能力仍缺拖拽语义、非法目标阻断和引用刷新的一致闭环。
