# F-015 最近工程快速重开

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 工程生命周期 / 最近工程
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[欢迎页](../../04-UI设计/01-欢迎页.md)、[主工作台](../../04-UI设计/03-主工作台.md)
- 共享实现基线：[工程与文件](README.md)

## 2. 完成定义
- 欢迎页可直接点击最近工程重新打开。
- 打开后恢复最近活动工程的工作台状态。

## 3. 页面入口与层级
- 页面：`P0 欢迎页`
- 主入口：最近工程列表项

## 4. 用户操作与系统反馈
1. 点击最近工程。
2. 进入主工作台。
3. 文件树、标签和侧栏状态恢复到该工程上次记录。

## 5. 数据与状态
- `RecentProjectRecord`
- `lastWorkbenchLayout`

## 6. 实现要求
- 最近工程记录必须带最后打开时间与最近布局快照。

## 7. 校验与异常
- 路径失效时显示失效状态，不直接报错。

## 8. 自动测试
- e2e：从欢迎页点击最近工程并恢复工作台。

## 9. 用户模拟测试
1. 退出到欢迎页。
2. 点击最近工程。
3. 确认正确进入上次工程。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
