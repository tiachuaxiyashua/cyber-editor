# F-016 关闭工程与切换工程

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：工程与文件工作台 / 工程生命周期 / 切换
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[主工作台](../../04-UI设计/03-主工作台.md)
- 共享实现基线：[工程与文件](README.md)

## 2. 完成定义
- 用户可从当前工作台关闭工程并返回欢迎页。
- 用户可从当前工作台切换到另一个工程。

## 3. 页面入口与层级
- 页面：`P1 主工作台`
- 主入口：
  - 顶部文件菜单/图标菜单
  - 命令面板

## 4. 用户操作与系统反馈
1. 点击关闭工程。
2. 若存在未保存内容，先处理保存确认。
3. 关闭后返回欢迎页。
4. 切换工程时走同样的保存检查。

## 5. 数据与状态
- `currentProjectId`
- `pendingUnsavedChanges`

## 6. 实现要求
- 关闭和切换都要复用统一的离开当前工程守卫。

## 7. 校验与异常
- 有未保存内容时不能直接切走。

## 8. 自动测试
- e2e：关闭工程、切换工程、未保存拦截。

## 9. 用户模拟测试
1. 修改文档后尝试切换工程。
2. 处理保存提示。
3. 确认切换完成。

## 10. 审计结论
- 审计状态：实现级文档已补齐。
