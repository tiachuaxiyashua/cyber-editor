# F-095 技能中心查看已装与可装技能

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：技能、连接与模型 / 技能中心 / 浏览
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[技能与连接中心](../../04-UI设计/08-技能与连接中心.md)
- 共享实现基线：[技能、连接与模型](README.md)

## 2. 完成定义
- 技能中心必须分三块：
  - 已安装技能
  - 可安装来源
  - 最近使用技能
- 每个技能项至少显示：
  - 名称
  - 来源
  - 版本
  - 启用范围
  - 状态

## 3. 页面入口与层级
- 页面：`P1 技能与连接中心`
- 主入口：左侧活动栏技能图标

## 4. 用户操作与系统反馈
1. 进入技能中心后默认看到已安装技能列表。
2. 切到来源页签可看到目录来源和远程来源。
3. 点击技能项可展开详情抽屉。

## 5. 数据与状态
- `InstalledSkill[]`
- `SkillSource[]`
- `RecentlyUsedSkill[]`

## 6. 实现要求
### Renderer
- 安装类动作默认收在图标入口和详情抽屉，不在首页大面积展开。

### Main / Service
- Skill registry 提供统一查询。

## 7. 校验与异常
- 损坏技能显示异常状态并阻断启用。

## 8. 自动测试
- e2e：进入技能中心、查看三块区域、展开技能详情。

## 9. 用户模拟测试
1. 打开技能中心。
2. 确认已安装和可安装来源分区清晰。
3. 点开一项技能查看详情。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
