# F-099 禁用、删除技能与状态反馈

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：技能、连接与模型 / 技能中心 / 管理
- MSABC 分类：A
- 当前状态：部分完成
- 关联页面：[技能与连接中心](../../04-UI设计/08-技能与连接中心.md)
- 共享实现基线：[技能、连接与模型](README.md)

## 2. 完成定义
- 用户可禁用技能，也可删除技能。
- 删除前必须检查当前是否被工程/会话/角色包引用。
- 删除成功后列表即时刷新。

## 3. 页面入口与层级
- 页面：`P1 技能与连接中心`
- 主入口：技能详情中的 `禁用`、`删除`

## 4. 用户操作与系统反馈
1. 用户禁用技能。
2. 技能列表显示 `已禁用`。
3. 用户删除技能。
4. 若被引用，显示阻断原因。

## 5. 数据与状态
- `skillStatus`
- `skillReferenceCount`

## 6. 实现要求
- 删除是危险操作，必须二次确认。

## 7. 校验与异常
- 被引用时不允许删除。

## 8. 自动测试
- e2e：禁用、删除、被引用阻断。

## 9. 用户模拟测试
1. 禁用一个技能。
2. 删除一个未被引用的技能。
3. 尝试删除被引用技能，确认被阻断。

## 10. 审计结论
- 审计状态：实现级文档已补齐，功能本身仍部分完成。
