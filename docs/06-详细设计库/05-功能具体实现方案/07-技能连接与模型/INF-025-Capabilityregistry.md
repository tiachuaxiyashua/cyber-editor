# INF-025 Capability registry

## 1. 基本信息
- 类型：内部功能
- 所属层级：连接层 / 能力注册 / 统一注册
- MSABC 分类：S
- 当前状态：已完成

## 2. 责任与完成定义
1. 统一注册本地工具、MCP 工具、脚本工具、内置能力。
2. 向节点绑定和运行时提供可查询能力清单。

## 3. 核心接口
1. `listCapabilities()`
2. `getCapability(capabilityId)`
3. `resolveCapabilityBinding(binding)`

## 4. 数据要求
1. 能力至少包含：
   - ID
   - 名称
   - 类型
   - 输入 schema
   - 权限边界
   - 健康状态

## 5. 自动测试
1. 注册能力。
2. 查询能力。
3. 绑定解析。

## 6. 不允许的错误实现
1. 不同来源能力各用不同注册表。
2. 节点绑定时直接绕过能力注册表。

## 7. 当前审计结论
- 审计状态：已完成
- 审计说明：能力注册表已是统一入口，但后续仍需与真实 MCP discovery 更深整合。
