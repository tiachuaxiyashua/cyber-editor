# INF-023 Stage guard engine

## 1. 基本信息
- 类型：内部功能
- 所属层级：编排层 / 阶段控制 / Guard
- MSABC 分类：S
- 当前状态：部分完成

## 2. 责任与完成定义
1. 根据阶段契约、工件状态、运行状态计算当前阶段是否可确认。
2. 返回结构化 guard 结果。

## 3. 核心接口
1. `evaluateStageGuard(stageId, context)`

## 4. 输入维度
1. 阶段输出契约
2. 工件完成状态
3. 审查 blocker 状态
4. 当前运行状态

## 5. 自动测试
1. 工件缺失阻断。
2. blocker 未清阻断。
3. 全满足放行。

## 6. 不允许的错误实现
1. 用户无输入也能无条件阶段确认。
2. guard 只在 UI 上显示，不真正阻断确认。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：阶段 guard 已有基础实现，但仍未把工件、运行和 blocker 统一纳入强阻断链路。
