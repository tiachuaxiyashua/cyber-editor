# INF-021 Repair / Fallback pipeline

## 1. 基本信息
- 类型：内部功能
- 所属层级：智能层 / 生成控制 / 修复
- MSABC 分类：S
- 当前状态：部分完成

## 2. 责任与完成定义
1. 处理模型输出不符合格式或质量要求的情况。
2. 提供统一的重试、修复、降级和人工升级路径。

## 3. 标准流程
1. 生成
2. 校验
3. 修复提示
4. 重试
5. 降级
6. 升级为人工处理

## 4. 自动测试
1. JSON 修复。
2. 超时重试。
3. 连续失败后降级。

## 5. 不允许的错误实现
1. 输出不合格直接写工件。
2. 一次失败就放弃，没有修复或降级。

## 6. 当前审计结论
- 审计状态：部分完成
- 审计说明：修复与降级链路已有设计，但尚未成为所有关键生成路径的标准流程。
