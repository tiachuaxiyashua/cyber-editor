# F-050 生成阶段草稿并写入工件

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：AI会话与阶段控制 / 阶段控制 / 生成
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[AI会话栏](../../04-UI设计/05-AI会话栏.md)、[流程面板](../../04-UI设计/06-流程面板.md)
- 共享实现基线：[AI会话与阶段控制](README.md)

## 2. 完成定义
- 点击“生成阶段草稿”后，系统必须依据当前阶段契约生成目标工件。
- 生成结果不能只停留在聊天输出，必须落到指定工件。
- 成功后流程面板要显示本次影响的工件列表。

## 3. 页面入口与层级
- 页面：
  - `P3 AI 会话栏`
  - `P3 流程面板`
- 主入口：流程面板阶段动作区 `生成阶段草稿`

## 4. 用户操作与系统反馈
1. 用户点击生成阶段草稿。
2. 系统创建一个运行记录。
3. 流程面板显示：
   - 运行中
   - 目标工件列表
4. 生成成功后：
   - 工件状态更新为“草稿已更新”
   - 用户可点击打开工件查看
5. 生成失败：
   - 旧工件保留
   - 运行记录显示失败原因

## 5. 数据与状态
- `stageDraftRun`
- `targetArtifacts[]`
- `artifactWriteResults[]`

## 6. 实现要求
### Renderer
- 受影响工件列表必须可点击定位。
- 生成中不可重复点击同一阶段的生成按钮。

### Main / Service
- RuntimeService 协调模型生成、结构化校验和工件写入。
- 写工件必须采用“先临时写入，校验通过后替换正式文件”的策略。

## 7. 校验与异常
- 当前阶段无目标工件时禁止生成。
- guard 未满足时允许生成，但需明确显示“仅生成草稿，不代表可确认”。
- 当前状态为“部分完成”，表示已有主路径，但工件契约联动、失败回滚和证据展示未完全收口。

## 8. 自动测试
- e2e：
  - 点击后出现运行记录。
  - 目标工件更新。
  - 失败时旧工件保留。
- unit：
  - 工件写入事务。

## 9. 用户模拟测试
1. 在 `discover` 阶段点击生成草稿。
2. 确认流程面板显示目标工件。
3. 打开工件确认内容变化。
4. 制造一次失败，确认旧工件未损坏。
