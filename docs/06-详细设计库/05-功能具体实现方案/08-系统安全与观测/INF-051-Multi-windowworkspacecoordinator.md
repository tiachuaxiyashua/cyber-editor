# INF-051 Multi-window workspace coordinator

## 1. 基本信息
- 类型：内部功能
- 所属层级：壳层与文档底座 / 多窗口工作台 / 协调
- MSABC 分类：A
- 当前状态：未完成

## 2. 功能目标
- 统一管理主工作台分屏和独立文档窗口的生命周期、状态同步和保存冲突。

## 3. 具体实现方案
- 维护 `windowId -> documentId -> viewState` 映射。
- 所有窗口共享同一工程上下文和保存服务。
- 当同一文档在多个视图打开时，必须有脏状态和冲突协调。

## 4. 自动测试
- 单元：窗口状态注册、文档订阅和销毁。
- e2e：新建文档窗口、同步编辑、关闭恢复。
