# F-002 欢迎页最近工程列表

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：平台入口与模板 / 欢迎页与空状态 / 最近工程
- MSABC 分类：M
- 当前状态：已完成
- 关联页面：[欢迎页](../../04-UI设计/01-欢迎页.md)
- 上游需求：`D-A1`

## 2. 用户价值与完成定义
1. 欢迎页必须能直接回到最近工作对象。
2. 列表项至少显示名称、路径摘要、最近访问时间。
3. 点击列表项立即打开对应工程。

## 3. 具体实现方案
### 3.1 Renderer
1. `RecentProjectList`
2. `RecentProjectItem`

### 3.2 Main / Service
1. `recent-project-template-store`

## 4. 校验与阻断
1. 损坏路径在列表中显示失效态。
2. 点击失效项不直接崩溃，转为修复或移除。

## 5. 自动测试
1. 最近工程渲染。
2. 点击有效工程打开。
3. 失效工程显示失效态。

## 6. 用户模拟测试
1. 制造两个最近工程。
2. 打开欢迎页确认都可见。
3. 点击其中一个，确认直接进入工作台。

## 7. 不允许的错误实现
1. 最近工程只显示名称不显示路径。
2. 点击最近工程没有真正打开工程。

## 8. 当前审计结论
- 审计状态：已完成
- 审计说明：最近工程列表主链路已在代码中存在，但仍依赖最近记录服务的稳定性。
