# INF-029 Template registry

## 1. 基本信息
- 类型：内部功能
- 所属层级：编排层 / 模板体系 / 注册
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：欢迎页、模板中心、新建工程
- 共享实现基线：[平台入口与模板](README.md)

## 2. 责任与完成定义
### 2.1 服务责任
1. 管理所有模板的注册、查询、更新、删除。
2. 向 UI 提供统一模板列表和模板详情。

### 2.2 完成定义
1. 内置、本地导入、远程下载模板都能进入同一注册表。
2. 模板中心、欢迎页、新建工程从同一数据源读取模板。
3. 注册表支持最近使用记录和状态查询。

## 3. 核心接口
1. `listTemplates(context)`
2. `getTemplate(templateId)`
3. `registerTemplate(manifest, source)`
4. `removeTemplate(templateId)`

## 4. 实现要求
1. 注册表是模板唯一事实来源。
2. 不允许欢迎页和模板中心各自扫描磁盘。
3. 模板排序规则应可配置。

## 5. 自动测试
1. 注册新模板。
2. 删除模板。
3. 最近使用排序。

## 6. 不允许的错误实现
1. 多个页面各自维护一份模板列表。
2. 删除模板后欢迎页和模板中心状态不一致。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：模板注册表已有骨架，但仍缺统一排序、来源合并和状态同步闭环。
