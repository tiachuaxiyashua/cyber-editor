# INF-030 Template scaffold and save service

## 1. 基本信息
- 类型：内部功能
- 所属层级：能力层 / 模板能力 / 脚手架
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：新建工程、保存为模板、从模板创建工程
- 共享实现基线：[平台入口与模板](README.md)

## 2. 责任与完成定义
### 2.1 服务责任
1. 根据模板创建工程目录。
2. 根据工程或编排草稿保存模板。
3. 负责模板清单打包与落盘。

### 2.2 完成定义
1. 模板创建工程时正确复制 Flow、角色、工件目录、导出映射。
2. 保存为模板时能正确打包这些资产。
3. 模板结构双向可逆：模板可创建工程，工程可保存回模板。

## 3. 核心接口
1. `createProjectFromTemplate(templateId, targetPath)`
2. `saveTemplateFromProject(projectId, templateMeta)`
3. `saveTemplateFromFlowDraft(flowDraftId, templateMeta)`

## 4. 实现要求
1. 模板包必须包含完整目录结构。
2. 保存过程要过滤运行时临时文件。
3. 创建工程时要生成新工程 ID，而不是复用模板 ID。

## 5. 自动测试
1. 从模板创建工程目录树。
2. 从工程保存模板目录树。
3. 保存后再反向创建工程。

## 6. 不允许的错误实现
1. 保存模板只导出部分文件。
2. 模板创建工程时把模板 ID 直接写进工程。
3. 运行时临时文件被错误打进模板。

## 7. 当前审计结论
- 审计状态：部分完成
- 审计说明：模板打包与反向生成已有基础路径，但仍缺完整资产清单和双向一致性验证。
