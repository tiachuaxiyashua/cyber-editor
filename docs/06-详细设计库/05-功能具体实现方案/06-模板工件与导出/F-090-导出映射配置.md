# F-090 导出映射配置

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：模板工件与导出 / 导出 / 映射
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)、[流程面板](../../04-UI设计/06-流程面板.md)
- 上游需求：`D-C1`、`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 最终交付结构必须由模板和编排决定，不由产品写死。
2. 用户需要明确知道“哪些工件会导出成什么、导到哪里”。

### 2.2 完成定义
1. 用户能配置工件到导出目标的映射。
2. 支持至少：
   - `md`
   - `txt`
   - `pdf`
   - `openspec`
3. 允许把中间工件排除在最终导出之外。
4. 运行导出前先校验映射完整性。

## 3. 用户操作流程
1. 用户打开导出映射资产。
2. 选择一个导出目标。
3. 为该目标选择包含哪些工件。
4. 配置目标目录和文件命名规则。
5. 保存后，流程面板中的导出入口使用该映射。

## 4. 数据模型
```json
{
  "target": "pdf",
  "outputDirectory": "delivery/pdf/",
  "items": [
    {
      "artifactId": "requirements/feature-list.md",
      "targetFileName": "功能清单.pdf",
      "include": true
    }
  ]
}
```

## 5. 具体实现方案
### 5.1 Renderer
1. `ExportMappingEditor`
2. `ExportTargetTabs`
3. `ExportArtifactTable`

### 5.2 Main / Service
1. `export-mapping-service`
2. `delivery-export-service`
3. `openspec-exporter`

## 6. 校验与阻断
1. 导出目标没有任何工件时，允许保存，但导出前必须警告为空。
2. 引用不存在工件时阻止保存。
3. 输出目录非法时阻止保存。
4. OpenSpec 目标若缺必需工件，阻止导出。

## 7. 自动测试
1. 映射保存与恢复
2. 空映射告警
3. OpenSpec 必需工件校验

## 8. 用户模拟测试
1. 配置一个 `pdf` 导出映射。
2. 只包含 2 个工件。
3. 运行导出后确认仅导出这 2 个结果。
4. 再配置一个损坏映射，确认系统阻止导出。

## 9. 不允许的错误实现
1. 导出仍然固定写死读取几个文件。
2. 映射只显示不参与实际导出。
3. 中间工件无法排除。

## 10. 当前审计结论
- 审计状态：未完成
- 审计说明：导出映射仍未成为一等配置对象，当前仍不足以支撑任意模板输出结构。
