# F-075 左侧面板缩放、折叠与记忆

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 布局 / 左侧面板
- MSABC 分类：A
- 当前状态：未完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C4`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 左侧面板承载资产列表和节点库，是高频区，但不能长期挤压画布。
2. 用户调好的面板宽度属于工作偏好，必须被记忆。
3. 在小屏和大屏下，左侧面板都要保持可预测行为。

### 2.2 完成定义
1. 面板可拖拽调整宽度。
2. 面板支持折叠和展开。
3. 不同 Flow、模式切换、页面重开后，宽度和折叠状态保持稳定。
4. 面板折叠后，画布即时扩展；展开后，回到上次宽度。

## 3. 页面入口与层级
1. 入口页面：编排页
2. 操作对象：
   - 左侧分隔条
   - 左侧折叠按钮
3. 所在层级：`P1 编排页 -> P2 左侧面板`

## 4. 用户操作流程
1. 用户拖动左侧分隔条调整宽度。
2. 系统实时更新面板宽度和画布尺寸。
3. 用户点击折叠按钮。
4. 系统折叠左侧面板并保留最后一次宽度。
5. 用户再次展开时恢复上次宽度。

## 5. 可见效果与状态
1. 左侧面板默认宽度应在 `280px-340px` 范围内。
2. 最小宽度固定为 `240px`，不允许拖得导致文本堆叠不可读。
3. 折叠态只保留最小图标化入口，不占完整栏宽。
4. 画布宽度变化要平滑，不允许突然跳动。

## 6. 数据模型
```json
{
  "leftPanel": {
    "width": 312,
    "collapsed": false,
    "lastExpandedWidth": 312
  }
}
```

## 7. 具体实现方案
### 7.1 Renderer
组件：
1. `ResizableLeftSidebar`
2. `SidebarResizeHandle`
3. `SidebarCollapseToggle`

Renderer 责任：
1. 监听拖拽并同步到本地布局状态。
2. 折叠时保留 `lastExpandedWidth`。
3. 窗口过窄时自动进入安全最小宽度，而不是继续压缩文本。

### 7.2 Main / Service
服务：
1. `settings-layout-persistence`
2. `ui-responsive-layout-engine`

Main 责任：
1. 持久化当前宽度和折叠状态。
2. 在编排页重新打开时恢复布局。

## 8. 校验与阻断
1. 不允许把宽度拖到低于最小值。
2. 不允许在切换 Flow 时重置宽度。
3. 不允许因 Inspector 切换或节点切换影响左侧面板宽度。

## 9. 自动测试
### 9.1 单元
1. 最小/最大宽度约束
2. 折叠/展开状态转换
3. 恢复最近宽度

### 9.2 端到端
1. 拖拽左侧宽度。
2. 折叠再展开。
3. 切换 Flow 后确认宽度不丢。
4. 重开页面后确认宽度恢复。

## 10. 用户模拟测试
1. 把左侧面板拖宽到明显大于默认值。
2. 切换到另一个 Flow，再切回，确认宽度保持。
3. 折叠后确认画布扩大。
4. 再展开，确认恢复到上次宽度。

## 11. 不允许的错误实现
1. 只在内存里保存宽度。
2. 切换 Flow 或切换模式就重置宽度。
3. 允许用户把面板拖到文本完全堆叠。

- 审计状态：未完成
- 审计说明：左侧面板仍缺少真正稳定的宽度持久化与折叠恢复语义。
