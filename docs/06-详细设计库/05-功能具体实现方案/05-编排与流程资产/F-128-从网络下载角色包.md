# F-128 从网络下载角色包

## 1. 功能定义
用户可从网络角色注册表下载角色包，并将其安装为本地可用角色包。

等级：A  
状态：未完成

## 2. 入口
- 编排页角色资产区的“下载角色包”
- 技能与连接中心的“角色包”分页

## 3. 支持内容
- 远程目录浏览
- 直接 URL 安装
- 来源、版本、兼容性与信任状态展示

## 4. 方法级 IO
### IPC
- `rolePackage.list`
- `rolePackage.installFromRemote`

请求：
```json
{
  "url": "https://example.com/roles/clarifier-role-package.json"
}
```

响应：
```json
{
  "id": "clarifier-role",
  "installed": true,
  "source": "remote"
}
```

## 5. 动作时序
1. 用户点击下载角色包。
2. 打开来源选择或 URL 输入对话框。
3. Main 调 `RemoteRoleRegistryAdapter` 下载并校验。
4. 成功后写入角色包注册目录。
5. 刷新角色资产列表。

## 6. 校验
- 角色包必须包含：
  - `role.json`
  - `IDENTITY.md`
  - `SOUL.md`
  - `AGENTS.md`
  - `USER.md`
- 必须声明兼容版本。

## 7. 错误处理
- 网络不可达：可重试。
- 包结构不合法：阻断安装。
- 已安装但版本更低：提示更新。

## 8. 自动化测试
- mock 远程包并安装成功。
- 包字段缺失时阻断并提示。
- 安装成功后角色列表刷新。
