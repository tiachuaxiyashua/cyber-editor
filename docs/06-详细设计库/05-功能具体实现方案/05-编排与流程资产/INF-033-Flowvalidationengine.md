# INF-033 Flow validation engine

## 1. 基本信息
- 类型：内部功能
- 所属层级：编排层 / 流程校验 / 结构
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：编排页保存、运行前校验、阶段确认
- 共享实现基线：[编排与流程资产](README.md)

## 2. 责任与完成定义
### 2.1 服务责任
1. 校验 Flow 结构、节点配置、边绑定、并行/循环语义、工件契约。
2. 输出结构化错误，供画布和 Inspector 使用。

### 2.2 完成定义
1. 保存前校验。
2. 运行前再次校验。
3. 校验错误能定位到具体节点或边。

## 3. 核心接口
1. `validateFlowStructure(flowDraft)`
2. `validateFlowRuntime(flowDraft, runtimeContext)`
3. `groupValidationErrors(errors)`

## 4. 校验维度
1. 基础结构
   - 开始节点
   - 孤立节点
   - 边环路
2. 节点配置
   - 角色绑定
   - 连接绑定
   - 工具绑定
3. 高级语义
   - 并行分支与汇合
   - 循环退出条件
   - 子流程目标
4. 工件契约
   - 节点 IO
   - 阶段输出契约
   - 导出映射

## 5. 实现要求
1. 错误必须带对象 ID、对象类型、错误码、用户可读说明。
2. Renderer 不自行拼校验规则，只消费校验结果。

## 6. 自动测试
### 6.1 单元
1. 孤立节点
2. 缺失汇合
3. 缺失循环退出
4. 缺失工件契约

### 6.2 集成
1. 编排页保存前阻断
2. 运行前阻断

## 7. 不允许的错误实现
1. 只在运行失败后才发现结构错误。
2. 校验结果只是一句通用报错，不能定位对象。

## 8. 当前审计结论
- 审计状态：部分完成
- 审计说明：Flow 校验仍缺少并行、循环和工件契约的系统级主链路。
