# F-067 条件节点配置

## 1. 基本信息
- 类型：用户可见功能
- 所属层级：编排与流程资产 / 流程语义 / 条件
- MSABC 分类：S
- 当前状态：部分完成
- 关联页面：[编排页](../../04-UI设计/07-编排页.md)
- 上游需求：`D-C2`

## 2. 用户价值与完成定义
### 2.1 用户价值
1. 条件节点决定流程分支，是流程语义的基本单元。
2. 用户必须知道条件判断依据是什么、真分支和假分支去哪。

### 2.2 完成定义
1. 条件节点可配置判断来源：
   - 工件字段
   - 消息字段
   - 控制信号
   - 人工确认结果
2. 条件节点显式区分真分支和假分支。
3. 条件未配置时阻止运行。

## 3. 具体实现方案
### 3.1 Renderer
1. 条件节点卡片显示判断摘要。
2. Inspector 显示条件表达式编辑器。
3. 真分支/假分支在画布中使用不同标签或颜色。

### 3.2 Main / Service
1. `flow-validation-engine`
2. `node-io-contract-service`

## 4. 校验与阻断
1. 条件节点必须同时具备真分支和假分支，除非明确声明单分支容错。
2. 表达式引用不存在字段时阻断运行。

## 5. 自动测试
1. 条件配置保存与恢复。
2. 真/假分支连接校验。
3. 条件表达式字段校验。

## 6. 用户模拟测试
1. 创建一个条件节点。
2. 绑定工件字段作为判断依据。
3. 连出真分支和假分支。
4. 保存并重开，确认判断摘要仍在。

## 7. 不允许的错误实现
1. 条件节点只是一个名字，没有表达式配置。
2. 只有一个分支，不区分真假。
3. 运行时才临时判断，不在画布中显示结构。

## 8. 当前审计结论
- 审计状态：部分完成
- 审计说明：条件节点仍缺表达式配置、真/假分支可视化和结构阻断主链路。
