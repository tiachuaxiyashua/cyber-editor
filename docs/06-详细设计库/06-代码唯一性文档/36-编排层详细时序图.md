# 36 编排层详细时序图

## 1. Flow 保存
1. Renderer 收集当前 `flowDraft`
2. Renderer 调用 `flow.validateLocal`
3. 若失败：更新 Inspector 错误列表，停止
4. 若通过：调用 `flow.save`
5. Main 校验：
   - draft schema
   - 资产引用
   - 输入/输出目录
6. Main 写文件
7. Main 返回新 `revisionId`
8. Renderer 清除 dirty 标记，保留选择与布局

## 2. 节点编辑
1. 用户在 Inspector 修改字段
2. Renderer 仅更新目标节点 patch
3. 触发局部校验
4. 更新节点状态与 draft dirty
5. 若字段影响下游契约，则标记下游 stale

## 3. 子流程直接打开
1. 用户点击子流程卡片按钮
2. Renderer 根据 `subflowId` 打开资产
3. 保存父 flow 当前视口状态
4. 切换到子流程 draft
5. 返回时恢复父 flow 视口与选择

## 4. 节点局部重跑
1. 用户选择“从此继续”
2. Renderer 调 `flow.rerunFromNode`
3. Main 校验上游结果有效性
4. 失效节点集合写入 run plan
5. Runtime 从目标节点开始执行
6. Renderer 更新节点运行态和日志
