# 05 模板中心与双主入口代码契约

## 1. 目标
- 锁定“欢迎页 / 新建工程与模板中心 / 无工程编排模式”这条主路径的代码行为。
- 防止另一套 AI 把产品重新做成“只有工程入口的文档编辑器”。

## 2. 不允许变化的产品语义
- `开始编排` 和 `新建工程` 是并列一级动作。
- 模板中心不是一次性向导，而是独立长期存在的中心页。
- 模板可以：
  - 创建工程
  - 直接开始编排
  - 被保存、安装、下载、更新、修复、删除
- 无工程编排模式必须是 `P0` 根页面，而不是欢迎页上的浮层。

## 3. 页面状态契约
### 3.1 欢迎页状态
- `no_active_project`
- `recent_projects_ready`
- `recent_templates_ready`
- `directory_picker_open`
- `template_center_open`
- `orchestration_draft_open`

### 3.2 模板中心状态
- `listing`
- `filtering`
- `detail_ready`
- `directory_target_pending`
- `creating_project`
- `installing_template`
- `remote_download_pending`
- `template_damaged`

### 3.3 无工程编排状态
- `draft_clean`
- `draft_dirty`
- `draft_saved`
- `binding_project`
- `saving_as_template`
- `exporting_flowpack`

## 4. IPC 唯一性约束
- 欢迎页只能通过以下 IPC 进入下一层：
  - `project.open`
  - `project.create`
  - `template.startFlow`
- 不允许 renderer 直接拼接工程目录结构后跳工作台。
- `project.create` 必须同时支持：
  - 选择父目录后创建新文件夹
  - 直接使用已有目录
- `template.startFlow` 的返回结果必须直接把应用切到 `orchestration_only` 或 `workspace`，不能要求 renderer 二次推断。

## 5. 模板中心列表/详情唯一行为
- 左侧模板列表只负责：
  - 选择项
  - 搜索/筛选
  - 最近模板分组
- 右侧详情负责：
  - 名称
  - 说明
  - 来源
  - 版本
  - 信任状态
  - 兼容性
  - 工件目录预览
  - 默认流程预览
  - 主动作按钮
- 点击左侧模板项只改变选中态，不得自动创建工程或自动切页。

## 6. 主动作唯一规则
- `创建工程`
  - 前置：目录有效、工程名有效、模板可用
  - 成功：进入工作台并返回完整 bootstrap
- `从模板直接开始编排`
  - 前置：模板有有效默认 Flow
  - 成功：进入无工程编排模式并加载草稿
- `打开已有工程`
  - 前置：选择目录成功
  - 成功：进入工作台

## 7. 错误与阻断
- 目录无效、模板损坏、模板不兼容、模板缺省 Flow 缺失，都必须阻断对应主动作。
- 阻断信息必须在当前页面可见，不能只打 toast。
- 模板损坏不得被当成“可安装但稍后再说”的弱提示。

## 8. 测试 oracle
- 欢迎页必须测：
  - 点击 `开始编排` 进入无工程编排模式
  - 点击 `新建工程` 进入模板中心/新建工程页
  - 点击最近工程进入工作台
- 模板中心必须测：
  - 仅选中模板不触发副作用
  - 创建工程成功路径
  - 从模板直接开始编排路径
  - 模板损坏阻断路径
