# 08 编排层与 Flow 编辑器代码契约

## 1. 目标
- 锁定编排页作为专业编辑器的行为边界。

## 2. 不允许变化的核心结构
- 编排页固定包含：
  - 顶部栏
  - 资产栏
  - 节点库
  - 画布
  - Inspector
  - 底部运行抽屉
- 设计态和运行态必须分离。
- 画布草稿是唯一状态源，不能让组件局部状态和持久化草稿并存竞争。

## 3. 节点与边
- 节点类型最少包含：
  - start
  - end
  - agent
  - tool
  - condition
  - loop
  - parallel_split
  - parallel_join
  - subflow
  - artifact_read
  - artifact_write
  - manual_confirm
- 边的 `channelType` 只能是：
  - control
  - artifact
  - message
  - signal

## 4. 位置持久化
- 节点位置属于 `FlowDraft` 一部分。
- 下列动作不得重置位置：
  - Inspector 编辑
  - 角色切换
  - 子流程切换
  - 工件契约编辑
  - 保存
  - 快照创建
- 只有显式“重置布局”才允许回到默认位置。

## 5. 拖拽与连线
- 节点库必须支持拖拽小卡片到画布。
- 仅点击节点库不应自动生成节点，除非另有显式“点击添加”模式。
- 连线创建后必须可见方向。
- 删除边、改边类型、改边映射必须可通过 Inspector 或对象菜单完成。

## 6. 子流程与角色包
- 子流程卡片本体必须支持直接打开编辑。
- 角色包实例化必须由：
  - 角色包清单
  - Skills 绑定
  - 权限边界
  - 默认模型策略
组成。
- 输出格式不属于角色包。

## 7. 并行与循环
- 并行至少要定义：
  - 分叉条件
  - 分支通信通道
  - 汇合策略
  - 失败策略
- 循环至少要定义：
  - 进入条件
  - 继续条件
  - 最大轮次
  - 超时/失败处理

## 8. 调试与恢复
- 节点级调试是必需能力。
- 必须存在：
  - 从节点试跑
  - 查看变量/工件
  - 局部重跑
  - 快照恢复
- 这些动作属于运行抽屉或深层入口，不得伪装成新的主页面。

## 9. 测试 oracle
- 拖拽节点到画布后位置正确。
- Inspector 编辑后位置不丢。
- 子流程可从卡片直接打开。
- 并行/循环配置必须能保存并重开恢复。
- 画布缩放、面板拉伸、紧凑宽度下仍可操作。
