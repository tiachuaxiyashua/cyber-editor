# 17 页面动作矩阵

## 1. 目标
- 固定每个复杂页面的主动作、深层动作、对象级动作和禁用条件。
- 防止另一套 AI 把动作入口随意移动。

## 2. 欢迎页
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| Hero | 创建工程 | 主动作 | 打开新建工程页 | 无 |
| Hero | 开始编排 | 主动作 | 进入无工程编排模式 | 无 |
| 最近工程列表 | 打开工程 | 对象级主动作 | 进入工作台 | 路径失效 |
| 最近工程列表 | 更多 | 对象级深层动作 | 打开重命名/移除/显示目录菜单 | 无 |
| 最近模板列表 | 使用模板 | 主动作 | 打开模板中心详情或直达编排/新建 | 模板损坏 |

## 3. 新建工程与模板中心
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 模板列表 | 选择模板 | 主动作 | 右侧显示详情 | 模板损坏 |
| 模板详情 | 从模板创建工程 | 主动作 | 打开工程创建表单 | 模板无效 |
| 模板详情 | 直接开始编排 | 主动作 | 进入无工程编排模式并加载默认 flow | 模板缺少默认 flow |
| 顶部工具条 | 导入模板 | 深层动作 | 打开目录/来源选择 | 无 |
| 顶部工具条 | 刷新来源 | 深层动作 | 重新拉取模板索引 | 来源不可达 |

| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 顶部栏 | 保存 | 主动作 | 保存当前文档 | 无活动文档 |
| 顶部栏 | 打开编排 | 主动作 | 进入编排页 | 无 |
| 文件树 | 新建文件/目录 | 对象级动作 | 打开轻量表单 | 无工程 |
| 文件树 | 右键菜单 | 深层动作 | 重命名/删除/导入/显示目录 | 无对象 |
| 文档区 | 切换视图 | 对象级动作 | 阅读/编辑/源码切换 | 无活动文档 |

## 5. AI 会话栏与流程面板
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 会话列表 | 切换会话 | 主动作 | 切换消息历史与当前 run | 无会话 |
| Composer | 发送消息 | 主动作 | 创建 run | 输入为空 |
| 流程面板 | 生成阶段草稿 | 主动作 | 发起阶段 run | guard 未通过 |

| 流程面板 | 查看问题详情 | 对象级动作 | 展开审查问题详情 | 无问题 |

## 6. 编排页
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 节点库 | 拖拽节点到画布 | 主动作 | 在放置点生成节点 | 画布只读 |
| 画布节点 | 选择节点 | 主动作 | Inspector 显示节点配置 | 无 |
| 画布节点 | 卡片操作按钮 | 对象级动作 | 打开子流程/复制/删除/测试节点 | 视动作而定 |
| 画布节点 | 右键菜单 | 深层动作 | 更多节点操作 | 无 |
| 边 | 选择边 | 主动作 | Inspector 显示边绑定 | 无 |
| 顶部栏 | 运行 flow | 主动作 | 进入运行态 | Flow 校验失败 |
| 顶部栏 | 保存快照 | 深层动作 | 创建快照 | Flow 未保存 |
| 运行抽屉 | 从节点继续 | 深层动作 | 触发局部重跑 | 节点不可调试 |

## 7. 技能/连接/模型中心
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 已装技能列表 | 启用/禁用 | 对象级动作 | 修改 scope 或状态 | 技能损坏 |
| 已装技能列表 | 删除 | 深层动作 | 删除技能 | 被引用 |
| 可安装列表 | 安装 | 主动作 | 安装并刷新列表 | 来源不可达 |
| Provider 列表 | 选择 profile | 主动作 | 自动激活并刷新诊断 | profile 无效 |
| Provider 编辑器 | 保存 | 主动作 | 持久化配置 | 表单校验失败 |

## 8. 设置页
| 区域 | 动作 | 层级 | 结果 | 禁用条件 |
|---|---|---|---|---|
| 布局设置 | 调整主题/字号/缩放 | 主动作 | 即时生效并持久化 | 无 |
| 调试与诊断 | 打开日志/导出诊断 | 深层动作 | 打开日志视图或导出文件 | 无 |

## 9. Oracle
- 主动作必须在首屏可见区域内完成，不得埋到三级菜单。
- 深层动作允许在右键、更多菜单、Inspector 高级区。
- 同一对象的高频动作优先贴近对象本体。
