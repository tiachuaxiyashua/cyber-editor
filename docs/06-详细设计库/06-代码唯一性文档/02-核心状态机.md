# 02 核心状态机

## 1. 应用顶层状态机
```text
launching
  -> welcome
  -> workspace
  -> orchestration_only
```

约束：
- 只能通过 `bootstrap.load()` 决定首个状态。
- `workspace -> welcome` 只能通过 `project.close()` 或工程失效恢复。
- `welcome -> orchestration_only` 只能走“开始编排”路径。

## 2. 文档状态机
```text
closed
  -> opened_read
  -> opened_edit
  -> opened_source

opened_edit/source
  -> dirty
dirty
  -> saving
saving
  -> clean
  -> conflict
  -> save_error
conflict
  -> clean
  -> dirty
```

约束：
- `dirty` 不得因视图切换丢失。
- `save_error` 不得自动清空草稿。

## 3. AI 运行状态机
```text
idle
  -> queued
queued
  -> running
running
  -> succeeded
  -> failed
  -> stopped
failed
  -> retrying
retrying
  -> queued
```

约束：
- `stopped` 与 `failed` 必须区分。
- 每次 `retry` 必须创建新 run，不能覆盖旧 run。

## 4. 阶段确认状态机
```text
guard_unknown
  -> guard_checking
guard_checking
  -> guard_blocked
  -> guard_ready
guard_ready
  -> confirming
confirming
  -> confirmed
  -> guard_blocked
```

约束：
- `guard_blocked` 时阶段确认按钮必须禁用。
- `confirming` 前必须再次在主进程校验，不能只信 renderer 里的 ready 状态。

## 5. Flow 草稿状态机
```text
clean
  -> dirty
dirty
  -> saving
saving
  -> clean
  -> save_error
dirty
  -> snapshotting
snapshotting
  -> dirty
```

约束：
- 节点位置变化属于 `dirty`。
- Inspector 改配置、节点拖拽、边创建、阶段契约改动都属于同一草稿状态机。

## 6. 模板状态机
```text
available
  -> installing
installing
  -> installed
  -> install_error
installed
  -> update_available
installed
  -> damaged
damaged
  -> repaired
  -> removed
```

## 7. 技能状态机
```text
discovered
  -> installing
installing
  -> installed_disabled
installed_disabled
  -> enabled_global
  -> enabled_project
  -> enabled_session
enabled_*
  -> disabled
disabled
  -> removed
```

## 8. 多窗口状态机
```text
single_window
  -> split_view
single_window
  -> detached_window
detached_window
  -> single_window
split_view
  -> single_window
```

约束：
- 所有窗口共享同一工程状态源。
- 被分离窗口关闭时，主窗口不能丢当前标签状态。
