# 53 复杂对象嵌套字段默认值表

## 1. ProjectManifest
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | string | 无 | 是 | 项目标识 |
| `name` | string | 无 | 是 | 项目名 |
| `templateId` | string | `"custom"` | 是 | 模板来源 |
| `templateVersion` | string | `"0.0.0"` | 否 | 模板版本 |
| `createdAt` | ISO datetime | 当前时间 | 是 | 创建时间 |
| `updatedAt` | ISO datetime | 当前时间 | 是 | 更新时间 |
| `paths.artifacts` | string | `"artifacts"` | 是 | 工件目录 |
| `paths.flows` | string | `"flows"` | 是 | Flow 目录 |
| `paths.exports` | string | `"exports"` | 是 | 导出目录 |

## 2. FlowDraft
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | string | 无 | 是 | Flow 标识 |
| `kind` | `"flow" \| "subflow"` | `"flow"` | 是 | 类型 |
| `name` | string | `"未命名 Flow"` | 是 | Flow 名称 |
| `nodes` | FlowNode[] | `[]` | 是 | 节点集合 |
| `edges` | FlowEdge[] | `[]` | 是 | 边集合 |
| `meta.inputDirectory` | string | `"artifacts/in"` | 是 | 输入目录 |
| `meta.outputDirectory` | string | `"artifacts/out"` | 是 | 输出目录 |
| `meta.stageBindings` | object | `{}` | 否 | 阶段绑定 |
| `ui.viewport.zoom` | number | `1` | 是 | 缩放 |
| `ui.viewport.x` | number | `0` | 是 | 视口 x |
| `ui.viewport.y` | number | `0` | 是 | 视口 y |

## 3. FlowNode.data
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `label` | string | `type` | 是 | 节点显示名 |
| `description` | string | `""` | 否 | 描述 |
| `rolePackageId` | string | `undefined` | 否 | 角色节点专用 |
| `subflowId` | string | `undefined` | 否 | 子流程节点专用 |
| `loopPolicy.maxIterations` | number | `1` | 否 | 循环节点 |
| `parallelPolicy.mergeStrategy` | string | `"all_success"` | 否 | 并行汇合 |
| `io.inputArtifacts` | string[] | `[]` | 否 | 输入工件 |
| `io.outputArtifacts` | string[] | `[]` | 否 | 输出工件 |
| `messages.publish` | string[] | `[]` | 否 | 发送消息通道 |
| `messages.consume` | string[] | `[]` | 否 | 读取消息通道 |

## 4. RolePackageManifest
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | string | 无 | 是 | 角色包 ID |
| `name` | string | 无 | 是 | 名称 |
| `version` | string | `"0.0.0"` | 是 | 版本 |
| `compatibleFlows` | string[] | `[]` | 否 | 兼容的模板/Flow |
| `skills` | string[] | `[]` | 否 | 默认 skills |
| `rulesFile` | string | `"AGENTS.md"` | 否 | 协作规则文件 |
| `identityFile` | string | `"IDENTITY.md"` | 否 | 身份文件 |
| `soulFile` | string | `"SOUL.md"` | 否 | 人格文件 |
| `userFile` | string | `"USER.md"` | 否 | 用户画像文件 |

## 5. ExportMapping
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `formats` | string[] | `["md"]` | 是 | 导出格式 |
| `rules` | ExportRule[] | `[]` | 是 | 导出规则 |
| `outputRoot` | string | `"exports"` | 是 | 导出根目录 |

## 6. ContextPack
| 字段 | 类型 | 默认值 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | string | 无 | 是 | 上下文包 ID |
| `entries` | ContextEntry[] | `[]` | 是 | 片段 |
| `budgetTokens` | number | `8192` | 是 | 预算 |
| `strategy` | string | `"hybrid"` | 是 | 打包策略 |
