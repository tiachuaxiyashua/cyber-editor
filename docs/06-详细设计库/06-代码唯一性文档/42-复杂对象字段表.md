# 42 复杂对象字段表

## 1. ProjectManifest
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `projectId` | string | 是 | 工程唯一 ID |
| `name` | string | 是 | 工程名 |
| `templateId` | string | 否 | 来源模板 |
| `createdAt` | string | 是 | ISO 时间 |
| `updatedAt` | string | 是 | ISO 时间 |
| `version` | string | 是 | manifest schema 版本 |
| `entryFlowId` | string | 否 | 默认 flow |

## 2. FlowDraft
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `flowId` | string | 是 | flow 唯一 ID |
| `name` | string | 是 | flow 名称 |
| `nodes` | FlowNode[] | 是 | 节点列表 |
| `edges` | FlowEdge[] | 是 | 边列表 |
| `inputDirectory` | string | 否 | 输入目录 |
| `outputDirectory` | string | 否 | 输出目录 |
| `stageContracts` | StageContract[] | 否 | 阶段契约 |
| `exportMappings` | ExportMapping[] | 否 | 导出映射 |
| `revisionId` | string | 是 | 当前修订号 |

## 3. RolePackageManifest
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `roleId` | string | 是 | 角色包 ID |
| `name` | string | 是 | 角色名 |
| `version` | string | 是 | 版本 |
| `identityPath` | string | 否 | `IDENTITY.md` |
| `soulPath` | string | 否 | `SOUL.md` |
| `agentsPath` | string | 否 | `AGENTS.md` |
| `userPath` | string | 否 | `USER.md` |
| `skills` | string[] | 否 | 默认 skills |

## 4. TemplateManifest
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `templateId` | string | 是 | 模板 ID |
| `name` | string | 是 | 模板名 |
| `version` | string | 是 | 模板版本 |
| `compatibleApp` | string | 是 | 兼容应用版本范围 |
| `trustState` | string | 是 | trusted/warn/blocked |
| `source` | string | 否 | 本地/远程来源 |

## 5. ArtifactCatalog
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `artifacts` | ArtifactDefinition[] | 是 | 工件定义列表 |
| `defaultInputDir` | string | 否 | 默认输入目录 |
| `defaultOutputDir` | string | 否 | 默认输出目录 |

## 6. StageContract
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `stageId` | string | 是 | 阶段 ID |
| `requiredArtifacts` | string[] | 是 | 必需工件 ID |
| `validationRules` | string[] | 否 | 校验规则 |
| `blockingIssuePolicy` | string | 否 | blocker 策略 |

## 7. ExportMapping
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `mappingId` | string | 是 | 映射 ID |
| `artifactId` | string | 是 | 来源工件 |
| `targetPath` | string | 是 | 输出相对路径 |
| `format` | string | 是 | md/txt/pdf/openspec/... |

## 8. ContextPack
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `packId` | string | 是 | 上下文包 ID |
| `requiredItems` | ContextItem[] | 是 | 必选上下文 |
| `optionalItems` | ContextItem[] | 否 | 可选上下文 |
| `tokenBudget` | number | 是 | token 预算 |
| `stale` | boolean | 是 | 是否过期 |
