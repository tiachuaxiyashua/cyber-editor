## 约束
- 任何 `P3` 和 `P4` 都不能伪装成一个新的完整页面。
- 任何会替换主内容区的入口，都必须在页面文档中明确标记为 `P0` 或 `P1`。
- 欢迎页、新建工程与模板中心、主工作台、编排页之间的跳转，不能再只靠按钮文案推断。
