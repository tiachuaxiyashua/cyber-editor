## 使用规则
- 页面结构调整时，必须同步更新对应低保真区域。
- 如果 UI 页面文档和低保真线框冲突，以页面文档中的页面层级和功能调用关系为准，再回改线框。
- 低保真文件只固定页面层级、区域分工和高频操作位置，不替代页面文档里的完整交互定义。
