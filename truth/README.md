# Truth

`truth/` 是 Cyber Editor 下一阶段重构的**新真相空间**。它与 `docs/` 平级，不从属于 `docs/`。

这里用于从 0 开始重新想未来系统：它暂时不是代码实现承诺，也不是旧文档体系的补丁，而是后续重构代码、产品和协议时优先阅读的新源头。

`docs/` 仍保留为旧系统、旧实现、旧验收和历史细节的参考库；当 `truth/` 与 `docs/` 冲突时，默认认为 `truth/` 表达新的方向，`docs/` 表达旧状态或待迁移内容。

## 当前状态

- 阶段：开放脑暴。
- 目的：把“文档编辑器 / 自动化工作流”重新想成“文件原生、意图驱动、可组织智能、可迁移能力包”的通用框架。
- 使用方式：先发散，再抽象，再收敛；不要急于定死层级、对象名或目录协议。
- 约束：这是新的正向真相空间；不要再把未来重构的核心判断写回 `docs/` 作为主源。

## 工作原则

1. 先问“人类真正想撬动什么”，再问“需要什么流程”。
2. 先识别痛点、欲望、约束和隐含意图，再生成任务。
3. 先定义可观察、可解释、可介入的协作关系，再谈自动化。
4. 先保留想象力，不急于把系统降维成工作流编辑器。
5. 所有未来规范都应能回落到文件协议，让 UI 只是投影、编辑和状态展示。
