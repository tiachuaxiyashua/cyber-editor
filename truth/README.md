当前判断：

1. 人类是非帧价值源、授权源和责任源。
2. 软件底层稳定单元是文件。
3. 工作帧是“可执行变化”的文件语义。
4. 产物、记忆、证据、信用、镜头是对象文件或账本文件，不是工作帧本身。
5. 根约束帧由人类写入，人工智能只读，是最高权限约束。
6. 角色、技能、流程、组织和市场都从工作帧及其文件关系中长出来。
